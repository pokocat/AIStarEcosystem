# 个人资产库交互原型

独立 HTML / CSS / JavaScript 原型，用《废市》试走「提取 → 快速编辑 → 补图 / 上传 → 确认主图 → 跨画布引用」的流程。生成全部为模拟，实际费用为零。

## 本地打开

在仓库根目录 `/Users/donis/dev/AIStarEcosystem` 运行：

```bash
python3 -m http.server 4317 --bind 127.0.0.1 --directory prototypes/asset-library
```

打开 [http://127.0.0.1:4317/#library](http://127.0.0.1:4317/#library)。无需启动应用或后端；直接双击 HTML 会使剧本 JSON 的读取受浏览器限制。

## 完整试走

1. 在资产库点击「提取剧本资产」。原文含 92 场，本轮固定整理 6 位人物（江口、安子、直之、郁代、三郎、志乃）和 4 组场景，选择保存文件夹后进入快速编辑。
2. 切换人物 / 场景，核对「剧本依据」及场次原文；修改名称、描述和生成提示词。原文事实与待创作确认的外貌、陈设等建议分开显示，编辑描述不会改写原文依据。
3. 点击「一键补齐缺图」。初始 9 项有提示词，显示 72 演示积分；志乃的提示词为空，需先补充。可勾选「演示其中一项失败」，观察成功项入库，再单独重试失败项。
4. 点击「新画布引用」，建立如「废市 · 长廊初遇」的画布。输入 `@` 或点击「从资产库选择」，搜「江口」：本剧江口与其他创作的同名角色分别列出，按缩略图、文件夹、描述、来源及具体版本选择。
5. 引用人物和场景，填写画面描述，点击「演示生成画面」。结果会进入画布和「全部素材」；它仍是示意图片，不代表模型按提示词生成了画面。
6. 返回快速编辑，为江口生成新版本并显式「设为主图」。已有画布继续引用旧版，只提示可以更新；通过节点上的「查看更新」主动替换。上传作为主图则会新建一个版本并立即采用，旧版本仍保留。
7. 刷新页面，继续查看资产、上传图片、编辑内容和画布引用。画布已有节点后新建另一张画布，旧画布可通过顶部下拉切换；节点顶部可拖动。

文件夹为普通单层组织：可以新建、改名、移动资产，删除文件夹后资产转到「未分类」。未补图的提取项可以显式复用已有角色 / 场景；独立素材也可以提升为角色。名字相同不会自动合并。

## 数据与演示边界

- **真实内容**：`screenplay.json` 保留用户提供的《废市》剧本文字、作者 / 译者和 92 个场次，供本机预览。
- **固定精选**：6 人物、4 场景组来自预先整理的结果；没有运行 AI 提取器，也不是完整全片资产清单。
- **有限初始示例**：「其他创作」的 2 个角色和 4 张独立图片只用于演示已有素材与同名区分，没有读取用户的生产资产库。
- **模拟生成**：等待和失败状态由前端演示；图片取自预置示意资源或当前参考图。8 / 72 积分是交互报价示例，不调用模型、不扣积分，也不验证人物一致性或场景准确性。
- **本地图片**：支持 JPG / PNG / WebP，单张不超过 1 MB。文件由浏览器读取为 data URL，和其他原型状态一起存入当前来源的 `localStorage`，没有上传外部服务。
- **保存范围**：没有登录、后端、云端同步或生产应用接入。换浏览器、换地址 / 端口、清除站点数据后，原状态不会随之迁移；浏览器空间不足时页面会提示改动仅保留在当前页面。

在资产库、剧本页或快速编辑页底部点击「重置演示」，再点击「重置这版原型」，可清空本原型的上传与编辑数据并恢复初始示例。存储键为 `ipstudio-assets-prototype-feishi-v1`。

图片来源及使用范围见 [assets/SOURCES.md](assets/SOURCES.md)。示意人物取自本仓已有资源，场景来自所注明的照片来源，均不是《废市》的正式形象设定。验收范围见 [交互验收记录](../../docs/prototypes/asset-library-validation.md)，设计核对见 [设计检查](../../docs/prototypes/asset-library-design-check.md)。
