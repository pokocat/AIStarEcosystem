## 报错

| 原文 | 改为 |
|---|---|
| 页面顶部横幅「删除失败」（手机上被抽屉挡住） | 弹窗「删除没有完成」+ 原因 + 下一步，错误码放在「错误详情」 |
| 供应商原话里带余额、额度、预扣费 | 「生成服务暂时不可用，请稍后再试或联系平台处理。」（供应商的余额不给用户看，也不引导用户充值；见服务端 `PublicModelErrorPolicy`） |
| 供应商原话「资源空间不足，请清理回收站」 | 「生成服务的存储空间满了，这次没有生成成功。问题出在平台这边，删作品或清空回收站都没有用。……」（不让用户删自己的作品） |

## 首页和营销位（信达雅）

- 标语要短、有画面、不空泛：「一个你，不止一种想象。」「货好，也要拍得好。」
- 已定稿的标语也照这个标准改（2026-11-03）：

  | 原文 | 改为 |
  |---|---|
  | 让灵感成形，让 IP 出圈 | 一个 IP，无限可能 |
  | 声量引擎，让灵感成形，让 IP 出圈（首页标题） | 一个 IP，无限可能（「声量引擎」只留在品牌位） |
  | 从一个灵感开始，创造数字人、图片、视频与故事。让你的 IP 拥有形象、声音与作品。 | 制作形象、图片、视频和短剧。 |
- 卡片描述说具体的事：「一张实拍，生成可上架的白底图」，不说「轻松打造爆款主图」。
- 同一组卡片别用同一个句式开头。
- 不写「即可」：「一张实拍即可」→「只需一张实拍」。
