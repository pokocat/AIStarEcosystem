# 决策台账文档模板 / Decision-Ledger Doc Template

支付决策是**承重的、易被反复推翻**。产物不要只是代码，而是一份固化「决了什么、为什么、范围、接受了哪些风险」的台账文档。下面是结构 + 每节要点。

> 用法：复制这个骨架到团队知识库（Notion / wiki）。`<...>` 是填空。代码定位一律 `file:line`。

## 为什么值得写

- **防反复决策**：支付里「年付怎么折」「过期怎么降」这类问题会被反复重提，台账一锤定音。
- **onboard 下一个实现者**：file:line + 决策理由让接手人不必重走调研。
- **接受的风险显式化**：「手动退款不回收」这种取舍写进去，是有意识决策而非遗漏。
- **范围 in/out 防 scope creep**：把「不做」也写明，避免顺手过度设计。
