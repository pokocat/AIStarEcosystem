## 1. 已接通的链路

同一画布：样例图片 → DapAssetIp/DapAvatar 定稿 → 可编辑剧本 → 最新正文拆镜 → 首帧 → 视频片段 → 真实 ffmpeg 合成与导出。选中对象后的动作自动建节点/引用；剧本、故事板、成片视图留在当前项目。

IP 主形象、历史版本与 DapLook 造型可以引用到另一个项目。请求保存版本/key 快照，不复制人物或重写 ipId；更新主形象保留旧作品的输入。既有 publishedAvatarId 尚未关联 IP 的人物也可引用，并显式将原人物关联 IP，不另造人物。采用图片/视频具体候选与导出文件分开。

剧本支持生成、粘贴、手改、指定大纲或单集正文改写，拆镜使用当前编辑正文；人物/场景/道具可继续生成视觉参考。候选比较与选择保留旧结果，来源更新只标记下游，不自动重新生成。任务面板可查看实际请求的提示词、参考版本与参数。合成成功通过既有 DapAssetUsage 回流来源 IP 的作品页。

V40 在既有 IpRun 上加请求键/指纹和唯一(project_id,client_request_id)，同键重试返回原任务，同键改正文 409。worker afterCommit，终态/结算使用独立事务和行锁；doc 由客户端整存整取。真实视频绑定原 MaterialVideoJob(ipstudio)，进度/结果/费用为只读投影，不新增结算真值。

## 10. 接入配音前的完成审计与声音依赖
