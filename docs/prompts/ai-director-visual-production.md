## 1. 从实际产品看到了什么

Chrome 查看 [《家庭会议》项目](https://dj.diguvip.com/#/projects/70)，第 1 集“冰淇淋引发的战争”：

- 第一片段为约 15 秒、6 镜；分镜图是 3 列×2 行。可见图片提示词逐格描述景别、机位、人物位置、视线和动作，要求统一身份、衣着与光线。
- 视频提示词逐镜写时间、对应宫格、运动和对白；图 1 指分镜整图，后续图片指角色、场景、道具。资产设定图的多视角用于识别同一资产，不能被复制成视频中的多人或拼版。
- “小洁”角色主图提示词既有脸、发型、痣、衣服等辨识特征，也有正面半身、中性表情、柔光等拍摄要求。仅“年轻漂亮、电影质感”不具备同样的识别信息。
- 角色资产有“设置角色音色”，可填描述、上传音频；该样例两项为空。页面提示最长 3 秒、超过截取前三秒，这是该产品的 UI 行为，不作为我们的默认规则。
- 已看视频语音轨列角色、情绪／语气／语速和台词；未显示实际音频绑定。视频预览曾报无法播放，不能验证成片的声音、动作或一致性质量。

本轮没有取得完整的场景／道具生成提示词，也未检查网络请求或后台配置。下文相应模板是本项目设计，不冒充网站原文。观察由 Luna 子 Agent 只读完成。

## 2. 一致性应如何分工

**采用的资产图 → 采用的分镜板 → 多镜头视频**是一条共享视觉依据的链路。

分镜板值得作为核心检查点：在花视频费用前，同时核对人物、场景、道具、构图和各镜头状态；视频尽量继承这份已确认的画面设计。它不能保证模型完全遵循，也不能替代声音、运动与跨片段状态的验证。

| 内容 | 稳定依据 | 每镜可以改变的内容 |
|---|---|---|
| 角色 | 同一个身份基准和当前造型版本 | 表情、姿态、视角、受光 |
| 场景 | 同一空间的门窗、固定家具及连接关系 | 机位、景别；经批准的时间／天气状态 |
| 道具 | 外观与批准的状态版本 | 持有人、位置、朝向；剧情明确发生的状态变化 |
| 分镜 | 同一镜头计划及采用分镜板 | 动作过程、已安排的切镜与运镜 |
| 声音 | 同一角色的采用声音样本或模型确实支持的声音身份 | 本句台词、情绪、重音、语速 |

优先级：批准的剧情／制作设计为准；图与设计冲突先处理冲突，不让下一步自由猜。采用图用于落实外观和构图，文字补充看不见的动作过程。不同镜头不应强制“屏幕左右永远不变”，应保持真实空间和视线关系。

## 3. 给提示词编译 Agent 的共同指令

```text
你的任务是把已采用制作设计和真实参考素材，编译成当前模型可以使用的媒体提示词。
输入包括：本次任务、当前片段计划、采用的设计、实际图片/音频绑定、画幅和时长、模型能力。
只生成本次需要的内容，不独立改编剧情，不重新设计已确定的人物与空间。

先列本次“必须保持”和“允许改变”的内容，再输出一份可直接提交的提示词。
引用只使用系统提供的文件编号，说明每份参考的用途。人物名字只是标签，不能代替实际附图或声音文件。
文字描述与参考明显冲突、必要素材缺失、规格不支持时，列出具体问题，不以更长的形容词掩盖。
不要把资产档案的三视图、分区线、文字标签、背景或旧动作复制进目标镜头。
画面提示词写一个静态时刻；视频提示词写开始状态、动作过程、结束状态及声音。
避免堆叠互相冲突的景别、运镜和动作。保留少量有依据的防错要求，不堆无关负面词。
输出沿用 A6 的结构：实际 prompt、referenceIds、cells 或 segments、dialogueTrack 和检查项。
检查项是要求，不是已经通过的结论。
```

以下【变量】必须在提交前由采用数据填好；缺失时不把占位词发给生成模型。示例中的“图1／音频1”是本次请求内编号，不是全项目永久编号。

## 4. 角色资产：先把人定清楚，再派生造型

**2026-10-24 现行实现（`DirectorPrompts.assetPrompt` 角色分支）**：角色出一张横版 16:9 设定集，同一张图里拼五个区：① 左侧全身三视图（正面、正侧面、背面）；② 颈部以上头部正面、左侧面、右侧面；③ 喜怒哀乐表情四宫格；④ 面部特征特写 2–3 张（眼、鼻、嘴或痣、疤、配饰等身体特征）；⑤ 正面半身展示图。浅灰纯色背景、统一棚拍光、细白边分隔，所有分区同一个人，图中不写文字。后续分镜图和视频把它当标准照锁定长相、服装和表情，不复制它的排版。

用户上传的照片不能直接当角色图，只能设为形象参考。生成时作为图1，提示词末尾追加 `DirectorPrompts.CHARACTER_REF_NOTE`：长相照着照片画，不照搬照片的构图、角度、背景、光线和画质，服装以设定为准，版式仍是上面的五区设定集。

主图优先清楚识别脸、头发和本次造型；需要全身、侧面或背面时再从同一基准派生。近景主图没有展示的裤装／鞋子不能声称已经视觉确认，应另有采用设计或全身图。不同用途允许不同画幅，不强迫角色参考图也是视频的 9:16。

```text
制作【视觉风格】角色【角色名】的【本次视图：头肩/半身/全身/侧面等】参考图。
身份特征：【年龄段、脸型、发型、体型及少量辨识特征】。
当前造型：【服装的款式与颜色、重要配饰】。
只展示一个角色，表情自然中性，轮廓清楚，关键身份特征无遮挡。
【与用途匹配的景别】、自然透视、均匀可辨的受光、简洁背景。
不添加剧情动作、其他人物、未指定配饰、文字标签或多视图拼版。
```

有采用基准时，首段改为：

```text
以图1中的同一个角色为身份基准，保留脸型、五官比例、发型和辨识特征。
本次只改变【批准的服装/角度/年龄造型变化】，其他身份特征不重新设计。
图1的姿势、表情和背景不作为本次必须继承的内容。
```

角色跨年龄需要明确年龄变体；不要同时要求“脸完全不变”和“从幼童变为老人”。图像变化与叙事身份分开管理。

## 5. 场景资产：先固定空间，再确定这一场的光线

场景不能只是一张氛围图。挑选剧情真正会用的 3–5 个空间锚点，写相对位置、连接和朝向；背景杂物不需要全部编号。房间方位是制作依据，具体生图仍要写相机位置和朝向，避免只靠“东／西”让模型猜。

```text
制作【场景名】的【建立全景/指定机位参考图】，风格【风格】。
固定空间：【空间形状、入口、窗、固定家具，以及它们的相对关系】。
相机位于【位置】，朝向【方向或可见锚点】，采用【景别与自然透视】。
画面必须清楚显示【本次可见的关键锚点】，被遮挡或画外的部分不强行挤入。
场次光照：【时间、主要光源及方向、室内灯状态】；保持统一色调。
不出现人物和临时剧情道具，不任意增加门窗、镜面或第二套家具。
```

同场景反打／新机位补充：

```text
以图1为同一空间基准，保持门窗、固定家具及通道的实际关系。
相机由【原位置】移至【新位置】，朝向【新方向】。
改变的是观看方向，不是房间布局；不要将整个房间水平镜像作为反打。
图1未展示而本镜必须显示的区域，只按已采用空间设计补充；没有设计就先列出缺项。
```

不默认让模型一次画四个完美一致的视角。先确认一个清楚的空间基准，再按镜头需求补机位；采用的场景图不是精确三维模型。

## 6. 道具资产：外观与剧情状态分开

```text
制作【道具名】的单件参考图。外观为【轮廓、材质、主色、尺寸关系、辨识细节】。
当前状态为【完整/折叠/关闭/打开等已采用状态】。
采用【能清楚识别的角度和景别】，光照均匀，背景简洁。
不出现人物或手，不表现使用动作，不添加重复道具或未指定文字商标。
```

必要的正反面按同一道具派生，不生成两个无关物件。信封从桌面到右手是镜头状态，不另造一个“手持版信封身份”；真正撕开、破损等外观改变才记录状态版本。

## 7. 分镜图：把采用资产落实成每格可以检查的画面

```text
根据采用的镜头计划生成一张【列数×行数】分镜板。
整板比例【系统计算的整板比例】，单格比例【单格比例】，等大格子，按左到右、上到下阅读。
风格【风格】，当前场次【地点、时间、光线】。

参考用途：
【图1】提供【角色及当前造型】，只继承身份与服装，不复制参考姿势和背景。
【图2】提供【场景固定布局及本场光线】。
【图3】提供【关键道具外观及当前状态】。
若参考图是多视角资料，将它理解为同一资产，不能画成多个角色、多个物件或复制资料拼版。

逐格画面：
第1格：【对应镜头；景别；相机位置/朝向；画面内人物及站位；视线；一个静态动作时刻；道具状态】。
第2格：【同上】。
……

全部格子保持同一角色、当前造型、同一空间关系和本场光源；按机位产生合理透视变化。
每格只描绘一个时刻，不画动作残影或连续步骤小拼图。
每格只出现该镜所需人物；镜头外的人或物不必强行出现，也不能在后续无故消失或更换。
不在图内绘制对白、字幕、镜号、水印或资产资料边框。格号由外部位置映射管理。
```

系统保存格子与镜头对应关系；如需可见编号，可用确定性排版加在预览层，不能依赖模型画字和 OCR。声称“6 格均为 16:9”时，3 列×2 行的整板应是 8:3（不计格缝），不是 16:9；当前示例产品提示词的“横版”不能直接推广为整板比例。最终视频 9:16 与参考板整体比例分别校验。

**生成前先减负：** 一个短片段内有过多人物、机位或复杂道具交换，先调整经批准的镜头安排。不能靠无限延长提示词把所有动作塞进 15 秒。

## 8. 视频：复用分镜设计，补足真正发生的过程

下列模板用于已经验证支持分镜参考与多镜头生成的模型路径。其他路径按工作流准备真实单镜首帧，不把整板当普通首帧直接提交。

**2026-10-26 现行实现（`DirectorPrompts.videoPrompt`）**：中文 H3 结构，用户看到、能改的是这一份；H3 提交前再按官方 skill 改写成英文（见本节末），厂商改写关着。
写法来自聚算 H3 文档（price.jusuanhub.com）与同一片段的五条对比实测（`docs/audits/director-h3-video-prompt-ab-2026-10.md`）：
旧写法在两人同框的第 1 镜两次出事（穿模、把宫格拍进画面），新结构三条都没有，中文与英文没有差别。

```text
【人物】
【角色】：长相、发型和衣服都照参考图N。参考图N 是【角色】的设定图，图里的人像都是【角色】一个人。
场景「…」：空间布局和光线照参考图N。 / 道具「…」：外观照参考图N。
【角色们】在画面里各只出现一个，长相和衣服从头到尾保持一致。

【分镜参考】
参考图1 是 2×2 分镜：左上格对应第1镜，右上格对应第2镜……（其余格子是空的）。每格只参考构图、机位和人物位置，每一镜都是一个完整的全屏画面。

【画面】
【风格】风格。
第1镜（0–【结束】 秒）：【景别】，【机位】。【画面】。【动作】。（只认出一个角色时）画面里只有【角色】。【角色】说：「【逐字台词】」
第2镜（【开始】 秒切）：……【说话人不在画面里时】【角色】在画外说：「……」画面里的人嘴闭着。【其他人】听着，嘴闭着。
（最后一镜）……最后保持这个画面到结束。

【声音】
（无台词时）这一段没有对白。
声音参考：【角色】的音色、口音照音频N，只借声音，说的是上面引号里的台词。
【角色】的音色：【voiceDesc】
【角色们】 没有声音参考，按人物身份自然配音。

【配乐】
无

人物只说引号里的台词，画面里没有字幕。
```

「画面里有谁」现在按镜头描述里点到的角色名认（`castOf`，长名字先认）；分镜脚本补了逐镜出镜人与站位字段后改读字段。
不写「禁止出现格线」这类否定句（H3 没有负面提示词字段，旧写法写了照样拍出宫格），不写画幅和总时长（走请求参数）。

2026-10-24 至 10-26 的旧模板（时间轴逐镜 →【语音轨】→【参考图说明】）保留为 `legacyVideoPrompt`，只用来核对旧格式生成的视频。

**提交前改写成官方英文写法（2026-10-26）**：上面这份中文是用户看、改的；所选视频模型是 H3 时，提交前用作品的文本模型按 MiniMax 官方 skill（`apps/server/src/main/resources/director/h3-skill`）改写成英文六段式，台词保留中文、由代码填进 `(Sx) <d>[Chinese] 原文</d>`（`DirectorH3Rewrite`）。原因：台词多的片段，中文正文会吞整句台词、还会把提示词里的中文念出来（审计 §6）。改写结果在视频提示词下方可展开查看「发给模型的英文」。

早期草案（保留作对照，含尚未进入镜头数据的语气、运镜、环境声字段）：

```text
生成【总时长】秒、【最终比例】的【风格】剧情片段，共【镜数】镜，按以下时间顺序呈现。
图1是已采用分镜板，按【阅读顺序】对应镜头；它指定构图与剧情时刻。
最终视频每一时刻只呈现一个完整镜头，不展示宫格、资料板或分屏。
图2提供【角色身份和造型】，图3提供【场景布局】，图4提供【道具外观】。
分镜板中的代表时刻不一定是该镜动作起点，按以下开始与结束状态完成动作。

00:00–【时间】：对应第1格，【景别与机位】。
开始：【状态】；过程：【主体动作】；结束：【状态】。
相机：【保持/一种明确运镜】。接下一镜：【切镜方式】。
【后续各镜同结构】

语音轨：
【镜头/时间段】，【角色】说：“【逐字台词】”。【情绪、语速、关键重音】。
【明确是否画外音；可见说话者口型配合，其他人不抢说；仅在剧情需要时重叠发言】。
声音身份按下方声音参考绑定；只说本段列出的台词，不朗读镜号、参考说明或旧样本内容。
环境声：【必要声音及出现时间】，不遮盖对白；配乐：【明确有/无及要求】。

连续状态：【当前服装、重要空间锚点、道具持有人/左右手/开合状态】。
禁止出现【本片段最容易发生的2–4项具体错误】。
不追加剧情、人物、对白或未要求的字幕。
```

每镜时间是生成意图，真实输出仍需测量；不能以提示词写了精确秒数就认定模型逐帧遵守。对白太长时调整已批准的时长或台词，不靠极快语速硬塞，更不能静默截断。

## 9. 声音连续性：原生音画生成，角色级保存声音依据

首版不设置独立“音画同步”必经页面。支持所需声音能力时，由模型直接生成视频、对白和环境声；重配音／对口型保留为有需要时的修复方式，不默认每段都走一次。

MiniMax 官方说明 H3 可原生生成声音，并支持以音频作为声音参考。当前平台代码也已有全能参考音频上传和请求组装路径。这只证明能力与输入通路，不证明任何项目已绑定正确音色，或跨片段效果已验收。

### 9.1 声音像角色图片一样管理

- 每个说话角色可以有一份采用声音基准及其版本；换衣服不自动换声音。
- 首版来源为用户已有声音素材、既有 DapVoice 版本的真实采样／试听文件，或明确发起的一次短配音试音；试音计入预算，不默认批量调用。混合视频提取不作为默认来源，后续仅在有干净单人语音或经过验证的分离能力时考虑。
- 使用清楚、单人、无重音乐和混说的片段；样本从哪里截取由有效语音决定，不机械截前三秒。长度、格式和数量取实际接入端点合同。
- 各段复用相同声音基准；不要每段都把上一段生成结果当新的唯一音色来源，以免把偏差逐段传下去。相邻片段声音可补表演衔接，身份仍锚定固定样本。
- 稳定声音特征（音色、口音、习惯语速）与本句表演（生气、低语、喊叫）分开，情绪变化不被错误判为换人。
- 只有文字音色描述时显示“未绑定声音参考”；多人说话超过音频参考上限时先调整片段计划，不悄悄遗漏角色。
- 按实际有效语音同时校验每段长度、数量与总长度，不固定平均分配。界面写“已绑定声音参考”，不把上传成功说成“音色一致已保证”。

有真实文件绑定时，视频模板加入：

```text
声音参考绑定：
音频1 → 【角色A】：沿用音色、口音和声音辨识特征。
音频2 → 【角色B】：沿用音色、口音和声音辨识特征。
音频仅作相应角色声音身份参考，不复制样本台词、背景音乐或噪声。
本段只说语音轨中指定的新台词，按本句要求改变情绪和语速；角色之间不交换声音。
```

只有文字描述时使用降级表述，不虚构“音频1”：

```text
【角色A】声音设计：【年龄感、音区、音质、口音、习惯语速】。
本段各次发言使用同一种声音设计；台词与情绪按语音轨执行。
```

后一种只提供文字约束，不能承诺跨片段身份一致。泛用 TTS 的 voiceId 也不能直接塞入没有该参数的视频接口。两段间对白是否衔接、有没有串角色，应使用音频证据或人工试听检查，静帧视觉模型无法证明。

## 10. 一套可直接评审的原创完整示例

以下沿用工作流的“林夏拿信封”故事，所有外观、布局和声音是**示例采用设计**，不是网站的素材或真实生成结果。示例时长 12 秒、4 镜；实际提交仍要满足所选模型能力。

### 10.1 人物图

```text
真人写实角色参考图。林夏，约28岁的东亚女性，椭圆脸，深棕色眼睛，黑色齐肩直发，右眉尾有一颗小痣，身形偏瘦。穿米色短外套、白色无图案内搭。正面半身构图，面部清楚，双手自然放松，中性表情，柔和均匀光线，简洁灰背景。画面只出现一个人，不添加首饰、帽子、文字或拼版。
```

### 10.2 场景图

```text
真人写实的夜晚旧书店空场参考图。长方形房间，北墙为深木色整面书架，东墙有一扇木门，西墙有一扇窗，中央只有一张长方形木桌。相机在房间西南角朝东北拍摄，平视广角全景，木桌在前景中央、书架在后景、木门在画面右侧，桌子与门之间留有可通行空间。西侧窗外冷色夜光与桌上方暖色灯光形成固定受光关系。画面不出现人物、信封、镜面或第二扇门。保持自然透视，不为了展示西窗而扭曲空间。
```

### 10.3 道具图

```text
真人写实物品参考图。一个普通信纸大小的暗红色哑光纸信封，长方形、背面有三角形封口，当前闭合，无文字、图案或蜡封。单件近景，三分之四角度清楚展示背面封口和纸张厚度，均匀柔光，简洁灰背景。只出现一个完整信封，没有手、信纸或重复物件。
```

### 10.4 分镜图

实际输入：图1=采用的林夏图，图2=采用的书店图，图3=采用的信封图。

```text
真人写实，夜晚旧书店。制作2列×2行分镜板，等大无间隙四格，整板9:16，每格9:16，按左上、右上、左下、右下阅读。
图1提供林夏的脸、发型和米色外套；图2提供同一书店的空间及光线；图3提供同一个暗红信封。不要复制资产参考的灰背景、姿势或资料排版。

左上：平视中全景，相机在西南侧朝东北。林夏站在东墙木门内侧，门已闭合，面向中央木桌；桌面上只有一个红信封，北墙书架可见。
右上：从木桌西侧拍手部近景，林夏右手刚拿起闭合信封；信封离开桌面，桌上没有第二只信封，米色袖口可见。
左下：西南侧中近景，林夏低头看右手中的信封，背面的三角形封口朝向她；信封仍闭合，左手没有拿走它。
右下：沿用西南侧机位的中景，林夏回头看向东墙木门，右手仍握同一信封；木门闭合，不出现门外来人。

四格使用同一张脸、发型、衣服、书店布局、信封及光线。每格只表现所述静态时刻，不画动作残影，不增加人物。图内不画文字、字幕、镜号或水印。
```

### 10.5 视频与原生声音

本次重新绑定：图1=采用分镜板，图2=林夏，图3=书店，图4=信封；音频1=已采用林夏声音样本。没有音频文件时不能原样提交本例的声音绑定段。

```text
生成12秒、9:16、真人写实的夜晚书店剧情片段，共4镜。
图1是2×2分镜板，左上、右上、左下、右下依次对应4镜；图2固定林夏的身份和米色外套，图3固定书店布局与光线，图4固定暗红信封。视频始终全屏呈现单镜画面，不出现宫格或参考资料背景。

0–3秒，对应左上格：平视中全景，相机保持。林夏起初站在已闭合的东墙门内侧，随后走到中央木桌前；信封始终在桌面，未被提前拿起。
3–6秒，对应右上格：切手部近景，相机在桌子西侧。起初信封仍在桌上，林夏右手伸向信封、抓住并拿起，结束时信封离开桌面、只有右手持有。分镜右上格是拿起后的代表时刻，不要从已经拿起的状态重复拿取。
6–9秒，对应左下格：切西南侧中近景。林夏用右手翻转闭合信封，让背面封口朝向自己，低头查看；不拆开，不换到左手，不出现第二只信封。
9–12秒，对应右下格：切同侧中景。她原本仍低头看信封，9秒处听见东墙门传来一次轻敲，停顿后回头看门；右手始终持信封，门保持闭合，画面不出现新人物。

声音：音频1只提供林夏的声音身份，沿用音色和口音，不复制样本中的台词、噪声或背景音乐。
10–12秒，林夏轻声、警惕地说：“谁在外面？”与可见说话动作配合。只生成这一句对白，不朗读提示词。
保留轻微室内底噪、脚步和纸张摩擦声；9秒出现一次清晰但不过响的敲门声。不要新增配乐、旁白、字幕或其他人物声音。
```

若走逐镜首帧路径，右上、左下、右下的代表图分别在动作完成后，不能直接充当拿起、翻转、回头的起始帧。先按每镜真正开始状态准备帧图，再按模型支持的时长生成；不得照抄四个3秒请求到不支持3秒的模型。

## 11. 检查与小样验证

先检查分镜板身份、机位、道具状态、格子映射；不合格先修图，再编译视频提示词。若实际计划不合理，修计划后更新对应图，不靠视频词补救矛盾。

首轮实测只需一个人物、一个场景、一个道具、连续两段视频：

1. 固定采用资产与分镜板，核对镜头顺序、关键动作和道具是否连续。
2. 比较“相同声音文字描述”和“绑定同一声音样本”两种条件，使用不同台词与情绪；保持模型、视觉输入及其他参数一致。
3. 记录漏词、串角色、音色漂移、口型、背景声突变及人工试听意见。原生声音不等于已通过声音一致性验收。
4. 固定样本是推荐策略；没有上述小样验证前，不承诺声音绝对一致。当前尚未开展这些收费验证。
