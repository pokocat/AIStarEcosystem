# IP 人物设定图 · 一次出图提示词

这是按用户目标版式编写的可复用提示词，不是小红书作者的原始提示词。默认一个图片步骤，参考来源选择用户自己的 IP 或图片，方形或接近方形画幅；模型、单价和真实支持规格仍以平台配置为准。

## 一次生成设定图

```text
以输入参考图中的人物为唯一角色，制作一张完整的接近方形的人物设定图（character design sheet）。整张设定图在一次生成中完成，不要输出多张独立图片。沿用参考图的视觉风格、脸部特征、年龄感、发型、服饰、配饰、身体比例和材质，所有区域必须是同一个人物、同一套服装。所有面部细节也严格沿用参考图风格：玩偶或卡通角色的眼睛、眉毛、嘴唇保持玩偶或卡通材质，不能换成写实真人皮肤和五官。

使用暖白纸面背景、细灰分隔线、编辑式网格排版、黑色衬线标题、均衡留白与清晰的视觉层级，类似一张专业角色档案板。整张图分成上、中、下三层：

上层约占全图45%。左侧是人物大幅半身/脸部照片与简短档案区，档案只填写已经提供的人物名、年龄、身份、时代、性格和关键词，不擅自补身份数据。中间是三视图：正面、严格90度侧面、严格180度背面全身视图，并排、相同人物比例、相同服装、相同高度和脚底基线，完整包含头和脚。右侧是风格关键词和两张小幅环境氛围图，环境只服务于角色设定，不改变人物。

中层约占全图25%。左侧横排五张头肩表情特写：慵懒微笑、惊讶、拽酷、轻微愠怒、温柔平静；保留同一张脸、发型和配饰，只改变表情。右侧安排眼睛、眉毛、嘴唇、发型、耳饰等已有特征的近景细节，主动使用特写构图，不必显示全身。

下层约占全图30%。左侧为服装细节网格，包括参考图实际具有的领口、袖口、面料、裤型、腰带和背部设计，缺少的项直接省略；中间是参考图已有配饰或用户明确指定的道具，整齐独立展示；右侧是材质纹理与主要/辅助配色色块。没有配饰时省略配饰栏，用已有材质与配色色块填充留白。不得为了填满版面增生裤子、腰带、耳饰、眼镜、道具、品牌标志、服饰图案或纹身。

标注保持简短，使用“人物档案”“三视图”“五种表情”“面部细节”“服装细节”“配饰”“材质与配色”。不要塞入长段文字、虚构参数或无关装饰。保证角色一致、图像清晰、分区互不遮挡；不要把三个视角画成同一种角度，不要混入其他人物，不要改变角色风格。不要添加签名或水印。
```

输入没有人物参考时，可将首段改成用户确认的人物描述；不得把作者私有图片或固定人物身份嵌入发布模板。如果所选模型中文表现不稳，可改为不生成文字，再用可控排版添加短标题。

## 用设定图继续生成单独镜头

把采用的设定图整张作为图像参考，明确输出是一张单独画面：

```text
参考人物设定图，只使用其中同一个角色。保留脸型、发型、服装、配饰、配色、身体比例和视觉风格。生成一张单独的镜头画面：角色以【所需视角】在【场景】中【动作】，采用【景别与构图】。画面中只出现所需数量的角色。不要重现设定图的拼版、多个视角陈列、分区边框、标题或色块。
```

这张单独镜头经过采用后，作为图生视频的首帧；设定图继续保留为角色来源。参考整图不等于像素复制，一致性仍需检查；特别小的脸部或衣服细节可以按需裁取或补一张单独特写。用户无需先制作八张图片才能开始使用。

## 附图对应的模板参数

- 视觉：1990年代美式街头、写实摄影、复古胶片质感。
- 人物：年轻男性、棕色卷发、反戴深色棒球帽、耳饰；可整体换为用户 IP，不能把这些特征写死到通用模板。
- 服饰：旧洗水深色牛仔夹克、米白内搭、宽松工装裤、腰带与旧运动鞋。
- 配饰：拍立得相机、棒球帽、头戴耳机、帆布挎包；仅在用户选中这套示例时使用。
- 布局：上层人物档案/三视图/风格氛围，中层五种表情/面部细节，下层服装/配件/材质配色。

文字与图像可以一次生成；是否正确可读要看实际输出。对后续人物参考而言，清晰的人脸、体态、服装和视角比长段档案文字更有用。
