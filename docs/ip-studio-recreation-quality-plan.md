## 3. 根因

按影响从大到小。每条都有证据和代码位置。

### 3.1 人物没有统一的样子

1. **每张开场画面各自换脸**。13 张图各自拿「原片截图 + 人物图1 + 人物图2」出一次图，提示词是「将男女主面部分别替换为人物图 1 和人物图 2，保留原片衣着与发型」。同一张人物图换 9 次脸，出来 9 张略有不同的脸。火山人像审核判了 4 张 `FaceMismatch`，就是这个问题的旁证。
2. **视频段的参考名额先给开场画面，剩下的才给人物图**。代码在 `StudioRecreationTaskPlan.prepare` 第 127–158 行：先按 `keyframeShots` 放开场画面，再 `for(Material m:pictures)` 放素材。第 1 段有 9 张开场画面，正好占满 9 个名额，人物图一张都没放进去；第 2 段只有 4 张开场画面，放进了两张人物图。于是两段的人物依据不一样，脸也对不上。
3. **自动检查默认关着**。视频页 `scene-video-studio.tsx` 第 146 行 `useState(false)`，这次 `autoCheck=false`，开场画面换脸不像、视频里人不对都不会重出。

### 3.2 商品被重画了

1. **开场画面模板的最后一句把商品标签也抹了**。`studio/prompts/stages/stage-recreation-keyframe.md` 结尾是「去掉画面上所有的平台水印、账号、文字和标识」。本意是去水印，但商品特写镜头里瓶标「101」也是文字和标识，出图模型照做，等于重新设计了一个瓶子。
2. **拉片对同一样东西叫法不一**。人物商品表里是「101 洗发水」，第 15 镜的构图描述写成「香水瓶」，第 14 镜写「卫浴场景」。钱包一处写黄色、一处写棕色，视频提示词用了错的「棕色」。
3. **结尾镜头的开场画面里商品还没出现**（「尚未完全露出香水瓶」），视频模型只能自己编一个瓶子。全片没有一张固定的「商品长这样」的参考图。
4. **第 3、9 镜没有开场画面**，只靠文字描述台面上的三样东西，品牌字、钱包颜色全靠模型猜。

### 3.3 流程断了，合成没跑

1. 执行时限是从开始算的固定 3 小时（`StudioPlanExecutor.SEGMENTED_WINDOW`，判定在第 157 行）。16:10 开始，中间空了两个半小时，又等人像审核，19:10:54 一到就停成「部分完成」。等用户操作的时间也算在里面。
2. 停下之后两段视频其实都成功了，但没有任何东西接着跑合成。字幕、顶部标题、音量统一都在合成里，所以全没有。
3. 真人审核在最后才撞上：出完 13 张图（260 积分）、提交视频时才被火山拒绝。人物图是真人这件事，在用户上传那一刻就知道了。
4. 16:14 点「继续」后没有执行记录。同一天 18:22 提交的 `da910ab58`（修预算检查、审核后视频任务继续）可能已经修了其中一部分，要核实它覆盖哪些路径、当时线上是哪一版。

### 3.4 用户要求和原片看点冲突

原片的笑点是女主变丑。用户要求「不要丑化」。写分镜脚本的模型折中成「头发蓬松毛躁但面容美观」「头顶头发明显稀疏但五官自然」，这两句只是文字，视频模型做出来第一档不明显、第二档很怪。冲突没有被识别，也没有用图把「变成什么样」定下来。

## 4. 为什么要重构，不再做局部优化

复刻已经优化过几轮（直接看视频的拉片、开场画面、自动检查），效果仍然不稳。问题在设计上，有四处：

1. **原片被压成文字再还原，而且转了两手。** 拉片模型看视频写成文字，另一个没看过原片的模型按这份文字写提示词。文字没写到的丢了，写错的（「香水瓶」「棕色钱包」）一路带到成片。能测出来的事（时长、人数、位置、颜色）也靠模型描述。
2. **一次让视频模型出十几秒、十来个镜头。** 切镜时间、每镜构图、跨镜头的人物一致全交给模型。提示词是一千多字的散文，九张参考图各管一镜。一段坏了一镜，整段 840 积分重出。
3. **没有任何东西能说明「改完更像了」。** 提示词写完直接出片，出来不像也不知道是哪句话的问题。每轮优化都是看一两条片子的感觉，没有一个可以重复测的分数。
4. **制作方案是一次性拼出来的一串步骤，带一个总时限。** 中间一步等久了，整条停成「部分完成」，后面没人接。

## 5. 约束和原则

用户已定：

- **不拼接原片画面。** 每个镜头都重新生成，包括没有要换的东西的镜头。
- **视频页不新增让用户确认的步骤**，靠自动检查和重出。
- **分镜复刻的核心是把原片的提示词还原出来。** 方案要说清怎么还原、怎么验证。

设计原则：

1. 原片的时间线（切镜点、每镜时长）由算法定，成片照它排。
2. 能测的不让模型说；模型说的每一项都要在画面上指得出来。
3. 每个要保持一致的东西，全片只有一份依据图。
4. 图管样子，字只管时间上的变化。
5. 提示词能不能还原，要有数字，离线可重复测。
6. 便宜的检查放在贵的步骤前面；会拦住整条流程的事（真人审核）最先做。
7. 一处不合格只重做那一处；流程在任何一步停下都能接着做。

## 6. 视频模型的硬约束

设计要落在模型实际能做什么上。下面是这次任务记录里 Seedance 2.0 Fast 的规格快照（线上实际配置）：

| | 图生视频（首帧） | 全能参考 |
|---|---|---|
| 首帧 | 一张，严格作为第一帧 | 没有首帧位，只能在提示词里写「从图N开始拍」 |
| 参考图 | 不能带 | 最多 9 张 |
| 参考视频 | 不能带 | 最多 3 段，每段 2–15 秒 |
| 参考音频 | 不能带 | 最多 3 段，合计 15 秒内 |
| 尾帧 | 不支持 | 不支持 |

两种模式单次都是 4–15 秒，这次的价格是每秒 60 积分。

这带来三个绕不开的取舍：

- **真正的首帧和身份、声音参考不能同时要。** 用首帧模式，人物只能靠首帧图本身，声音没有参考；用全能参考，能带定妆图和声音样本，但首帧只是「建议」。
- **镜头中途才出现的人和物，首帧图里没有。** 例如结尾女主从画面下方举起洗发水。首帧模式下它只能靠文字，全能参考可以带商品图。
- **最短 4 秒。** 本片 15 镜里 13 镜短于 4 秒，5 镜不到 1 秒。

按这条片子算几种生成单位的视频秒数（每秒 60 积分，不含出图和重出）：

| 生成单位 | 生成次数 | 生成秒数 | 视频积分 | 相对现在 |
|---|---|---|---|---|
| 现在：2 段，每段十来镜 | 2 | 28 | 1680 | 1 倍 |
| 一镜一次 | 15 | 约 62 | 约 3720 | 2.2 倍 |
| 同机位、同样子的镜头一条拍完再剪 | 约 10 | 约 40 | 约 2400 | 1.4 倍 |
| 相邻 2–3 镜一组 | 约 6 | 约 30 | 约 1800 | 1.1 倍 |

「一镜一次」最可控，但贵一倍多，而且 0.7 秒的镜头要生成 4 秒再裁，动作节奏未必落在要用的那一小段里。所以**生成单位不能在纸面上定，要由第 10 节的实验定**；设计里把「镜头」和「一次生成」分开记，哪种单位都能装。

客户这次自己重试花了约 8000 积分。成本上限定在几倍以内可以接受，需要产品决定，实验会给出每种做法的实际花费。

调研了用户给的四个仓库和另外四个相关项目，完整报告在临时文件
`/private/tmp/claude-501/-Users-donis-dev-AIStarEcosystem/5bbb410c-39dd-4a5c-b9f3-695b4ad0c220/scratchpad/oss-recreation-survey.md`。
没有找到专门做「换人换商品、每个镜头都重新生成」的开源项目，下面是最接近的。

| 项目 | 和我们多近 | 值得学的 |
|---|---|---|
| [ViMax](https://github.com/HKUDS/ViMax)（剧本到视频，MIT） | 不做复刻，多镜头一致性做得最系统 | 一镜一次生成，首帧是真正的首帧；按首尾变化大小决定要不要尾帧；人物拆成不变的和会变的特征；每个首帧出几张候选再挑 |
| KOSENX 批量复刻 | 做商品视频复刻 | 一镜一个任务；每镜抽 3 帧和参考图对比，不对就重出，最多两轮，不过关不出片 |
| [skill_video-style-analysis](https://github.com/huangserva/skill_video-style-analysis) | 做重建，不换人 | 人脸聚类给原片人物建档；画面里每个看得见的人都要有身份图；全片锁一份风格说明拼进每条提示词；每个判断带证据和未决点 |
| [hypit](https://github.com/hypit-ai/hypit)（我们已在用它的拉片） | 分析很强，生成靠人看 | 带时间标签的帧网格加逐词转写；提示词模板分「要保持的」「要照搬的」「不要照搬的」；同场景从上一张图延续，换场景从定妆图重新开始；一次生成多长由表演和模型能力定，不是一图一镜 |
| [replicate-video-ad](https://github.com/Jingyi-Wu-Richael/replicate-video-ad) | 只有分析和提示词 | 听不清的台词标「不可用」不许编；文字全部后期加 |
| ChatCut viral-video-cloner | 场景最贴近，生成部分闭源 | 两种做法按「没点名的部分重不重要」选：编辑原素材，或只留动作整个重生成；0.3 秒以下的快切会漂 |
| [video-production-skills](https://github.com/Pluviobyte/video-production-skills) | 做网页动效，不相关 | 逐帧算相似度和时间偏移；只声明证据能证明的保真程度 |

各家在生成单位上没有共识：ViMax、KOSENX 一镜一次，hypit、skill_video-style-analysis、ChatCut 一次多镜。这也说明生成单位要靠实测。

各家一致、我们采纳的：先定人物和商品的参考图再开工；提示词由代码模板拼，不变的和会变的分开；每个看得见的人都给身份图；文字后期加。

## 8. 新设计

一句话：**原片提供时间线；每个镜头有一张测量加观察填出来的镜头卡和一张首帧图；提示词由代码从镜头卡拼出来；全片共用一套定妆图；逐镜检查、逐镜重做；提示词还原得好不好有离线分数。**

| 算法拆原片：切镜、人脸建档、语音识别、文字识别 | 定了 |
| 全片一套定妆图和商品图，真人审核最先做 | 定了 |
| 镜头卡、代码拼提示词、出片前后的核对 | 定了，字段和模板在实验里调 |
| 还原基准 | 定了 |
| 所有首帧过了检查才出视频 | 定了 |
| 按原片时间线合成，字幕后期加 | 定了 |
| 一次生成包含哪些镜头（8.6） | 等实验 |
| 用首帧模式还是全能参考（8.6） | 等实验 |

### 8.2 复刻工程

一次复刻是一个存在服务端的结构化对象，不再是一次性拼出来的一串步骤。

```
复刻工程
├─ 原片：时长、分辨率、帧率、音轨
├─ 人物和商品（每项一个编号）
│   ├─ 原片里最清楚的一帧、出现在哪些镜头
│   ├─ 几种样子（如 正常 / 炸毛 / 稀疏），各出现在哪些镜头
│   ├─ 换不换、换成用户的哪张图
│   └─ 定妆图（每种样子一张）或商品图，及其审核状态
├─ 风格说明：全片统一的画质、光线、色调
├─ 镜头（按原片顺序，起止时间由算法定）
│   ├─ 原片首帧、尾帧、这一段原片
│   ├─ 镜头卡（8.5）
│   └─ 首帧图：候选、选中的、检查结果
├─ 生成任务（一次生成，覆盖一个或几个镜头）
│   ├─ 覆盖哪些镜头、用的模式、参考素材、拼出来的提示词
│   └─ 视频候选、检查结果、重出次数、每个镜头从哪一秒裁到哪一秒
└─ 成片：合成记录
```

镜头和生成任务分开，是为了不管实验定下哪种生成单位，结构都不用改。

每个镜头、每个生成任务有自己的状态。任何一步停下（等审核、等排队、服务重启）都从那一步接着做，没有「总时限到了整条作废」。

导演台的作品已经是服务端结构化对象，有资产、形态、分镜图、导出。实现前先评估哪些能直接用（资产和形态、合成最可能），不要另写一套并行的。导演台的片段是一次多镜的，这部分不能照搬。

### 8.3 流程

| 步骤 | 做什么 | 花什么 |
|---|---|---|
| 0 受理 | 用户的人物图送真人审核；读原片信息。审核不过就停 | 不花钱 |
| 1 拆原片 | 切镜、抽帧、人脸建档、语音识别、文字识别；视频理解模型看全片定人物商品表、几种样子、看点、风格说明 | 文字 |
| 2 定样子 | 定妆图、商品图，送审 | 图片 |
| 3 填镜头卡 | 每镜测量 + 模型看着这一镜填 + 另一次调用核对 | 文字 |
| 4 出首帧图 | 每镜一张，检查不过重出。**全部过了才往下走** | 图片 |
| 5 出视频 | 按生成任务出，逐镜和原片对比，按差别改提示词重出 | 视频 |
| 6 声音和合成 | 按原片时间线排，加字幕、标题、配乐 | 不花钱或少量 |

第 2 步和第 3 步互不依赖，同时做。

#### 第 1 步的细节

- 切镜用现有的 `scdet`，切点以它为准。
- 人脸建档：对抽出的帧做人脸检测和聚类，得到原片有几个人、每镜有谁、各在什么位置。人数按单帧里看得见的人算。
- 语音识别给出逐句文字和起止时间，对到镜头和说话的人。听不清的标出来，不编。
- 文字识别找出烧录字幕、顶部标题（后期重新加）和商品上的字（要保留）。
- 视频理解模型只定全局的事，提到人和物只能用编号。

#### 第 2 步的细节

- 要换的人物：脸照用户的图，服装发型照原片最清楚的一帧。有几种样子出几张，后面几张以第一张为依据只改变化的部分。
- 不换的人物（本片的收银员）也要一张，依据是原片那一帧。
- 商品：用户给了替换图就用它；没给就从原片最清楚的一帧裁出来。
- 每张出 2–3 张候选，挑和依据最像的。
- 用户的约束（「不要丑化」）落在定妆图上：只改发型，脸保持好看。任务页告知一句「原片的看点是女主头发越变越糟，按你的要求只改发型」，不等确认。

#### 第 4 步的细节

- 输入：这一镜的原片首帧（定构图）+ 画面里每个人的定妆图 + 商品图。文字只说「把谁换成哪张图的样子，其它不变；去掉平台水印和烧录字幕，商品包装上的字保留」。
- 同一场景的连续镜头，多带一张前一镜已选中的首帧，保持道具和背景一致；换场景时不带，避免小错一路累积。
- 检查：人脸和定妆图像不像、构图和原片首帧像不像（算法）；商品、样子、有没有多余的字（视觉模型）。不过重出，最多两次。

### 8.4 镜头里图表达不了的东西

首帧图只管第一帧。下面几种情况要额外处理，否则只能靠文字硬写：

| 情况 | 例子 | 做法 |
|---|---|---|
| 人或物中途才入画 | 结尾女主举起洗发水；商品特写里第二只手伸进来 | 这一镜必须带上它的参考图（只能用全能参考），镜头卡里写明从哪边、第几秒入画 |
| 镜头内样子有大变化 | 一镜之内头发变样 | 本片的变化都发生在切镜处，不涉及。遇到时在变化点把镜头拆成两个生成任务，后一个用变化后的首帧 |
| 单个镜头超过模型上限 | 15 秒以上的长镜头 | 拆成几段接着拍，后一段的首帧取前一段的最后一帧 |
| 镜头很短 | 0.7 秒的反应镜头 | 生成 4 秒，提示词写明动作一开始就发生，裁开头一段；裁出来动作不完整算不合格 |

### 8.5 提示词怎么还原原片

这是分镜复刻的核心，分五层。

#### （1）图管样子，字只管变化

有了首帧图，人物外貌、服装、场景、构图、光线都在图里，提示词不再重复，重复了反而和图冲突。提示词只写这一镜在时间上发生了什么：

- 镜头怎么动（固定、推、拉、摇、跟，幅度和快慢）
- 人怎么动：从什么状态到什么状态，按先后分成几拍
- 表情怎么变
- 谁说哪句话
- 有什么声音
- 结束时停在什么画面

一镜几十到一百多字。

这条成立的前提是视频模型严格从首帧开始。如果实验定下用全能参考（首帧只是建议），提示词要补回一句构图说明，由模板统一加，不是回到写散文。

#### （2）一镜一张镜头卡

提示词不直接写成一段话。先填结构固定的镜头卡，再由代码拼。

```
镜头卡
├─ 测出来的（代码填，模型不能改）
│   ├─ 时长
│   ├─ 画面里有谁（编号）、各在左中右哪边
│   ├─ 景别（按人脸占画面的比例算）
│   ├─ 台词：谁说、原文、起止时间
│   ├─ 画面上的字：烧录字幕、商品标签
│   └─ 后续再加：镜头运动类型、关键物件的颜色
├─ 看出来的（模型填，每一项都要能在画面上指出来）
│   ├─ 镜头运动
│   ├─ 动作节拍：[{第几秒到第几秒, 谁, 做什么, 从什么状态到什么状态}]
│   ├─ 表情变化
│   ├─ 中途入画的人和物：谁、第几秒、从哪边
│   ├─ 声音：音效
│   ├─ 结束画面
│   └─ 这一镜的看点（没有就空）
└─ 拿不准的（模型列出来，不许硬填）
```

- 测量分两批做。第一批用现成的东西就能得到：时长、人脸位置和大小、语音识别、文字识别。第二批（用画面位移判断镜头运动、对物件取色）要多做一些工作，先由模型填，基准上发现这几项经常错再补测量。
- 模型填的每一项对应画面上能看到的东西。看不清的写进「拿不准的」，拼提示词时不写。
- 人和物只能用编号。写出表里没有的名字（「香水瓶」）判格式错误重填。
- 镜头卡只描述原片。「把 P2 换成用户的人」不在这里处理，拼提示词时 P2 指向它的定妆图。还原和替换分开，各自能单独验证。

#### （3）填卡的模型看着这一镜

一镜一次调用，输入是这一镜的原片片段、带时间标记的帧网格（每秒 6–8 帧）、测出来的事实、人物商品表。看的模型直接填卡，中间没有第二个模型转述。15 次调用并发。

填完由另一次调用核对：给它原片这一镜和填好的卡，只问两件事：卡里哪一项在画面上找不到依据；画面里哪件显眼的事卡里没写。有出入就改卡。这一步只花文字的钱。

#### （4）代码按模型的写法拼提示词

- 每个视频模型、每种模式一份模板，放提示词库。固定的部分（风格说明、身份说明、「不要出现字幕和文字」、「不要配乐」）一字不变，槽位只放镜头卡里的内容。
- 一次生成包含几个镜头时，模板按镜头顺序把几张卡排进去，写法相同。
- 模板的依据是模型的官方写法说明和实测。H3 已有官方写法（`resources/h3-skill`）；Seedance 要补，可参考 hypit 的 `packages/seedance-kits`。
- 镜头运动这类词各模型认的说法不同。建一张小词表（「慢推」在这个模型里怎么写），写法在基准上确认模型照做。
- 台词原文逐字放进去。

这样出了问题能定位：是哪张卡的哪一项填错了，还是模板哪一句不管用。

#### （5）验证

**每次任务：**出片后，生成的镜头用同一套测量再测一遍（时长、人数位置、景别、台词转写），和原片的卡逐项比；再把原片和生成的镜头在相同时间点各抽几帧并排，让视觉模型逐项说哪里不一样。差在哪一项，就改那一项的写法再出，不是原样重试。最多两轮。

**离线：还原基准。**找 20–30 个有代表性的原片镜头（对话、手部特写、商品特写、运镜、快切、多人），做纯还原：不换任何东西，看流程能把这一镜还原到什么程度。

评分先做简单的，够用再加：

- 第一版：视觉模型拿原片和生成结果并排，按镜头卡逐项判「一致 / 不一致」，得出每项的一致率；加上时长、人数位置、台词转写这几项算法比对。
- 之后按需要加：相同时间点的帧相似度、人体关键点轨迹对比。

以后改镜头卡字段、改模板、换填卡的模型、换视频模型，都先在基准上跑，一致率涨了再上线。

基准还回答一个问题：纯还原都做不像的镜头类型，换人以后只会更不像。那类镜头要换做法（带原片片段做动作参考），或者在任务页说明还原度有限。

### 8.6 一次生成包含哪些镜头、用哪种模式（等实验）

候选做法，实验里逐个跑：

| 做法 | 好处 | 问题 |
|---|---|---|
| A 一镜一次，首帧模式 | 首帧严格；镜头内没有切镜 | 贵 2.2 倍；不能带定妆图、商品图、声音样本；中途入画的东西只能靠字 |
| B 一镜一次，全能参考（这一镜的首帧图 + 定妆图 + 商品图 + 声音样本） | 身份、商品、声音都有依据 | 贵 2.2 倍；首帧只是建议。只给一张首帧、只拍一镜时模型听不听，没测过 |
| C 同机位、同样子的镜头一条拍完再剪，全能参考 | 约 1.4 倍；同机位的镜头本来就该是一条素材，道具状态自然连贯 | 要在生成的那一条里找到每个镜头对应的那一段，台词可以靠转写定位，没有台词的动作不好定位 |
| D 相邻 2–3 镜一组，全能参考 | 约 1.1 倍；参考名额宽裕 | 切镜又交回给模型 |
| E 全能参考再带原片这一段做动作参考 | 动作和运镜不用靠文字还原 | 模型可能把原片的人、字幕、水印也带过来（H3 实测会）；原片里有真人时过不过审核没测过 |

E 不是分镜复刻的做法，是现有「元素替换」的思路。把它放进实验是为了有个对照：如果带原片片段的效果明显好于任何靠提示词还原的做法，分镜复刻就应该只用在原片不能交给模型的场合，产品上要调整两种方式的推荐规则。

### 8.7 声音（等实验）

逐镜或逐组生成带来两个新问题，现在一次出 14 秒时不明显：

- **同一个角色，每次生成的声音可能不一样。**
- **配乐不能让视频模型配。** 每次生成各配各的，接起来是断的。

做法：

- 提示词里固定写不要配乐。配乐在合成时加：从原片分离出来沿用，分离不干净就按原片的风格另配。
- 角色声音的候选做法，实验里比：
  1. 全能参考带这个角色的声音样本（从原片里他说话的几句截出来）。只有全能参考能用。
  2. 视频模型出无声或随意配音的画面，台词另外用固定音色合成，再对口型。配音和对口型的链路已经有（`StudioSpeechService`、`DAP_LIP_SYNC`），多一步花费。
- 字幕时间按**生成结果**的语音识别来定，不按原片的时间。原片那句话在第 3.2 秒，生成的可能在第 3.5 秒。
- 检查里加一项：这一镜的台词在裁出来的那一段里说完了没有。没说完算不合格。

### 8.8 检查和重出

| 检查什么 | 怎么查 | 不过怎么办 |
|---|---|---|
| 首帧图：人对不对 | 人脸相似度 | 重出这张图 |
| 首帧图：构图、商品、多余的字 | 构图相似度 + 视觉模型 | 重出这张图 |
| 视频：镜头内有没有多出来的切镜 | 切镜检测 | 重出这次生成 |
| 视频：人对不对 | 每镜抽 3 帧算人脸相似度 | 重出 |
| 视频：动作、镜头运动、商品 | 和原片的镜头卡逐项比（8.5 第 5 层） | 改对应那一项的写法再出 |
| 视频：台词说完没有、说对没有 | 语音识别 | 重出 |

- 每处最多重做两次。仍不过的镜头标记出来，成片照出，任务页说明哪一镜没达标。不整条作废，也不悄悄放过。
- 人脸相似度的线要和火山真人审核的 `FaceMismatch` 对齐：我们判像而它判不像，这张图交不出去。线在实验里定。
- 没有脸的镜头（手、商品、背影）不做人脸检查，靠视觉模型。

### 8.9 合成

- 按原片的切镜点排，每镜裁到原片的时长。
- 字幕按生成结果的语音识别时间加；顶部标题重新加；配乐加上；音量统一。
- 每个镜头都选定之后自动触发，不依赖前面的流程还在不在跑。

### 8.10 和现在的做法对比

| | 现在 | 新设计 |
|---|---|---|
| 原片谁来读 | 模型描述一切 | 能测的算法测，模型只补动作和表情 |
| 提示词谁写 | 没看过原片的模型写一大段 | 看着这一镜的模型填镜头卡，代码拼 |
| 提示词写什么 | 外貌、场景、动作、台词全写 | 只写时间上的变化 |
| 提示词准不准 | 没有验证 | 出片前核对，出片后逐项比，离线有基准分数 |
| 人物依据 | 每张图各自换脸 | 全片一套定妆图 |
| 切镜 | 模型决定 | 算法定，合成时裁 |
| 一次生成多少 | 十来个镜头 | 实验定，结构上不限 |
| 一处坏了 | 整段重出 | 只重做那一处，并且改了写法再出 |
| 中途停了 | 整条「部分完成」 | 从停下的地方接着做 |
| 花钱的顺序 | 图和视频连着出 | 所有首帧过了才出视频 |
| 配乐 | 视频模型顺带配 | 合成时加 |

## 9. 风险和还没想清的地方

| 风险 | 影响 | 怎么处理 |
|---|---|---|
| 每张含真人的图交给火山都要过审，生成的脸和已核验的人像不够像会被判 `FaceMismatch` | 首帧图一多，被拦的概率变大，这次 13 张里就有 4 张 | 首帧图先自己算人脸相似度，过线才送；线和火山的对齐。实验里统计通过率 |
| 原片里的人如果是真人，「不换的人物」的定妆图和纯还原基准可能过不了审 | 收银员这类不换的角色没法照原样出；基准做不了 | 实验第一步先核实。过不了的话，不换的人物改成「照原片的样子重新设计一个不是同一个人的角色」，基准只用非真人的原片或已授权的素材 |
| 人脸模型的许可 | InsightFace 的预训练模型只许非商业用途 | 选型时确认许可，备选火山或阿里的人脸比对接口 |
| 超短镜头裁出来动作不对 | 本片 5 镜不到 1 秒 | 实验里专门看；不行就走做法 C 或 D |
| 做法 C 里定位镜头对应哪一段 | 没台词的动作镜头不好切 | 实验里看能不能靠动作节拍的提示词顺序加切点检测解决；不行这类镜头单独生成 |
| 快切、卡点类原片 | 0.3 秒级的镜头，逐镜生成不现实 | 这类原片不适合分镜复刻，受理时按切镜密度判断并提示，或走别的方式 |
| 成本和时间上升 | 调用次数从十几次到五六十次 | 并发；实验给出每种做法的实际花费和耗时，由产品定上限 |
| 镜头卡的测量做重了 | 运动估计、物件取色工作量不小 | 分两批，第二批看基准结果再决定做不做 |

## 10. 动工之前先做实验

用这条原片和两张人物图，手工跑，不写产品代码。按顺序做，前面的不过后面的不用做。

**先核实（半天，不花或少花钱）：**

- 首帧模式和全能参考在线上的实际限制和第 6 节是否一致；首帧模式的输出有没有声音。
- 原片截图里的人（收银员）交给 Seedance 会不会被真人审核拦；拦的话 asset 引用怎么处理不换的人物。
- 全能参考的声音样本起什么作用：定音色，还是只当背景。

**实验：**

| 实验 | 做什么 | 看什么 |
|---|---|---|
| E0 纯还原 | 挑 6 个不同类型的镜头，手工填镜头卡，按模板拼提示词，首帧用原片首帧，出片 | 镜头卡加首帧能还原到什么程度；哪类镜头不行。再让模型填同样 6 张卡，和手工的比 |
| E1 定妆图 | 男主 1 张、女主 3 张、收银员 1 张、商品 1 张 | 同一个人的几张是不是一张脸；三档发型清不清楚；过不过审 |
| E2 首帧图 | 15 镜各出首帧 | 和原片首帧并排看；人脸相似度能不能把好坏分开；送审通过率 |
| E3 生成单位 | 同一批首帧，按做法 A、B、C、D 各出全片 | 人物商品一致性、镜头还原、超短镜头、实际花费和耗时 |
| E4 对照 | 做法 E（带原片片段）出全片 | 和 E3 里最好的那个比 |
| E5 声音 | 声音样本参考和「另配音加对口型」各做 3 镜 | 同一角色声音是否一致，口型，花费 |
| E6 总对比 | 客户那条成片、第 12 节小改后的现流程、E3 最好的、E4，四条并排 | 改善有多大 |

估算花费：E3 四种做法的视频合计约 1.2 万积分（3720 + 3720 + 2400 + 1800），加上 E0、E4、E5 和出图，总共约 2 万积分。想省就先只跑 B 和 C。

**判定：**

- E0 里多数镜头类型能还原 → 镜头卡这条路成立，继续。只有个别类型不行，记下来单独处理。多数不行 → 靠提示词还原这条路在当前模型上走不通，停下来重新评估（换模型，或改走带原片片段的做法）。
- E3 里选一致性和还原度最好、花费在产品接受范围内的做法作为生成单位。
- E4 明显好于 E3 最好的 → 调整产品上两种方式的推荐规则，分镜复刻仍按本方案重构，但不再是「只换人」这类需求的默认方式。

## 13. 验收

固定样本：这条原片和两张人物图，另加两条不同类型的原片（单人口播、商品展示）。

| 检查 | 通过标准 |
|---|---|
| 还原基准 | 各项一致率不低于实验选定做法时的水平；以后每次改动不下降 |
| 男主、女主 | 每镜抽 3 帧，和定妆图的人脸相似度全部过线；人工看对照图是同一个人 |
| 女主的三档发型 | 在对应镜头出现，区别清楚，脸好看 |

| 镜头 | 镜头数和原片相同，切点偏差不超过 2 帧 |
| 台词 | 每句都说完整，转写和原文一致；同一角色全片一个声音 |
