# Studio 导航与内容组织定稿

确认日期：2026-10-16。后续更新：用户将「项目」加入首页之后的一级菜单，并要求创作能力以图像卡片平铺；当前本地实现与验收以顶部链接为准。

按本定稿制作的图片见 [关键页面设计稿](studio-v3-design-review.md)，覆盖完整一级导航、场景工坊、我的 IP 列表与详情、就地选择及发行各页面。图片设计不代表功能已实现。

本文件记录用户最终确定的导航、IP 合并前提及后续扩展规则。它替代此前将带货和分发各自增加为一级菜单的临时方案。线上现状与本方案的差异见 [现有页面核对](studio-commerce-current-page-audit.md)；开发拆分见 [任务清单](studio-commerce-development-tasks.md)。

## 一级导航

**首页｜项目｜画布·自由创作｜场景·专项创作｜灵感｜资产｜发行**

菜单文本使用用户确认的完整写法。「场景·专项创作」进入后的页面标题为「场景工坊」。不自行把一级名称改成“应用”“带货专区”“造物间”或“全网分发”。

| 入口 | 职责 | 路径安排 |
|---|---|---|
| 首页 | 了解能力、继续最近工作 | 保留 `/dashboard` |
| 项目 | 管理已有个人画布，搜索、筛选与继续创作 | `/projects` 独立管理，画布编辑返回该页 |
| 画布·自由创作 | 原“创作”，自由搭建的通用画布，功能和路径保留 | 保留 `/create`、`/projects/[id]`，不因改名迁移已有画布 |
| 场景·专项创作 | 剧情带货、爆款复刻、短剧、音乐等创作起点，背后复用模板画布 | 建议新增 `/scenes` 为场景工坊入口，显式创建个人副本后打开原 `/projects/[id]` |
| 灵感 | 原“模板管理”，官方模板、我的模板、精选案例，用于找参考、做同款 | 保留 `/templates`，调整用户界面名称与内容组织 |
| 资产 | 管理 IP、图片、视频、声音、创作素材 | 沿用 `/assets`，合并原 `/ips` 的完整管理内容 |
| 发行 | 矩阵账号、发布准备、发布记录，各类成片共用 | 建议新增 `/distribution` 及其草稿、账号、记录子页 |

`/scenes`、`/distribution` 及细分参数仍是待实现的路径设计，不代表当前已存在。场景和发行各增加一个入口，IP 与模板的原职责分别合并、改名，后续反馈已将「项目」加入首页之后，最终共七个一级入口。

## 命名原则

名字说清用户的目的。品牌感放到页面视觉和副标题里，不放进菜单名。

画布保持自由创作，场景提供按目的组织的模板画布入口；灵感负责找参考与做同款，资产负责管理已有内容，发行负责把作品交给目标渠道。不要把“灵感”变成另一套制作工作台，也不要将发行账号藏在某一个场景内。

## IP 并入资产的三个前提

1. **「我的 IP」放在资产第一位，并作为默认打开的分类。** 裸路径 `/assets` 打开“我的 IP”；用户显式选择或通过深链访问其他分类时尊重该目标，不强制跳回默认分类。
2. **IP 详情保持完整。** 包含人物设定、形象版本、关联声音和相关作品。继续复用原 IP 的身份、版本和关联关系，不能将 IP 降成普通图片卡或创建第二份人物档案。
3. **场景与画布选角色时，直接弹出「我的 IP」。** 不先跳到资产页。选择后回到原输入、原草稿和原视口，引用精确的角色/形象/声音版本，不复制人物。

资产分类建议顺序为「我的 IP / 创作素材 / 生成与上传 / 声音」。这只是内部分类细化建议；用户已确认的强制条件是“我的 IP”第一且默认，以及完整详情和就地选择。当前“人物形象”页签不再与“我的 IP”重复展示同一份人物管理；形象图片仍可作为该 IP 的具体素材被查看和引用。

当前 `/ips` 是列表加详情交互，不存在独立 `/ips/[id]` 页面。实施时保留旧 `/ips` 与其已有参数的兼容入口，映射到资产里的 IP 视图；不能只改顶栏链接就删除原详情能力。现有 `/assets/[id]` 的个人资产详情也不能冒充 IP 详情，两类对象继续区分。

顶栏“搜索 IP”、首页相关链接、画布人物选择器及旧深链均需纳入检查。视觉上合并入口，不改变底层 IP、素材、声音和任务的归属。

## 场景扩展：同一个画布，不同起点

```text
场景·专项创作
└─ 场景工坊：按目的开始
   ├─ 剧情带货：商品参考 + 植入要求 + 剧本
   ├─ 爆款复刻：参考内容 + 拆解要点 + 改编要求 + 剧本
   ├─ 短剧制作：故事 + 角色 + 分集剧本
   └─ 音乐创作：创作要求 + 歌词 + 音频
        ↓ 显式使用模板，免费创建个人画布副本
      原生画布 / 故事板 / 成片
```

这些入口背后都是模板画布。模板说明放什么、怎么连接、下一步做什么，帮助用户上手；进入后可自由增删节点，不受场景锁定。创建的副本统一在“项目”管理，不另建带货项目、爆款项目、场景项目表或专项进度系统。后续增加能力时扩展场景目录和模板，不再加一级菜单。

剧情带货的核心是把商品拖入画布，作为剧本的参考：选择段落或场景，输入替换/植入要求，预览改稿，用户采纳后继续原制作链。已有画布也能直接使用商品，无须从场景入口重建。商品选择和 IP 选择均在画布内完成。

爆款复刻与其他几项并列。模板包含参考内容、拆解要点、改编要求和创作节点；用户补入参考视频、截图或文字，确定要借鉴的结构和需要改编的内容。模板打开不代表已分析视频、生成剧本或制作成片，分析能力按实际支持范围接入。

场景与灵感可引用同一模板源：场景按创作目的组织少量明确起点，灵感供浏览更多模板和案例。预览只读；点击“开始创作”才创建个人副本，不自动生成、不自动扣点。原“IP 商品视频”模板的预览与存副本行为保留。

尚未接通的短剧、音乐入口如实显示后续接入；已有通用图文节点可以承载构思，并不等于已完成音频生成或发行适配。

## 发行边界

发行对各类成片开放，直接选择本人可用成片。需要商品时，显式选择该作品使用的商品参考快照，普通视频商品可空。视频首期复用平台分发链，音乐音频的发行、版权和渠道接入后续单独适配。

画布原有“发布”为 IP 资产登记，“发布为模板”为创作配方保存。两者保持原业务含义；发行的“发布准备”“发布记录”独立于画布“已发布”状态，不能混用统计和结果。

首期仍是独立发布草稿和手动发布出口，自动发布按实际平台能力分批开放。叫“发行”不代表所有渠道已接通。

## 后续调整的条件

若 IP 将来拥有独立运营能力，包括绑定发行账号、人设内容规划、数据分析，再评估将“我的 IP”升级回一级入口。此前不因人物素材变多或单一详情页增加字段就重新拆出一级入口。

## 设计与验收约束

- 桌面完整展示七个一级入口，保留现有品牌、搜索、积分和账号区；不得为了容纳长标签偷偷截断、简写或改成另一组名称。
- 原画布功能、路由、节点、连线、三种制作视图继续使用现有能力，导航改名不触发收费或数据迁移。
- `/assets` 默认“我的 IP”；角色详情包含四类完整内容；深链、刷新和浏览器返回都能恢复正确对象。
- 场景和画布内直接选角色，取消和选完都回原流程；不绕行资产页，不丢草稿，不偷偷改人物默认版本。
- “灵感”页保留现有模板的只读预览和显式保存个人副本；精选案例和模板可区分，不把当前待建设的社区内容包装成已上线。
- 手机导航需按现有真实页面另做布局校验，不直接增加六个底部 tab，也不静默修改已确认菜单名。现有 `data-layout` 选择规则继续生效。
- 所有旧概念图均不作为本定稿的页面验收依据；下一版设计必须先呈现这套完整导航，再画各入口内的页面。
