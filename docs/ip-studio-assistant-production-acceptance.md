## 真实流程

1. 从空白画布打开 AI 创作。快捷入口填写可编辑需求，显式发送后由 Qwen3.6 输出三步方案与可直接采用的角色正文，实际消耗 1 积分。
2. 未采用文字时图片步骤提示前置文案且不能创建。修改正文后免费采用为普通文字节点；未再次调用模型。
3. 图片步骤创建新节点，连入已采用文字，生成面板读取修改后的完整正文。ERNIE 生成真实 3:4 角色全身图，消耗 30 积分。
4. 刷新后原对话、编辑后的正文、图片、采用绑定均保留。视频步骤引用实际图片节点，首帧 key 精确等于图片产物 key。
5. 手动确认首帧、768p、9:16、1 条、5 秒及 200 积分报价，提交 Minimax H3。生成期间刷新继续查询同一任务；成片在节点中实际播放，文件下载成功。
6. 最终修正版再次刷新并从助手“打开节点继续创作”：复用原视频节点，保留首帧/时长/模型/费用，结果卡和参数区均不再错误要求补选参考。未重新生成、没有额外扣费。

## 验收发现与修复

模型在 `dependsOn` 已声明图片前置步骤的同时，把同一步骤 ID 重复放入 `referenceNodeIds`。旧隔离逻辑把它当作未知画布引用，导致已经正确连接图片却仍显示“补选参考”。

后端只剥离明确声明且确实位于前面的重复依赖；未知名称保持待用户解析。前端兼容已保存的旧方案，在结果卡、创建/重新打开生成面板与采用后的保存中统一消除该重复标记。新增回归覆盖未知名称不被吞掉、后续步骤不被误识别、原节点复用且不再次提交付费任务。
