# Studio 图片上传与模型 404 修复

2026-10-16，已生产发布。仅更新 server / web-aiavatar；工作区并行进行的导航、场景与发行页面改动未包含在产物中。

## 用户报错与原因

- 图片节点上传报“图片不能超过 8 MB”：前端直接拦截相机原图，没有自动处理。服务端图片附件仍要求不超过 8 MB。
- 任务 `IPR-fbd0ef66c25f47299dc5`，追查号 `7DYWYDRSMR2J`：助手请求使用旧 `qwen3-6-35b-a3b`，供应商返回 HTTP 404 / `not_found` / `resource not found`。最新 `/v1/services` 目录已没有该模型；不是超时或用户文案错误。
- 原任务失败时冻结的21积分已全部释放，任务 cost=0。修复没有重放原任务、改写历史或再次退款。

## 最终行为

JPG/PNG 原图最多50 MB。共享上传接口在超过8 MB时，在浏览器生成不超过8 MB的版本；最长边先限制4096，再按需缩小。小图保留原字节；PNG继续使用PNG以保留透明背景。节点替换、附件与素材入口共用处理函数；本机原文件不改写，解码/处理失败不发上传请求。

Studio 固定文本模型切换到新端点 `ai-studio-jusuan-qwen38` / `qwen38-27b`，仅对 Studio 开放。旧端点和历史任务保留；声明视觉能力，按供应商合同配置不支持的聊天参数为false，输出预算继续8192。新端点沿用原客户端费率：输入0.18、输出1.08积分/千Token；没有增加客户售价，也没有将旧供应商核价说明冒充新供应商报价。

全片解析和逐段拉片继续复用同一场景模型。候选的 `max_ref_images=9` 来自当前供应商合同；分段规划和逐段分析按该配置控制单次图片数量，保留片段首尾证据。避免旧的每段12图超过新模型9图上限。旧候选没有配置时沿用6图预算，不按模型名字写死。

上游404仍保留 `AI_CALL_FAILED` 稳定错误码，但新任务会明确提示“当前模型服务不可用（HTTP 404），请联系管理员更新模型配置”，不再让用户盲目重复重试；供应商原文和机密不显示给用户。
