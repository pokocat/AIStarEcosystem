## 统一选择器的业务语义

所有入口先按人物浏览，再进入同一素材详情。选择精确 ipId/avatarId/version/lookId/storageKey；画布导入同时保留人物默认声音的 voiceId 快照。不是按同名、最新形象或第一张素材隐式替换。

- 工作台人物库和底部人物图标：添加素材节点并聚焦。
- 节点参考中的“IP 人物”：添加素材节点、连接到当前节点，再恢复该节点输入。失败保留选择界面；恢复保存复用原节点。
- 创作要求/商品视频：使用相同选择器，确认后回填当前参考或出镜人物，保留表单。
- 模板输入：使用相同选择器，确认后回填该输入槽，不提前创建画布、不自动生成；改变输入使旧制作计划失效。

手机将商品视频收到“更多创作”，保留人物库和 AI 创作入口可见。画布工具横向滚动，不把缩放或提交按钮盖在编辑工具上。手机继续遵循 html[data-layout]，不会绕过用户选择强切桌面版。
