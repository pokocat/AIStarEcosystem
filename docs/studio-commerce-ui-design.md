# Studio 页面与画布创作设计

状态：设计稿与后续实施规格；本轮不修改业务代码。图片见 [设计评审索引](studio-v3-design-review.md)，架构见 [六项导航定稿](studio-information-architecture.md)，开发拆分见 [任务清单](studio-commerce-development-tasks.md)。

## 本轮设计结论

一级导航保留 **首页｜项目｜画布·自由创作｜场景·专项创作｜灵感｜资产｜发行**。

剧情带货、爆款复刻、短剧制作、音乐创作都是按目的组织的模板画布入口。模板帮助起步，进入后使用同一个原生画布，可以自由增删和连接节点。所有个人副本统一出现在画布列表中。不新增独立带货项目、前置向导、阶段进度或第二套制作系统。

## 场景工坊 `/scenes`

页面标题“场景工坊”，说明“选一个方向，开启新的创作。”。同一层级四张入口卡，不增加独立业务左侧栏。

| 入口 | 卡片说明 | 主动作 | 次动作 |
|---|---|---|---|
| 剧情带货 | 让商品成为故事的一部分。 | 开始创作 | 预览模板 |
| 爆款复刻 | 借鉴出彩的结构，创作自己的表达。 | 开始创作 | 预览模板 |
| 短剧制作 | 从故事构思，到一幕幕成片。 | 后续开放（未接通时） | 接通后再开放 |
| 音乐创作 | 让灵感有词，让情绪有声。 | 后续开放（未接通时） | 接通后再开放 |

卡片下辅助文案：“从这里起步，按你的想法自由创作。”。不在卡片说明里堆砌拖入、连接、路由和模板实现细节。

底部标题“继续创作”，说明“从上次停下的地方，继续。”，展示原画布缩略图、名称、最近编辑时间，动作“继续创作”。不再使用“继续相关画布”“仍是同一份画布，也可从自由创作中打开”等系统解释。

“开始创作”显式使用对应模板，免费创建个人副本；“预览模板”只读，不创建、不生成、不扣点。图中入口可用态是目标设计，不代表功能当前已经上线。已有画布可直接用商品、IP或参考内容，无须重新选择场景。

## 画布内剧情带货

### 商品参考

复用现有素材浮层的使用方式，按需打开“商品”。轻量浮层包括商品库搜索、分类、商品详情、粘贴链接与手动补充，借用 celebrity 的选品查询及抖音链接解析能力，视觉按 Studio 绘制。

点击添加或拖入后，在当前画布创建商品参考。优先使用原生图片/文字节点，保存商品名称、来源、用户核对的事实和素材引用。普通创作者的补充只进本人文档，不写公共商品池。价格、佣金未知时不编造，基本剧本植入不要求这些字段。

用户可先写剧本再加商品，也可先放商品再创作；不强制单商品、先核对卖点、固定阶段或新建业务项目。商品参考连接到剧本，或者由用户在本次改稿中显式选取；只连线不自动发起生成。

### 局部植入与改稿

保留现有剧本节点、全屏编辑器、AI对话和模型/费用确认。在选中场景或段落后输入自然语言要求，例如：“把第2场的纸杯换为这款咖啡杯，通过递杯动作自然出现，其他剧情不变。”

界面只需三项上下文：本次引用商品、修改范围、用户指令。商品事实进入文本上下文；涉及外观理解时才显式使用商品图片。当前编辑器改稿请求尚未装配商品上下文，后续必须适配实际请求链，不能只画连线。

先展示AI版本，再由用户采纳或放弃。沿用当前稿/预览切换、冲突保护和撤销；不覆盖用户生成期间的新改动，不自动重做下游图片和视频。模型失败保留原稿及要求；已受理而查询失败时继续查原任务，避免重复提交。

原“发布”仍是IP资产登记，“发布为模板”仍是模板保存。可用成片增加独立“准备发行”动作。

## 爆款复刻的模板画布

与剧情带货平级，不另建复刻项目或采集后台。预置参考内容、拆解要点、改编要求、剧本/分镜节点。用户补充视频、截图或文字后，明确借鉴的节奏、结构与表达方式，以及自己的主题、角色和素材。

模板本身不承诺已自动拆解视频。第一版可以人工填写拆解要点，并复用已支持的文字/图片参考；视频分析按实际模型支持范围接入，不能把现有抽帧阅读宣传成逐秒全视频理解。生成仍是用户显式操作。

场景按目的推荐少量模板，灵感按模板和案例浏览，两者引用同一模板源。预览与个人副本行为一致。

## 资产与我的 IP

`/assets` 第一且默认页签为“我的 IP”，其他分类可用明确深链进入。复用原IP列表、状态筛选、标签、搜索和视图切换，不把IP降成普通图片，不建立第二份人物数据。原 `/ips` 和查询参数保留兼容。

详情继续在原管理交互中打开，提供人物设定、形象版本、关联声音、相关作品。现有 `/assets/[id]` 普通素材详情不能冒充IP详情。没有声音时如实说明，不补造试听。

画布里打开“我的 IP”选择器，直接选择人物、精确形象/声音版本后回到原节点，保留草稿与视口。选择器背景是原画布，不再是独立带货建项表单。取消不清空原输入。

## 发行

发行对所有本人可用成片开放，商品可空。页面与原Studio普通页面共用品牌外壳，页签为发布准备、矩阵账号、发布记录。图中的“剧情带货”等是创作方向提示，不引入独立业务项目实体。

发行首页选择已有成片或继续草稿。准备页左侧预览明确版本的视频，右侧编辑标题、正文、话题、目标账号与意向时间；主动作“保存草稿”。账号、时间和标题未完成仍可保存，完整性提示与保存动作分开。

草稿独立持久化，不调用现有创建即排队的PublishJob接口。保存成功不等于发布成功，计划时间不触发调度。先提供下载视频、复制文案/商品链接的手动出口；真实绑定、发布和回执按平台分期开放。

矩阵账号复用当前用户已有账号与真实状态。未接通的绑定或续期如实显示；无账号仍可保存草稿。记录区分别呈现草稿与平台任务，只有真实回执才能显示已发布，下载/复制不能产生成功记录。

商品挂载是渠道能力，不因剧本里有商品就假定可以挂载。准备发行时显式选取适用商品和当次文案，不把当前画布最新商品静默挂到旧成片上。媒体保存稳定key，执行时按需重签。

## 状态与验收

- 模板预览不创建项目；开始创作创建可保存、可自由修改的原生画布副本，统一出现在原列表。
- 商品可从库、链接、手动内容进入；解析失败保留原输入，导入图片失败可补图，不伪装已引用成功。
- 既有普通画布无需重建即可植入商品；选区、商品引用和改稿要求实际参与生成；采纳前不覆盖正文。
- 生成期间用户继续编辑时保护新稿；换商品不自动重跑，所有生成与计费使用原规则。
- 资产默认我的IP，详情四部分完整；就地选择不绕行资产管理页。
- 发行草稿刷新恢复且无派发/扣发布费；真实任务和外部状态单独验收。
- 桌面保持原视觉和工具结构；手机单独按现有 `data-layout` 规则设计，不直接塞六个底部tab。本批只交付桌面图片。
