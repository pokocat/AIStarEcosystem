# Studio 助手与画布引用

2026-10-08 · v0.209 / v0.214 / v0.215 / v0.216 / v0.217 · 本地实现，未发布。

这一增量保持 Studio 的纸白、群青与麦黄，补齐助手的引用、故事导入和对话恢复。2026-10-08 在已登录 LibTV 的已有画布中核对：TV Director 支持 `@` 节点选择、感知画布、历史对话，附件入口提供本地上传与素材库添加。本次没有向 LibTV 发送消息或上传文件。

## 已实现的操作

- 输入 `@` 后按名称筛选画布节点；上下方向键选择、Enter 确认、Escape 关闭候选。选择结果绑定节点 ID，重名人物不会只按标题回溯。
- 引用节点与感知画布使用同一引用列表。最多 16 项，重复选择不重复发送；引用标签可移除。超过 16 项的感知画布会明确提示只加入前 16 项。
- 添加故事支持 UTF-8 的 TXT / Markdown（256 KB 内）及 PDF / Word DOC、DOCX（8 MB 内）。单份正文不超过 24000 字，PDF 不超过 100 页。正文成为可编辑文字节点并加入引用，先保存画布，再参与助手对话；导入免费，不提交助手消息。
- PDF / Word 由本人画布的免费接口提取正文，不保存原附件。无文字层 PDF、密码保护、限制文字提取、损坏及超限文件明确报错；读取期间锁定输入，失败保留原想法与引用。没有 OCR，不执行宏、链接或嵌入对象。
- 历史对话恢复原模式、模型和精确引用。节点已删除时显示缺失项，移除或重新选择后才能发送。保存失败保留附件节点与引用；v0.216 提供“重试保存附件”，确认保存后才能发送。
- 任务未完成时锁定本轮输入，恢复使用原请求与费用上限。建议仍须确认参数及费用，不直接执行生成。
- 明确的提交前拒绝（上下文超限、引用缺失等）恢复本轮草稿、可编辑引用和之前的对话。保存失败且尚未提交也恢复草稿；网络超时或受理结果未知时保留锁定与原请求编号，通过“确认原对话任务”继续确认。
- 发送前完整会话作为客户端文档快照保存，和提供给模型的最近 14 条上下文分开。拒绝与刷新后的恢复保留原来最多 16 条可见消息及已有方案；旧任务无快照时只能恢复其已保存的请求历史。
- 助手浮层挂载在共享 Studio 内容容器，避免命中固定顶栏的同名样式作用域。
- v0.215 增加“读取图片与视频画面”。只有后台声明当前模型支持看图时可选；其他模型明确仅读取文字设定。图片传入实际选中候选，60 秒内视频按时间取四帧；不读音轨，也不代表完整连续动作。最多 16 张画面，每段视频占四张。
- 历史恢复原读取方式。新对话过滤选中的对话/制作计划节点，避免把不可引用节点误标为已删除；历史中真正失效的引用仍保留并要求移除。

## 能力边界

当前助手默认模型仍可仅支持文字；v0.215 为后台明确声明的看图模型接通图片和短视频采样。图片最大 8 MiB / 2400 万像素，视频最大 128 MiB / 60 秒，传给模型的 JPEG 长边不超过 768px。图像解码与视频时长检查在 worker 中进行，失败释放原冻结；模型声明、引用存在、归属和帧数预算在冻结之前检查。v0.216 已接通本地媒体附件和多文件导入，v0.217 已接通对话文字快照分享与复制继续。音频理解、完整连续视频理解、Skill / 插件及整张画布分享仍未接通。

原有任务服务、模型白名单、积分冻结与结算、请求幂等和服务端上下文校验继续复用；读取画面不改变平台单次对话价。任务只保存本人素材 key 和读取快照，媒体字节只在调用时转换。用量记录隐去图片内容，后台禁止将这类记录按纯文字重放；仍可用原请求确认原任务。

v0.214 在 Chrome 系统文件选择器实际导入 DOCX、DOC、PDF。DOCX 正文和表格文字落入画布，直接编辑后刷新仍保留；无文字层 PDF 失败时，桌面与手机的原稿引用及未发送草稿不变。四节点、运行 0，钱包和账本前后相同。前端专项 19 项、全量 43 文件 332 项、后端 7 项、构建、类型与契约检查通过，唯一 detector 无发现。见统一验证 §25 和 `.studio-e2e/story-documents/`。

v0.215 一次真实 Agnes 3.0 Flash 调用传入测试图及四帧视频，视频主体被描述，但三色图没有得到有效回答；不把模型输出认作漏传证据，也不宣称图片理解效果通过。用量观测确认五份图片内容块，HTTP 桩测试另验证原字节实际发出且观测脱敏不修改请求。同键重试返回原任务，两项免费预检拒绝与后台重放拒绝不增加费用。仅此调用消费 2 积分，没有出图或出视频。前端全量 335 项通过，最后选择过滤修正的 18 项专项通过；后端 36 项、构建、类型及契约通过。见统一验证 §26 和 `.studio-e2e/assistant-visual/`。

## v0.216 · 统一附件入口（2026-10-08，本地未发布）

“添加附件”提供“本地上传”和“素材库添加”，都进入同一份明确画布引用。可以多选图片、视频、音频及故事，逐项导入，失败文件显示名称和原因，成功项继续保存；正在导入时锁定输入。保存失败保留节点和引用，并提供独立保存重试，不重新上传，不发送付费消息。素材库使用现有云端画布素材，可搜索、按类型筛选、多选和翻页；搜索不清掉选择。已有相同 key 的普通画布节点直接复用，文字按内容复用。最多16项引用，不悄悄丢弃超出的选择。

新增免费 `POST /v1/ip-studio/projects/{id}/media-import`，先验证本人项目，再检查实际文件内容。JPG/PNG 最多8MiB、最长边8000px、总像素2400万；MP4 最多128MiB/60秒、H.264画面/AAC音轨；MP3/WAV/M4A最多25MiB/10分钟，音频不能夹带画面。通过后存入本人 `ipstudio_source`，计aiavatar存储用量，返回短期签名地址。画布文档仍只保留key，读取时重签。音频成为可试听普通节点，画布的“加入我的资产”、资产列表与助手素材库都支持同一音频条目。

上传音频不代表助手听懂音频。当前仍只读取文字设定；视频画面仍是可看图模型下的四帧，不含音轨或全部动作。未发送草稿仅在当前组件保留，不宣称刷新或设备形态重新挂载后恢复；已保存的附件节点可重新引用。

实际验收画布 `IPP-931abf03`：一次多选五个文件，四类有效文件保存，损坏PNG明确失败且草稿保留。库内选择已有图片/音频及新文字只新增一个节点，刷新保留五节点；3秒音频实际播放并通过节点菜单保存，同key素材仍为一个条目。运行0，钱包/账本前后相同，无模型调用。前端45文件345项、后端22项、真实接口生产构建/类型/契约检查通过；保存失败不重传、删除/历史、上限与文件归属由专项测试覆盖。见统一验证§27及 `.studio-e2e/assistant-attachments/`。

### v0.217 · Studio 对话快照分享（2026-10-08，本地未发布）

助手历史旁“分享”仅在完成一轮对话后开放。先保存画布并预览服务端白名单文字快照，再明确创建链接；任何获得链接的人可匿名查看对话和创作建议。V47 新增 `ip_conversation_share` / `ip_conversation_copy`，不修改原画布、素材和积分。24字节随机 token，同内容发布幂等；更新快照撤销旧链接，撤销和源画布删除使公开读取失效。公开 GET 仅豁免精确路径，返回 no-store/noindex；复制和管理保留登录、aiavatar 开通、手机绑定及本人归属检查。

快照不含源节点、素材 key/URL、请求、模型、任务或账号字段，原参考绑定替换为重新选择提示。公开页“在 Studio 中继续创作”将文字与建议复制到本人新画布，创建新节点 ID并直接打开助手，无媒体和执行请求，未自动生成；同 owner/clientRequestId 幂等，浏览器 session 保留复制键以供失败/刷新重试。复制内容仍需显式选择本人参考素材、模型并确认费用。分享后新增消息不会自动公开，未发送草稿不进入快照。

这是 Studio 自有分享闭环；LibTV 当前可见“空对话不能分享”入口，但调研账号无历史，本轮未为探测弹窗调用模型，不能宣称其分享表单的所有行为逐项一致。公开画布与复制、社区展示仍是独立待办。验收见统一验证§28。
