# Studio 端到端测试用例

> 用途：发布前按用户的真实路径把这些场景从头点到尾。单测和结构测试只证明「挂上了」，不证明「用起来对」（AGENTS §8.0.1 ⑭）。
> 做法：浏览器面板或无头浏览器（CDP），**每一步读 DOM 状态**（焦点在哪、面板开没开、节点在不在可见区域、按钮是否可点、提示写了什么），
> 不只看最后一张截图。涉及积分的场景，开始前和结束后各记一次钱包余额与账本条数，核对差额。
>
> 环境：本地 `pnpm dev:aiavatar` + `apps/server` 起 dev profile；需要真模型的场景用受控测试身份和明确预算。
> 每条用例写清楚「前提 → 步骤 → 每步要看到什么」。测完在「记录」一列写日期、环境、结果；没测就留空，别写「通过」。

只供本机隔离库；脚本的 API 固定为 `http://localhost:18080/api`，测试上游仅绑定 `127.0.0.1:19090`。不要改成生产地址或将受控输出视为真模型制作效果。

后端使用 dev profile 的独立 H2/存储，端口18080，并设置 `aep.ipstudio.fixture-enabled=false`、`aep.dev-fake-llm.enabled=false`、`aep.enterprise.enabled=true`。前端3013代理到18080，按正常本地OIDC登录。若有人同时编译后端，使用独立源码快照打包的JAR，不共用会被clean的target/classes。

```bash
# 仓库根目录。生成带 TEST 标识的色块视频、长短配音；需要 ffmpeg/ffprobe 和 Pillow。
python3 scripts/studio/acceptance_lab.py media
# 单独终端保持运行（明确的测试上游，非生产模型）
python3 scripts/studio/acceptance_lab.py serve
# 以下修改的只是隔离库配置，setup 会把本地默认模型暂时切成受控模型。
python3 scripts/studio/acceptance_lab.py setup
python3 scripts/studio/acceptance_lab.py seed
python3 scripts/studio/acceptance_lab.py enterprise
# 各项顺序运行，共享一个受控上游，不能同时跑两个 case。

```

`agnes` 子命令调用已配置的真实Agnes，属于真实厂商调用，不是桩；首次运行依赖 `seed` 的原片和本地 `studio-live-agnes-text3` 端点。`setup` 不写入或打印供应商密钥。企业 seed 仅本地测试账本，不走支付网关。脚本结果、模型绑定原值与媒体都写入 `.studio-e2e/remaining-20261019/`。测试结束后恢复该隔离库原默认模型；受控候选可保留用于显式复现，不能留作不知情用户的默认。
