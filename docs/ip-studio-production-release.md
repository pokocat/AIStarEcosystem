# Studio 生产发布记录

本次覆盖后端、AiAvatar（含 Studio）和管理后台，已于 2026-10-10 UTC 完成正式部署。下列记录区分部署版本、真实线上验收与尚待确认的业务参数。

定价配置 `ipstudio.supplier-point-pricing` 示例：

```json
{"supplierToPlatformRatio":1,"markupPercent":50,"endpointCosts":{"ai-jusuan-qwen3-tts":1}}
```

`endpointCosts` 为已核实的供应商积分/秒。缺少端点成本时模型不可生成；不回落到验收单价。Qwen3 的现有供应商单价记录为 1 积分/秒，平台展示 1.5 积分/秒。口型 x-dub 的数值单价尚未核实，不以接口计量单位推断价格。所有积分最终为整数，计算 `ceil(ceil(秒数) × 供应商每秒积分 × 换算比例 × (1 + 溢价百分比/100))`。

配音预冻结上限按 `min(600, max(10, 正文Unicode字符数 + 10))` 秒计算。界面明确显示冻结金额及按实际时长退款；超出上限失败且不扣费。语音费用快照进入 `_exec.pointPricing`，同键恢复无需重新报价。口型按解码的驱动音频秒数报价。平台积分和人民币充值包之间的换算不参与当前公式。

部署前：生产 MySQL 8.0.46 / Flyway V39；完整备份目录 `/opt/ai-star-eco/backups/studio-v0227-20261010T033556Z`，含数据库压缩转储与三服务旧文件，权限 0700/0600。仅结构副本在隔离 MySQL 8.0.46 上验证 V40–V48 九项迁移，重复执行零项；不修改旧迁移。

发布前集中回归覆盖前端 475 项、后端选定 399 项，发现三个已过时断言并修正后定向通过。新增计费另外覆盖总额取整、快照、预算冻结、实际结算退款、超限无扣费、重放幂等及界面金额；不重复验证模型出图效果。各历史功能的本地边界保留在统一画布验证记录中。

发布复查发现配音 worker 未绑定已占用的端点名额，嵌套 HTTP 可能二次申请名额。三服务首版已部署后，补充作用域绑定及异常路径释放用例，追加部署后端修复版本，再配置端点并发限制；首版期间尚未启用这些限制。

### 功能与费用

- 真实画布创建、文档版本保存及读取通过。个人画布发布模板、免费套用模板通过，模板实例建立独立节点；整画布分享仍不开放。
- 全屏所见即所得剧本编辑器中，修改正文标题后文档标题导航立即联动；保存、刷新、重开后标题仍保留。AI 面板默认收起，桌面视觉验收通过，浏览器无新增脚本错误。
- 线上配音模型返回 `1.5` 平台积分/秒，不使用旧的单次验收售价。创作浮层显示本次预冻结金额与退回差额说明，输入有效正文后生成按钮可用，底部操作区未与编辑区重叠。
- 仅提交一次真实 Qwen3 配音：15 个正文 Unicode 字符，预冻结 38 平台积分，实际音频 3.2 秒。原厂任务计量返回 `audioSeconds=4`、`effectiveDurationSeconds=3.2`，我方按 `4 × 1 × 1 × 1.5` 结算 6 积分，退回 32，冻结余额归零。同一请求重放复用原任务，账本没有新增记录。
- 画布保存、编辑与个人模板发布/套用均未扣积分。此次没有追加图片或视频生成来重复评判模型效果。

Studio 当前绑定的图片、人物设定、视频、剧本、配音、口型接入端点，在原并发限制为空时初始化为 2；保留原有非空限制。这是平台初始并发设置，不代表供应商公布的配额。配音 worker 复用已取得的端点名额，相关真实数据库并发与异常路径回归通过。
