## 触发与边界

原请求必须先实际调用。只有供应商结构化响应同时包含HTTP 400、`unsupported_geometry`和精确原因`visual activation/HBM headroom budget`才触发分批读取。成功响应、普通400、其他geometry原因、429、5xx、超时或普通内部异常不触发。

分批仅重组本次相关原片画面：从原视频按采样时间提取，源尺寸不缩小，每批最多两帧、串行、独立上下文。观察记录按程序维护的帧号和原片时间汇总，仍调用原模型完成原任务。后续阶段仍先尝试各自的原请求；不会因前一步降级而把整条任务永久切到分批。分批自身失败立即停止，不递归降分辨率或切换模型。

恢复状态写在原任务检查点，不保存Base64图片。显式继续拉片时按请求指纹复用成功批次；父步骤已经物化后删除重复文本缓存。所有成功调用的Token统一计入原任务快照费率与预算，只在原终态结算一次。
