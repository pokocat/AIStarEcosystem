# 全部内置场景提示词清单（38 个，origin/main）

日期：2026-10-30。来源：`apps/server/src/main/resources/ipstudio/scenes.json`（version 1）+ `StudioSceneCatalog.java` 拼装逻辑（`origin/main ee984dcb3`）。**这是当前线上实际发送给模型的提示词**（含生成规则），不是给用户看的界面文案。

> 提示词不是一条静态文本，而是「场景定义（scenes.json）+ 拼装规则（Java 代码）」的组合。下面先给拼装规则，再逐场景给拼好的样子。方案文档（PR-3/PR-4）会改动这些：图片场景加 `keep/change/checks`，视频场景加 `brief`（目标/必需事实/节拍/CTA），`scriptBrief` 输出改成 H3 能解析的「第N镜（…）旁白说：「…」」格式。

## 1. 拼装规则（所有场景共用）

### 1.1 事实边界 FACT_RULE（所有视频场景都会附上）

> 下面这些我没写就不要出现：价格、优惠、地址；品牌创立年份、有多少年历史；检测、测试、实验的次数和画面；销量、排名、获奖、认证、门店数、用户数；功效和其他数据。也不要写「有优惠」「限时」「十年老店」「经过上千次测试」这类话，拍法里要讲但我没给的，就只引导关注或下单。可以虚构人物和情节来讲故事，但不要写成品牌的真实经历，也不要给编出来的内容配上年份、次数、数量。

### 1.2 图片场景（17 个）


### 1.3 视频场景 A：交给助手/编导出完整方案（videoBrief）

```

我的要求：{用户写的那句}                    ← 没写则没有这一行
{选项行，如「出镜方式：真人出镜对着镜头讲…」}

```

### 1.4 视频场景 B：编导写脚本（scriptBrief，AI 视频页实际发这条）

```
写一条 {时长} 秒的{横|竖}屏「{场景名}」短视频脚本，交给视频模型一次生成，台词用{中文|…}。
我的要求：{用户写的那句}                    ← 没写则没有这一行
{选项行}
参考素材（已附图片，按这个编号写）：图1「{图名}」是{素材名}；图2「{人物}」是出镜人物，长相和穿着要和图里一致；「{声音}」是说话要用的声音。
我没写具体要求：先看图，说清楚是什么、卖点在哪，再按下面的拍法写。   ← 没写要求且有素材时才有
拍法：{场景拍法}
写法：按时间顺序分镜头，每个镜头单独一行，格式是「镜头N（起–止秒）：画面……；台词：……」，没有台词就不写台词。单个镜头 2 到 5 秒，所有镜头加起来正好 {时长} 秒。台词说人话，按每秒 4 个字左右算长度。只写镜头里看得见、听得见的东西，不写拍摄建议、不写给人看的解释。
{FACT_RULE}
正文只放脚本本身；summary 用一句话说这一版的思路，只说脚本里实际写了什么，用了虚构的人物或情节就直说，不要写「没写功效」「信息都属实」这类保证。
```

> **与 H3 保护路径的冲突点**（方案 PR-3）：上面「镜头N（起–止秒）」是场景稿格式；`H3PromptRewrite` 只认「第N镜（」+「某人说：「」」，所以场景稿进不了固定镜头/台词代码填路径。改造后这里会输出 H3 格式。

### 1. free 自由出图
`{用户描述}` + 选项行（无选项组时仅用户描述）；没写描述则报错。

### 2. ip-sheet IP 设定图
> 以图1中的人物为唯一角色，做一张完整的人物设定图，一次生成在同一张图里。沿用图1的长相、发型、服装、配饰、身材比例和画风，所有区域都是同一个人、同一套衣服。浅暖色纸面背景，细灰分隔线，排版清楚。上半部分：左边一张大幅半身像，中间是正面、90 度侧面、背面三张全身像，并排、同样高度、脚底对齐；中间部分：五张头肩表情特写（微笑、惊讶、酷、生气、温柔）；下半部分：服装细节、配饰和主要配色色块。不要多余文字，不要水印，不要混入其他人物。

### 3. ip-portrait IP 写真
> 以图1人物为准，保持长相、脸型和发型一致，拍一张写真，风格和场景按补充要求来，没写就拍午后咖啡馆里的杂志感写真。人物半身入画，姿态放松自然，光线柔和，背景有层次但不抢人物，写实照片质感，不加文字和水印。

### 4. ip-expression IP 表情包
> 以图1人物为准，生成 3×3 九宫格表情图：开心、惊讶、生气、委屈、思考、得意、害羞、无奈、大笑。九格是同一个人、同一套服装、同样的画风，头肩入画，纯色浅色背景，每格表情夸张清楚，格子之间留细白边，不加文字。

### 5. face-turnaround 脸部三视图
> 以图1人物为准，保持五官、脸型、发型、肤色和年龄感一致，在纯白背景上生成头部三视图：从左到右依次是正面、45 度半侧面、90 度正侧面。三个头像一样大、平视、肩部以上入画，柔和均匀的影棚光，写实照片质感，不加文字和水印。

### 6. fullbody-sheet 人物四视图
> 以图1人物为准，保持长相、发型、身材比例和服装一致，在纯白背景上横向排列四个视图：全身正面、全身侧面、全身背面，以及一张脸部特写。站姿自然、双臂放松下垂，三个全身像一样高、脚底对齐，影棚柔光，写实照片质感，不加文字。

### 7. face-swap 模特换脸
> 把图1中模特的脸换成图2人物的脸，发型一起换成图2的样子。保留图1的姿势、服装、光线、背景和构图，脸部肤色和光影与身体自然衔接，看不出拼接痕迹，写实照片质感。

### 8. face-fusion 人脸融合
> 融合图1和图2两个人的面部特征，生成一个全新的虚拟人物：五官比例取两人之间，和任何一方都不完全一样，气质自然。正面半身肖像，浅灰纯色背景，柔和影棚光，写实照片质感，不加文字。

### 9. outfit-on-model 服装上身
> 让图1中的模特穿上图2的服装，服装的款式、颜色、图案、面料质感和细节与图2完全一致。保留模特的长相、发型、姿势和背景，衣服贴合身形、褶皱自然，电商模特图质感。

### 10. product-in-use 商品使用
> 生成一张真人正在使用图1商品的生活场景照片。商品的外观、颜色、包装和标识与图1一致并且清晰可见；人物动作自然、表情放松，场景和商品用途相符，自然光，适合做电商种草配图，不加文字。

### 11. white-background 商品白底图
> 把图1中的商品单独放到纯白背景正中，商品完整、居中，约占画面七成。保留原有外观、颜色、文字和标识，加上柔和的接触阴影，影棚布光，边缘干净，适合电商平台主图。
> 选项「拍摄角度」（默认正面）：正面→商品正面朝向镜头；斜 45 度→商品斜 45 度摆放，看得出立体感；俯拍→从正上方俯拍商品。

### 12. selling-point 商品卖点图
> 以图1商品为主体，做一张竖版详情页卖点图：商品放在画面中上部，用简洁的场景和道具表现补充要求里写的卖点（没写就突出商品的质感），四周留出干净的空白方便后期加字，配色和商品协调，质感高级，画面里不要生成任何文字。

### 13. outfit-restyle 服装改款
> 保持图1服装的版型、剪裁和穿着方式不变，把面料和印花换成图2的样式；没有图2时，按补充要求里写的颜色或图案改。光影和褶皱随新面料自然变化，展示方式与原图一致。

### 14. scene-swap 人物入景
> 保留图1人物的长相、服装、姿势和光线方向，把背景换成图2的场景；没有图2时，换成补充要求里写的场景。人物和新背景的透视、光影、色调统一，脚下有合理的阴影，写实照片质感。

### 15. product-scene 商品入景
> 把图1的商品放进图2的场景里；没有图2时，放进补充要求里写的场景，商品外观不变，摆放符合真实使用习惯，光影和环境一致，适合做种草配图，不加文字。

### 16. realism 人物真人感
> 让图1的人物看起来像真实拍摄的照片：加上自然的皮肤纹理、毛孔和细微瑕疵，去掉过度磨皮和塑料感，眼神和发丝细节更真实。保留原有长相、表情、服装和构图。

### 17. retouch 图片精修
> 精修图1：提高清晰度和细节，修正曝光和白平衡，光影更通透、颜色更自然，去掉噪点和压缩痕迹。不改变画面内容、人物长相和构图。

### 1. ecom-talking 口播带货
拍法：真人对着镜头讲：开头一句话说清商品能解决什么，中间边讲边展示商品细节和使用过程，结尾讲优惠并引导下单。
想法：开头用反常识说法抓人 / 先讲真实烦恼再给答案 / 前后对比突出效果 / 结尾明确告诉观众怎么买。
选项：出镜方式（真人讲解→真人出镜对着镜头讲，边讲边拿起商品展示；只拍商品→不出现人脸，只拍商品和手部操作，用画外音讲；前后对比→用使用前后的对比画面说明效果）；语气（像朋友推荐/专业讲解/热情带货）。
提示词 = §1.4 模板，标题填「口播带货」，拍法如上，附上述选项行。**文字可不填**（不填时提示词去掉「我的要求」行、加「先看图…」行，拍法仍要求"结尾讲优惠"）。

### 2. ecom-promo 促销转化
拍法：开头直接亮出优惠力度，中间用两三个画面证明商品值这个价，结尾强调时间有限、马上下单。
想法：同 ecom-talking。无选项。文字可不填。

### 3. ecom-seeding 场景种草
拍法：从一个具体的生活场景切入，商品自然出现在场景里被使用，展示用完之后的好状态，不硬推销。
选项：语气（像朋友分享→像朋友分享自己在用的东西，自然不推销；活泼→节奏轻快，画面明亮活泼）。文字可不填。

### 4. ecom-painpoint 痛点解决
拍法：开头放大一个用户熟悉的烦恼，接着商品出场解决问题，用前后对比展示效果，最后一句总结。文字可不填。

### 5. ecom-demo 功能演示
拍法：按功能逐个演示，每个镜头只讲一个功能，特写操作和效果，最后一个镜头展示商品全貌。文字可不填。

### 6. local-discovery 门店发现
拍法：像路过发现宝藏小店一样开场，带观众看门头、环境和最有特色的东西，结尾说清在哪里。
想法：从街口走进店里的第一视角 / 老板或员工亲口介绍招牌 / 突出排队和热闹的氛围 / 结尾说清地址和团购入口。
选项：拍法（边走边拍→第一人称从门口走进店里，一路拍环境、招牌和招牌菜；菜品特写→以菜品和制作过程的特写为主；拍顾客反应→多拍顾客吃到、用到时的真实反应）。文字可不填。

### 7. local-visit 到店实录
拍法：第一视角从进门开始，点单、上菜或体验服务，拍吃到、用到时的反应和细节，结尾说一句自己的感受。文字可不填。

### 8. local-signature 招牌体验
拍法：围绕一道招牌（或一项招牌服务）拍：制作过程特写、上桌或完成瞬间、第一口或体验反应。文字可不填。

### 9. local-groupbuy 同城团购
拍法：开头亮出团购价格和包含的内容，逐项展示套餐里的东西，结尾提醒怎么买、怎么到店用。文字可不填（完整展开示例见 §1.5）。

### 10. brand-proposition 品牌主张
拍法：用有画面感的场景表达品牌态度，少讲产品多讲为什么，结尾落在一句品牌主张上。
想法：不出现硬广，用画面讲态度 / 用一个人物的一天串起来 / 画面统一成一种主色调 / 最后一个镜头落在品牌标识上。
选项：画面风格（电影感/简洁干净/温暖生活）。文字必填。

### 11. brand-story 品牌故事
拍法：从一个人物讲起：给了创始人或品牌经历就照着讲，没给就讲一位用户的故事。拍出一个具体的坚持，最后回到品牌。文字必填。

### 12. brand-lifestyle 生活方式
拍法：用几个生活片段拼出目标用户向往的一天，产品自然出现在其中，节奏轻快，配乐有氛围。文字必填。

### 13. brand-concept 创意概念
拍法：用一个有想象力的视觉概念贯穿全片，画面有记忆点，最后把概念和产品连起来。文字必填。

### 14. drama-dialogue 对话剧情
拍法：以对话为主，正反打镜头切换，每段对话都推进一点关系或冲突，结尾一句点题。
想法：前三秒就进冲突 / 每段结尾留一个钩子 / 台词短，多用动作和表情 / 结尾来一个出人意料的反转。文字必填。

### 15. drama-twist 反转剧情
拍法：前半段按观众预期铺垫，埋一个不起眼的伏笔，结尾揭开反转，让伏笔说得通。
选项：反转方式（身份反转→结尾揭开某个人物的真实身份；真相反转→结尾揭开事情的真相，和前面看到的相反；结局反转→眼看要走向一个结局，最后一刻翻转）。文字必填。

### 16. drama-suspense 悬疑剧情
拍法：开头抛出一个谜团，中间逐步给线索、制造紧张，结尾揭晓或留下更大的悬念。文字必填。

### 17. drama-emotional 情感剧情
拍法：围绕一段关系（亲情、友情、爱情）讲一个小事，情绪慢慢推进，结尾有一个让人动容的瞬间。文字必填。

### 18. drama-placement 剧情植入
拍法：先讲一个完整的小故事，商品在关键情节里自然出现并帮上忙，不打断剧情，结尾轻轻点出商品。文字必填。

### 19. ip-talking 数字人口播
拍法：人物面对镜头讲解，中间穿插和内容相关的画面，字幕跟着说的话走，结尾一句总结。
想法：开头先抛一个问题 / 分成三点讲，每点一个画面 / 结尾提醒关注。文字必填。

### 20. ip-vlog IP 日常
拍法：按时间顺序拍几个生活片段，人物长相和穿着保持一致，节奏轻快，像真实的 vlog。
想法：用手持自拍的视角 / 每个片段配一句心情 / 画面统一成暖色调。文字必填。

### 21. recreation 爆款复刻（走 reference-video-recreation 技能）
拍法：先拆解参考视频的镜头、节奏和文案结构，再按同样的结构换成我的内容重新拍。
想法：保留原片的节奏和镜头顺序 / 台词换成我的卖点 / 人物换成我的 IP。文字必填；**必须上传参考视频**（提示词含「「{参考视频}」是要复刻的参考视频」）。
