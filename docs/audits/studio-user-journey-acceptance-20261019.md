## 优先处理顺序

先修文字结果落画布和复刻检查的错误通过口径；再修成片片段默认选择、首页复刻入口的素材/收费动线、通用对话技能绑定与失败通知；最后清理历史内部动作展示和重复项目命名。修复后用新建的受控测试身份和明确积分预算，按“首页输入 → 加参考素材 → 分析报价 → 确认 → 生成/检查 → 成片 → 刷新恢复 → 账本核对”重跑一条真实链。
