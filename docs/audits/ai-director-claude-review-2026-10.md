## 1. 评审方式与证据

用户授权将方案交给 Claude App，并让双方讨论收敛。通过原生 Claude App 的 AIStarEcosystem 环境新建会话“AI导演台方案评审”，会话标识 `local_ac772be0-1706-4c8d-9e8c-6753ccfb1d5f`；沿用其已有模型设置，没有另开媒体生成。

Claude 第一轮读取当前本地、含未提交内容的总方案、Agent 提示词、视觉实操稿、工作流及现有分镜编辑方案，并核对相关源码。它给出 8 项意见和 3 个决策问题。Codex逐项反馈依据、反例和拟定方案；第二轮 Claude 明确接受核心方向，并提出 5 个需要补充的落地条件。修订后再交 Claude 做定点复核。

这是产品／架构评审。源码配置、历史文档、第三方界面观察与真实在线行为分别对待；双方都没有以此宣称宫格视频、音色或完整制作链已经实测通过。

## 2. 讨论后的决策

| 议题 | 第一轮分歧或缺口 | 收敛结论 |
|---|---|---|
| 导演作品放哪里 | v1.0 依赖画布文档和客户端结果回投，牵连未实现的单镜编辑方案 | aiavatar 内独立服务端制作对象；画布继续原文档边界，首版无双向同步 |
| 现有短剧和资产 | 未具体说明 web-drama、IpLibraryRecord、DapVoice 复用 | 补映射；不迁移／下线 drama、不混写项目、不新造平行全局资产库 |
| 资产身份 | 不能把所有资产一概落到 DapAvatar／DapLook | 人物复用既有角色／造型；独立场景道具由现有资产库服务管理逻辑身份和不可变版本 |
| 模型与价格 | 将历史 seed／代码描述当当前线上事实，照厂商公式推价格 | 只按当前端点合同及平台报价；型号和上限需在实施时读取确认 |
| 宫格与回退 | 有些整板比例不被端点支持，短镜头不满足视频最短时长 | 先两段小样；布局按能力开放，逐镜转换须调整计划和报价，不宣称天然兜底 |
| 声音初始来源 | 从混有背景声的视频自动取音色的默认路线过于乐观 | 上传、已有声音版本试听或显式短试音优先；混合视频提取后置 |
| 质检与一键连跑 | Claude 初提把不少身份／动作检查降为提醒，Codex认为偏离核心目标 | 硬契约、关键内容、非关键质量三层；关键错误保留停点，无依赖分支继续 |
| 人工出口 | 模型误判不能永久阻断，也不能被改写为 AI 通过 | 人工逐项核验并记录版本／实际状态，可作为独立证据驱动后续；仅选中候选不等于核实全部状态 |
| 界面简化 | Claude 初提隐藏模型、提示词和参考资产 | 沿用用户认可的可见字段，未经使用验证不全藏；定时后置 |
| 首版范围 | 整剧到视频的报价、队列与检查风险较大 | 整剧到分镜图，本集／选中片段到视频；仍完成整集导出闭环 |
| 模型调用 | A4/A5 可能重复选图，固定八类调用增加成本 | 程序完成确定性绑定；A5、A8 条件调用；提示词可按模板编译，列出所有费用类别 |

## 3. 第二轮补充的五个条件

1. **生成宿主与企业付款**：明确 director／canvas 宿主、文件归属、恢复、统计、billing 授权快照与在途结算，不能靠隐形画布兜底。
2. **场景／道具的版本身份**：现有资产库服务扩展稳定身份和不可变版本列表，采用指针变化不改已提交引用。
3. **质检误判与校准**：人工确认有独立证据；自动策略默认启用前记录 unknown、误判与成本。有限补证据，避免无限反思。
4. **连跑公平性**：父任务按批次放行；初始建议用户每端点 2 个在途、跨端点 4 个，受更低端点上限约束，后续容量实测调整。
5. **并发写入**：用户写入校验修订；后台仅写授权空位和新候选、填基线匹配的空采用指针；既有内容改写走显式补丁采用，派发前比对输入指纹。

## 4. 明确未采纳或修正的绝对说法

- “客户端不回投，列表一定全空”：原稿已允许列表读后台运行，Claude 第二轮收回绝对说法；服务端独立作品仍因工作区内容与后台采用更直接而被采纳。
- “生产只有 H3／V54 seed 就是当前可用尺寸”：未检查在线配置，不能当现时真值。
- “厂商第七张参考图加价，就按该公式向用户报价”：平台自行定价，不能照抄厂商收费规则。
- “所有人物或动作检查未知都只提醒”：不符合一致性目标；只有非关键美学项可不阻断。
- “声音样本固定平均分成 15/N 秒”：按实际有效语音和端点单段／合计限制选择，不硬编码平均分配。
- “人工确认不能驱动任何下游”：人工不能伪装成 AI 通过，但核实过的具体状态应作为合法人工证据，否则恢复出口无效。

## 5. 尚需真实验证

讨论不能证明目标端点会按 2×2 分镜板生成多镜视频、保持身份和关键动作，也不能证明音频参考稳住跨段音色。阶段 0 在明确预算后用两个短片段验证，同时评估自动检查的 unknown／误判与成本。

本次只把这项验证列为实施门槛，没有执行收费测试。定稿指方案决策与边界收敛，不是产品已经实现或效果已经通过。
