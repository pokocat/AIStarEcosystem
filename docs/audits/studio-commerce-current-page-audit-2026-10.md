# Studio 当前页面与带货分发增量设计依据

核对日期：2026-10-16。来源：直接查看线上 aiavatar 页面、打开现有商品视频模板和本人已有商品视频画布，并核对当前工作区代码。本轮仅阅读，没有新建画布、存为副本、提交生成或发布。

## 已确认的实际页面

| 页面 | 当前真实内容 | 必须保留的职责 |
|---|---|---|
| 首页 `/dashboard` | 品牌首屏；数字人形象、图片、视频、短剧四类创作入口；继续创作；灵感故事 | 发现与进入，不改造成带货后台 |
| 创作 `/create` | 全部画布/草稿/已发布筛选；我的画布列表、搜索排序与视图切换；新的创作；官方模板 | 通用画布的管理和创建，不升级成业务分区总目录 |
| 新的创作区域 | 全能创作/图片/视频/剧本四种输入；免费创建并打开画布；个人 IP、数字人视频、IP 商品视频等快捷入口；更多工具 | 这些入口创建或预览的仍然是画布，不代表已有选品业务 |
| IP 商品视频快捷入口 | 打开官方只读模板，需显式“存为个人副本”才创建个人画布 | 现有创作配方；不能把它当成已经存在的带货专区 |
| IP 商品视频模板 | 人物参考、商品参考、商品卖点与视频要求、商品展示画面、商品视频片段五个节点及连线 | 可作为商品展示配方复用，但不是完整剧情带货项目或商城选品页 |
| 个人画布 `/projects/[id]` | 独立全屏画布、返回创作、画布名称、历史、模板相关动作、发布；画布/故事板/成片三种工作视图；人物库、模板、任务与 AI 创作工具 | 创作引擎及文档编辑，不复制一套带货专用画布 |
| IP 管理 `/ips` | IP 状态、搜索/标签/排序、角色卡，查看设定和内容资产 | 人物资产管理，不重复建设带货人物库 |
| 模板管理 `/templates` | 官方模板、我的模板、待建设的用户模板；只读预览、个人副本；精选画布 | 可复用画布流程，不与带货项目混成同类列表 |
| 资产库 `/assets` | 剧本资产、生成与上传、人物形象、专属声音；文件夹、搜索和资产操作 | 个人素材及资产的统一入口，不把商品公共池当成本人全部资产 |

线上当前一级导航是五项：**首页 / 创作 / IP 管理 / 模板管理 / 资产库**。当前没有一级带货或分发入口，也没有本轮方案拟新增的商品库和发布草稿页面。

页面与源码参考：`desktop-top-bar.tsx`、`studio-create-home.tsx`、`studio-creation-brief.tsx`、`studio-entry.ts`、`studio-template-use.tsx`、`studio-flow-canvas.tsx`、`canvas-host.tsx`、`publish/publish-dialog.tsx`。路径均相对 `apps/web-aiavatar/src` 的对应目录。

### 现有“发布”的业务含义

画布顶栏已有“发布”，代码打开的是选择主形象、造型和资产名称的 PublishDialog，提交到 `IpStudioApi.publishProject`。它是发布为数字人/IP 资产，不是发布视频到抖音等平台。

创作列表的“已发布”是画布项目状态，不能被新分发功能拿来当作视频已上线。新增入口使用“准备分发”“提交平台发布”等能区分的动作；现有资产发布和模板发布保持原义。

## 上一版设计的问题

1. 用截图匹配品牌和卡片，没有完整列出页面实际承载的工作，再决定入口。
2. 将 `/create` 当成通用业务启动页，准备往其中加入完整带货流程，忽略其“我的画布 + 新建画布”的中心语义。
3. 将矩阵账号、发布准备和记录全部归在 `/commerce`，使普通视频分发也要经过带货业务。
4. 两张 v2 图仍只有五项全局导航并高亮“创作”，不符合后来讨论的独立一级业务入口。
5. 未在设计中明确既有商品模板、已有个人画布、带货业务项目和平台发布任务之间的关系。

因此原拼版图和 products-v2 / publish-v2 只保留为早期视觉探索，均不再作为信息架构或开发验收依据。不能用“颜色和控件接近”宣称已经按实际页面完成设计。

## 已确认的目标结构

用户于 2026-10-16 确认：**首页｜画布·自由创作｜场景·专项创作｜灵感｜资产｜发行**。进入“场景·专项创作”后的页面标题为“场景工坊”。完整规则见 [Studio 导航与内容组织定稿](../studio-information-architecture.md)。

现状事实与目标结构应分别阅读：上文五项导航是本轮已核对的线上现状；六项导航是尚未实施的用户定稿。此前独立增加带货、分发形成七项导航的提议已被替代。

| 现有内容 | 定稿后的安排 | 保留的行为 |
|---|---|---|
| 首页 | 仍为首页 | 能力介绍和继续最近工作 |
| 创作 | 一级改名“画布·自由创作” | `/create`、`/projects/[id]`、画布管理、自由搭建及原制作能力 |
| IP 管理 | 并入“资产”的第一分类“我的 IP”，裸 `/assets` 默认打开 | 完整人物设定、形象版本、关联声音和相关作品；旧 `/ips` 参数兼容 |
| 模板管理 | 一级改名“灵感” | `/templates`、只读预览、显式存个人副本；区分官方、个人模板及精选案例 |
| 资产库 | 一级简称“资产”，承接 IP 管理 | 创作素材、生成与上传、声音以及现有个人资产详情 |
| 暂无专项业务目录 | 新增“场景·专项创作”，页面为“场景工坊” | 首接带货，之后短剧和音乐都在此扩展，不再追加一级菜单 |
| 暂无独立平台分发入口 | 新增“发行” | 草稿、矩阵账号和发布记录跨场景共用；视频先接，音乐发行单独适配 |

场景与画布选角色时，必须直接弹出“我的 IP”，选完返回原输入和版本引用，不先跳转资产页。IP 若未来具备绑定发行账号、人设内容规划、数据分析等独立运营能力，再评估恢复一级入口。

## 下一版视觉设计的依据

旧拼版及两张 v2 图均已撤出实施依据。下一版必须先展示完整六项一级导航，以及场景目录、资产默认“我的 IP”、完整 IP 详情和就地角色选择，再画带货选品与发行准备。

后续只做增量界面：自由画布保留当前工作视图；专项业务保留来源上下文；发行与 IP 资产发布的动作含义分开。不得用旧五项导航高亮“创作”来代表专项场景或发行。
