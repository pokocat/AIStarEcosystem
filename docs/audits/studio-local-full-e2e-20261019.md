# IP Studio 本地端到端验收记录（2026-10-19）

范围：`web-aiavatar` 的首页、项目、自由画布、场景、模板、资产、成片、发行入口及画布内创作助手。使用 Chrome 实际操作并逐步读取 DOM；服务端为独立 H2 本地实例，账号走本地 OIDC。代码基线 `b7861a4b`。测试数据均为虚构商品与测试项目，未发布或部署。

## 结论

画布手工创作、模板复制、素材引用及基础成片可用；对话驱动的参考视频复刻**尚未通过端到端验收**。真实 Agnes 调用能完成计费、生成图片，但分析方案被校验器拒绝，无法进入确认卡及制作阶段。首页带话进入对话、聊天完成状态和草稿恢复还有用户可见问题。下文把通过、失败、未覆盖分开记录；未覆盖项不视为通过。

## 确认问题（按优先级）

1. **P1：首页带话创建不能自动发送。** 在首页输入“请帮我为虚构商品「星桥保温杯」做一张 9:16 宣传图。先说制作方案，等我确认再生成”，点“开始对话”；新项目带 `?start=assistant&send=1`，助手输入框为空且时间线没有该句，刷新仍为空。手工发才继续。`studio-entry.ts` 已把 brief 写入 `assistantConversations`；`studio-workspace.tsx:710-719` 在资料尚未就绪时就可能写入 `startOpened`，之后不重试，符合实测症状。影响对话入口的第一步。
2. **P1：普通创作错误绑定“参考视频复刻”技能。** 空画布的“生成商品宣传图”及泛创作串流程请求都自动绑定此技能，后续对话只能“从这里重新开始”换技能。`StudioSkillRouter` 在仅有一条 active skill 时无条件选中（第 27 行），不检查视频输入或意图。影响非复刻场景的正常对话。
3. **P1：真实复刻分析无法生成有效确认卡。** 主画布钉住“商品视频片段”和“图片”，明确要求仅分析报价。Agnes 返回一条拉片计划，但 `questions` 使用 `{id,text,defaultAnswer}`；`StudioPlanValidator.questions()` 仅接受文本或 `{question,default}`，工具以 `AI_BAD_OUTPUT / 创作方案不完整，请重试` 拒绝。该计划还填写了本地不可用的 `sora-2`，即使问题字段兼容仍需拦截并引导可用模型。助手随后给出没有数字的“报价依据”，误称用户提过 300 积分、猜测原片内容，且没有审批卡；不能作为已完成报价或已拉片。对应 run `IPR-d0862946d4a141458c77`，工作记录“整理制作方案 没有完成”。
4. **P1：真实对话完成后当前页不稳定显示结果。** 多次 Agnes 文本调用在后端已完成并扣费、页面却持续显示“停止”而无回复；手工刷新后回复和脚注出现。一次后续轮次自行恢复，说明非每次必现。需查 SSE 断连后的轮询投影和终态收敛；本地日志同时出现流式 session ping 的 Broken pipe，但尚不能断定因果。会让用户误以为任务还在运行，并影响付费透明度。
5. **P2：素材来源标识失真。** 从“AI 生成”素材库导入图片、视频、音频，画布卡片均显示“你上传的”，刷新后仍如此；真实 AI 图裁剪出的节点也显示“你上传的”。`studio-flow-canvas.tsx:63-67` 以 `storageKey && !libraryReference` 推断为上传，而普通生成资产导入时没有 `libraryReference`。在来源敏感的成片选择中容易误认原片/生成片。
6. **P2：未发送草稿刷新后消失。** 对话框输入文字后关闭重开仍在；刷新页面后文字消失，两次复现。runbook 2.7 要求草稿保留。`studio-assistant.tsx:121-143` 仅用组件内 `useRef(Map)` 缓存草稿，没有跨页面持久化。
7. **P2：模型下拉出现两个同名“未命名模型”。** 2.5/3.0 文本模型都这样，图片候选也这样；只能靠位置猜测。后台候选有名称和模型名，但本地 `modelAlias` 为空时对外名称回落成“未命名模型”。实际选第二项能调用 Agnes 3.0，属可选择但不可辨认。
8. **P2：选中的对话模型刷新后回到默认。** 限流预备时选第二项实际调用 Agnes 3.0；刷新后相同对话的后续消息改走默认 Agnes 2.5，而 UI 仍都写“未命名模型”，用户无法察觉。`studio-assistant.tsx:104,167` 的选择只在组件 `useState` 中，未按画布/用户记住。与此前约定的“模型偏好记住”不符，也会使预算和质量预期改变。

## 尚未完成或受阻的验收

- runbook 1.1.1–1.1.3：缺一张含参考原片、拉片片段和三段新视频的完整复刻画布，无法验证“原片默认不进成片”及显式勾选覆盖。1.1.4 的播放/跳段已测，配音与字幕全段逐帧同步未充分核对；1.1.5 的同集重排、1.1.6 的“长于成片”配音未做实测。
- runbook 1.2.3、1.2.7–1.2.8：跨浏览器的冲突提示、冲突时发布/关页、后台写回 30 秒稳定性未测。同浏览器三种恢复选项已测，不把它推断为跨浏览器通过。
- runbook 1.3.1–1.3.3：Agnes 视频候选虽在后台配置，画布视频生成对话框却显示“尚未配置模型”，未能走真实 15 秒视频、视觉模型显存分批和该路径费用对账。需要补齐该候选的制作合同/定价后再跑；不能用图片成功代替视频验收。
- runbook 1.4.1–1.4.8、1.4.10 及 2.2–2.4：分析计划无法出现确认卡，后续生产改词、暂停、预算追加、企业付款、断网恢复及进度条定位无完整用户路径。1.4.9 的模型切换实际端点已核；2.5–2.6 交互已核，2.7 草稿失败。
- 真正逐字流式输出未验收：本地 Agnes 文本端点能力未标记流式，调用日志为 `stream=false`；本轮仅观察到事件式工作记录和输入不中断，不将它视为流式正文通过。
- Agnes 的**供应商级** 429 未自然触发；本次通过本地模型 RPM=1 测到了应用层 429、账本释放和刷新后的错误展示，不把它当作供应商实际限流验收。
