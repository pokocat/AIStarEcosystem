## 设计判断与交接

依据 Impeccable 的状态可信、上下文延续、焦点管理和响应式原则：当前视觉风格可以保留，接下来应优先改善“做完一步后是否知道发生了什么、回到哪里、是否真的保存”，其次才是间距和字重。项目卡片新增继续入口解决了动线，却又让次要动作争抢同一行；这类回归需要按完整任务路径验收。
