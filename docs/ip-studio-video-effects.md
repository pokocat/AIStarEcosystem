# Studio 视频特效库

> v0.213 · 2026-10-08 · 本地实现，未提交、未发布。界面交互为本轮验收重点，没有新增供应商生成或扣费。

## 操作路径

原生视频节点、放大编辑和 Studio 视频抽屉共用同一特效库。入口位于正文前，与运镜并列。广场展示官方描述；我的收藏、最近使用和我的特效按当前账号保存。支持名称、作者、模型名称、标签搜索和分类筛选。

点击适用模型的特效卡片直接选用并返回原编辑器。详情图标可独立查看完整描述、作者与适用模型，收藏也不触发选用。已选特效时入口显示“替换特效”；再次选用在原位置替换已识别的特效指令，旧画布里多个已识别特效也收敛为一项，不重复追加。原正文、已修改的自定义描述、运镜、参考标签与节点连接保留；点标签可展开修改，移除和剪贴板均使用完整正文。新指令在原光标插入；库加载后的输入重建按序列化文字位置恢复光标，快速选用还会重新识别已有指令。应用等弹窗关闭并解除焦点约束后才回填。三个入口使用真实 endpoint ID 判断模型，不能拿前端渠道名称作模型 ID。

默认筛选仅适用当前模型。取消筛选可查看其他条目；不适用时禁止应用并提示先选择支持的模型，不自动切换模型或丢弃参考素材。服务端再次校验配置与范围。最近使用记录成功应用描述的时间，不代表提交生成、生成成功或平台使用量。

“保存我的特效”填写名称、简介、完整描述、标签、适用模型及可选参考封面。封面只能选择当前画布的本人图片。保存形成不可变条目，仅自己可见，可跨画布调用；此版本没有个人条目编辑、删除、社区公开投稿或审核后台。收藏与最近记录独立保存。

## 能力边界

v0.213 补齐 LibTV 已观察到的点卡片直接选用、替换、移除动线；详情不再是必经确认步骤。v0.212 已提供特效查找、作者/模型/标签筛选、收藏和最近调用。完整社区与供应商能力仍有差距，没有把当前实现称为全量一致。

特效是可复用的自然语言描述，不是供应商原生效果参数。画布与生成请求只保存完整 `metadata.prompt`，不存在隐藏的第二套特效真值。参考封面以“参考封面”命名，不冒充效果演示视频；三条内置官方描述没有演示媒体，显示“暂无预览”。全量社区目录、效果视频预览、原生模型效果和五分钟长视频仍未接通。

本次仅在 LibTV 调研画布选择一次 360 旋转展示后移除，并恢复原模型；没有提交生成、收藏、投稿或上传。没有为模型画质重复调用。

## 数据与接口

`packages/types/src/ip-studio-effect.ts` 为前端类型真源，`StudioEffectDtos` 保持同字段。端点均挂现有 aiavatar 开通和身份保护：

| 接口 | 用途 |
|---|---|
| `GET /api/v1/ip-studio/video-effects` | 官方及本人条目、本人活动和短期签名封面 |
| `POST /api/v1/ip-studio/video-effects` | 发布描述；官方条目要求超级管理员 |
| `PUT /api/v1/ip-studio/video-effects/{id}/favorite` | 本人收藏状态 |
| `POST /api/v1/ip-studio/video-effects/{id}/apply` | 校验模型后记录本人最近应用 |

模型白名单复用画布通用视频链的 `VIDEO_GENERATION` 配置。图片 key 校验本人归属及真实图片类型；库中只存 key，URL 在响应时签名。发布与使用不创建生成任务、不冻结积分、不新增账本。生成继续复用原通用视频链的预检、原请求和结算。

新增 Java 迁移 `V46__studio_video_effects` 建不可变条目表及账号活动表，活动 `(owner_user_id,effect_id)` 唯一。收藏/最近写操作锁定当前用户后读改活动，避免首次并发插入或相互覆盖。三条官方文本种子幂等补齐，不改旧画布、模板、任务或已执行迁移。
