| 旧 IP 链接 | `/ips` 的已有查询参数转到 `/assets?tab=ips`；`focus=search` 保留并实际聚焦搜索框 |
| 发行账号 | 读取同一 uid 的存量社交账号；复用扫码、轮询、短信交互、取消、状态验证、解绑接口。关闭/晚到响应取消原票据，查询失败续查原绑定，不伪造成功 |
| 发行记录 | 原批次服务端分页、按原 batch identity 读取本人任务、手动刷新与真实状态/外链。范围明确为当前 uid 全部存量记录，不冒充 Studio 来源隔离 |

## 明确待建设

- 商品库/抖音链接选品与商品进入剧本编辑器的局部融合、采纳链。
- 短剧与音乐专项模板入口。
- 画布精确成片来源适配、发布草稿持久化、画布作品投递。
- 本发行入口的批量定时、发布任务写操作与平台待验证处理，以及音乐发行渠道。

待建设部分有明确标记，不提供伪保存、伪绑定、伪发布成功。保存发布草稿不会调用现有创建即排队的 PublishJob。原画布“发布”继续指 IP 资产登记。

## 后端改动边界

只增加按缺失补充的两个普通场景模板（`StudioScenePresets`），并在 `ProductRouteTable` 精确共享账号域与发布任务 GET。原社交账号和发布任务服务、DTO、本人归属、账本与调度协议继续复用；发布任务 POST 仍限 celebrity，未伪装产品请求头。没有新增实体、数据库迁移、API路径或发布任务写能力。

新模板不覆盖和重新启用已有模板。前后端需一起发布才能得到新模板与正确的跨产品开通检查；本轮未部署。
