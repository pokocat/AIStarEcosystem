## 后端改动边界

只增加按缺失补充的两个普通场景模板（`StudioScenePresets`），并在 `ProductRouteTable` 精确共享账号域与发布任务 GET。原社交账号和发布任务服务、DTO、本人归属、账本与调度协议继续复用；发布任务 POST 仍限 celebrity，未伪装产品请求头。没有新增实体、数据库迁移、API路径或发布任务写能力。

新模板不覆盖和重新启用已有模板。前后端需一起发布才能得到新模板与正确的跨产品开通检查；本轮未部署。

首页 `ip-canvas-hero-v3` 与 `ip-canvas-scenes-v2` 使用同内容本地 WebP，保持 1672×941；转换前本地原稿 MD5 与现有 OSS ETag 一致。首页主图由 Next Image 按视口选择并 preload，CSS 背景引用同一本地资源。logo 保留 PNG 路径，从 1254×1254 缩到 256×256，覆盖现有 30–58px 显示与 Apple 图标用途。

验证：16 个静态资源均返回 HTTP 200 和正确图片 MIME；所有 WebP 文件头有效，均比原稿小。与原稿人工对照细节较多的剧本图及缩小后的 logo，浏览器实际确认创作九图、场景四图和首页首图均正常加载，CSS 背景改用 WebP，页面构图未改变。375 CSS 像素手机下首页首图选择 w=640，创作卡片选择 w=256，九图滚动后全部加载；首页无横向溢出，临时视口已恢复。

实际 HTTP 测量：手机首页首图优化结果为 15,858 bytes，创作图片入口 w=640 结果为 14,472 bytes（均 WebP）。这两项是单资源响应体大小，不当作整页加载耗时或全页流量结论。
