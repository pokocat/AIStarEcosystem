## 交付

| 项目 | 结果 |
|---|---|
| 分配与回收 | 单人/批量1–100人，先预览后确认、旧预览重验、正文幂等、整批原子；不回收冻结，不转个人或跨企业 |
| 人工充值 | 固定企业根钱包、金额/积分/凭据快照；重复核准和重复收款凭据不重复到账；保留个人原流程 |
| 原单退款 | 来源随划拨、冻结、FIFO消费和释放保留；仅退原单可用充值积分及原比例人民币，原单有冻结先等结算；归集/退款中途失败全部回滚 |
| 报表 | 待分配、成员可用、冻结、实耗分开；划拨不计收入/消费；流水和CSV保留企业、钱包及业务关联 |
| 页面 | Studio `/enterprise` 与后台充值订单的企业页均接真实API，沿用平台组件；普通成员仅本人数据 |

退款接口只登记人工现金退款事实，不自动打款。外部渠道与系统不是同一事务；凭据或金额不一致须人工对账，不可自动重复付款。自动退款预约、企业生成、停用/退出与完整成员管理不在本批。
