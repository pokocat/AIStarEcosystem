## 段落表达

*   **叙事要素**：这是一个典型的“换装转场”起始段。人物处于静止状态，通过躺姿展示服装全貌。动作极其微小（仅手臂微动），重点在于建立场景氛围和人物基准线。
*   **视觉变化**：画面几乎静止，唯一的动态来自光影的细微变化和人物呼吸带来的衣物起伏。这种静态是后续快速剪辑的基础。
*   **剪辑节奏**：单镜头长持，节奏舒缓平稳。没有切点，利用画面的稳定性让观众适应俯视视角。
