## 上线内容

- 新版导航加「灵感」，排在首页后面；新版手机「我的」里也有。旧版顶栏本来就有。
- `/templates` 默认显示案例，可筛视频、图片，搜索能搜到提示词。
- 点开案例是居中弹窗，不再全屏：左边看效果，右边是规格和需要准备的素材。**预览不显示提示词**，只读画布点开节点也不显示。点「做同款」才复制画布并进入，提示词在那里。
- 首页灵感新发布的在前：比发布日期，同一天的按运营排序，有成图的仍排在只有步骤的模板前面。`IpTemplate` 新增可空字段 `createdAt`。`/templates` 仍按运营排序。
- 做同款后助手打开并预填要求、绑定方法，发不发由用户决定。选填的素材位空着不挡生成。
- 服务端修复：发布官方示例时文字节点的正文不再被删；画面描述里的「不出现」「描写」「手写」不再把出图请求路由到写剧本；方案概述不能切到写作；素材概要读节点自己的画幅和时长。

每次发布前都核对过线上版本和 main 的差异：除上表内容外，DTO 和 openapi 只增加了 `createdAt`。

## 同一时段的线上故障：账号中心欠费停服（10:47–11:12）

不是发布引起的，但第五次发布的重启让它变重了。

- **根因**：阿里云账号 `1603478465921848` 余额到 -0.04 元，账号中心用的负载均衡 `alb-8lqfxfyvfyitbs3s6r` 的两个公网 IP 被按欠费锁定（`LockReason=financial`，负载均衡 `Inactive` / `RelatedResourceLocked`）。用户充值后 11:12 恢复，当时余额 4.96 元。
- **影响**：25 分钟内不能登录。10:47–10:52 已登录用户大约一半请求超时；10:52 重启之后几乎全部卡住，到超时才报错。公开页面正常，没有在跑的任务，服务端 0 条 ERROR，数据不受影响。
- **为什么重启后变重**：`IdentityTokenVerifier.decoder()` 第一次校验时才去账号中心取密钥，只存在内存里。取的时候持锁，且没有超时，所以其它请求全部排在锁后面（当时 13 个请求线程 `BLOCKED`）。重启前内存里还有密钥。
- **发布前为什么没发现**：只查了在跑的任务，没查账号中心是否可达。已加进发布顺序（AGENTS「生产发布顺序」）。
- **还要做**：见 TODO「账号中心断开时的登录校验」。账户余额按当前约 3.7 元 / 天的按量费用，4.96 元只够一天多，要继续充值并打开余额提醒。
