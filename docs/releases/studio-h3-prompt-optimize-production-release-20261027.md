# Studio：H3 视频提示词「智能优化」推到画布与创作助手（2026-10-27）

发布编号 `20261027-studio-h3-optimize`，服务 `server,web-aiavatar`，构建自远端 `main` `384dfe3159a9bf532842e399419b56032103ba40`（分支 `dev/studio-h3-prompt-optimize` 快进合入，基于当时线上的 `96eeec0a`）。

## 变更

上一版只有 AI 导演台在交给 H3 前把中文提示词改写成 MiniMax 官方写法。这一版把同一套改写（`resources/h3-skill`，官方 skill 原文未改）推到 Studio 画布和创作助手，并按用户的要求把所有检查改成「只提示、不拦人」。

- **画布卡片**：选 H3 时底部工具栏多一个「智能优化」按钮（默认开、浅紫色），不再收在「创作参数」里；价格写「N 积分 · 优化另需少量积分」。关掉后旁边提示「H3 建议开启，台词更完整」。其它视频模型不显示这个按钮。
- **创作助手**：制作计划里的 H3 视频步骤一律先优化再出片；计划报价包含优化的冻结上限，视频的上限 = 计划上限 − 优化实际花费。
- **检查不拦人**：优化稿检查全部通过 → 直接出片；有需要留意的地方（台词改了或漏了、引用了不存在的参考图等）→ 停下来，卡片上列出提示，用户选「用优化稿生成」或「用原文生成」；只有模型没返回能解析的结果才算失败，不扣改写费，可以重新优化或按原文生成。超过 7000 字符的优化稿只能按原文。
- **台词**：原文按「某某说：「…」」写的（助手照这个写），台词由代码原样填进去；用户自己写的提示词由模型按官方写法写台词，代码逐句按顺序核对原文。
- **导演台同步改成不拦人**：片段改写有提示时停在片段上让用户选；一键制作不停，可用就用优化稿，否则按原文。
- **计费**：改写按实际用量另扣，和视频在同一个任务里；改写完成后在一个事务里结算改写、提交视频，不会出现视频交了但改写没结算。只用模型赠款的用户也照常优化（用户定：以效果为准，积分不够自己取消）。厂商自带的智能优化仍关着。

无迁移、无新接口路径（`video.rewrite`、`promptChoice` 等为已有请求体上的可选字段，契约已同步）。

1. 只用赠款的用户被扣了普通积分 → 当时改成不优化；后按用户意见去掉这个特例（`8858f4f6`）。
