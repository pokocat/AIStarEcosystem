## 最终交互

- 固定底栏显示模型、参数摘要、费用和提交动作；模型使用轻量选项菜单，参数使用独立的分组浮层，正文不再因展开参数而增高。
- 图片比例用真实长宽关系的矩形预览与比例数字显示，消除“竖屏首帧”等用途混入比例的问题；清晰度附实际像素，数量来自模型能力。切比例保留所选清晰度档位。
- 视频模式、清晰度、比例、数量与时长使用同一套点选控件；首尾帧及参考素材留在正文。剧本/分镜、文本、配音、口型和解析统一模型/参数入口。
- 浮层跟随当前工作区，限制可用高度并内部滚动；手机沿用 data-layout，Esc 收起浮层、返回焦点，方向键跳过禁用项。
- 此次只改前端配置交互，不新增供应商能力、价格、后端协议或数据库迁移；渠道 2K 尺寸限制仍以 GPT Image 接入发布记录为准。
