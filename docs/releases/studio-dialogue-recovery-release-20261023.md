## 修复

线上用户两轮（`IPR-b84f128b6fb546749283`、`IPR-2f77de9fb21d4ed59221`）均有完整剧本文字，但模型将动作 JSON 多写一个 `}`；三次格式纠正无效，0 次工具执行后显示“这一轮没能执行，请再说一次”。
