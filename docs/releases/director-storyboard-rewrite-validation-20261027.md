# AI 导演台：分镜页重写入口、一键制作无反应、本集摘要（2026-10-27 本地验收）

分支 `fix/director-storyboard-prompts`，基于 main `e5d96aab`。**本地验收通过，未发布**（这次不做部署）。截图在同名目录。

## 用户反馈

1. 分镜页没有单独对整集或某个分镜重新生成提示词的地方；「一键制作」里能选「分镜脚本」，但点了没反应。
2. 剧本页分集展开后「本集摘要」只有一行，摘要长了后面的看不到。

## 根因

**分镜脚本和提示词是什么关系**：每个片段的分镜脚本是一组镜头（景别、机位、动作、静态帧、台词），外加标题、摘要、关联资产。分镜图提示词和视频提示词由代码按镜头和资产编出来（`DirectorService.refresh` → `DirectorPrompts.boardPrompt / videoPrompt`），不调模型。用户手改过提示词时，改后的提示词不再跟着镜头变。所以「重新生成提示词」就是让 AI 重写分镜脚本，提示词随之重新编出来。

**没有入口**：原来只有工具栏上一个小的文字按钮「重写分镜脚本」，它把整集重新切分、替换全部片段。本集只要有一个片段出过分镜图或视频，这个按钮就是灰的（悬停提示「请先删除已有分镜图的片段」）。用户截图那一集「分镜图 2/4 · 视频 1/4」，正好是这种状态。单个片段则完全没有重写入口。

**一键制作 → 分镜脚本「没反应」**：功能是通的，但它只补还没做的步骤。所选范围的每一集都写过分镜脚本时，点「开始」会建一条连跑，第一步推进就发现无事可做，立刻标成「已完成」，没发任何任务、没花积分。页面上的反馈只有：弹窗关掉，状态线里多一行小灰字「已完成　分镜脚本已完成：2 集 2 个片段」。弹窗里本来就写着「文字生成 0 次」，主按钮仍然是「按推荐预算开始」。修复前已在本地复现，截图 `before-oneclick-1-dialog.jpg`、`before-oneclick-2-after-start.jpg`。属于「启动后立即判完成」：没有失败，也不是任务在跑却没提示，而是根本没有要做的事，界面却没说。

**本集摘要**：控件是 `<input>`（单行），文字只能横向滚动（宽 622 px，内容宽 1660 px）。手机上折叠行的摘要预览被隐藏，单行框只露出约 15 个字。截图 `before-summary-desktop.png`、`before-summary-mobile.png`。

## 修复

- **整集重写**：分镜页工具栏改成显眼的「重写分镜脚本」按钮，点开弹窗。弹窗写明范围：「只改文字，不会出图、不会生成视频，其他集不受影响」。有两种做法：
  - 「保留现有 N 个片段，逐段重写」，默认选中，新任务 `reshoot`。片段 id、数量、顺序不变，每段换一套镜头。已有分镜图和视频留在历史版本里，标成「需更新」。
  - 「重新切分片段」，就是原来的 `plan`。本集有分镜图或视频时不可选，旁边写明是哪几段、为什么。
  - 弹窗列出会被替换的内容：手改过的视频或分镜图提示词、还没保存的修改。
- **单段重写**：每张片段卡头部加「重写」按钮。确认框写明「只改这一段的文字，不会出图、不会生成视频，其他片段不变」，并列出这一段手改过、会被替换的提示词。
- **重写的规则**（服务端 `reshoot`）：只换要重写片段的镜头、标题、摘要、关联资产，提示词回到随镜头自动生成。台词原文、顺序、说话人都不变，也不挪到别的片段。
  - 模型拿到的输入：要重写的片段只给摘要、时长和台词，不给旧镜头；其他片段的镜头照给，只作前后衔接的参考。
  - 冲突处理：同集正在写或重写、片段正在出分镜图或视频时，返回 409 并说明原因。重写期间用户改过的片段，新版本挂在 `pendingShots` 上，用户自己选「换成新版本」或「保留现有」。
  - 失败处理：失败原因写在本集的错误提示里，单段失败会注明是哪一段，冻结的积分按原规则退回。
- **不能操作时点了也有回应**：片段在出分镜图、出视频，或镜头编辑区开着时，「重写」按钮仍然可以点，点了弹出原因，不再是一个点了没反应的灰按钮。整集重写在跑时，每张片段卡标题旁显示「重写中」；单段重写的片段卡上显示「AI 正在重写片段 N 的分镜脚本」。
- **一键制作**：
  - 弹窗选「分镜脚本」时，估算里一次文字生成都没有，就直接写明「全部 2 集的分镜脚本都已写好……要重写，请到「分镜」点「重写分镜脚本」（整集），或在片段上点「重写」（单段）」。这时不显示预算卡，主按钮换成「前往分镜」。
  - 服务端兜底：start 时什么都不用做，就不建连跑，返回 409 `DIRECTOR_PIPELINE_NOTHING_TO_DO` 并给出原因，弹窗保持打开显示这段话。这条对四个目标都适用。
  - 防重复提交：启动按钮在提交中锁住，连点两次只发一个请求。
- **本集摘要**：改成多行框（`GrowTextarea`）。
  - 高度：最低约 3 行（72px），随内容长高，最高 40vh，再长出滚动条，右下角可以拖高。
  - 不横向滚动，保留换行。折叠行照旧显示一行预览，展开就是全文。
  - 内容不截短，字号不变。

### 真模型：线上同款聚算 qwen38-27b，本地后端加开发库副本

| 场景 | 结果 |
|---|---|
| 新建两集作品，一键制作选「分镜脚本」 | 提交后显示「制作中」，174 秒完成：提取资产、两集分镜脚本，共 6 积分（`r-1`） |
| 整集重写第 1 集 | 85 至 106 秒，3 积分。片段 id 和顺序不变，镜头确实换了，台词逐字保留，无「需修改」项，第 2 集不变（`r-2-*`） |
| 整集重写进行中，再发单段重写 | 界面上片段卡已换成「重写中」，没有按钮可点。直接调接口返回 409 `DIRECTOR_TASK_RUNNING`「本集正在重写分镜脚本，完成后再试」 |
| 单段重写片段 2 | 49 至 59 秒，2 积分。只改片段 2，片段 1 一字不差，台词原样（`r-3-*`） |
| 刷新页面 | 结果还在 |
| 上游一次无响应 | 本地经中转约 290 秒没有返回任何数据，任务按失败结束，冻结的 21 积分全额退回。页面显示「片段 2 重写失败：AI 生成失败，请稍后重试」（`r-3-clip-rewrite-failed-upstream`）。之后重试成功 |

**真模型调用发现并已修的问题**：第一版把要重写片段的旧镜头原样交给了模型，整集重写回来的结果几乎照抄：第 2 段一字未改，第 1 段只改了时长。改成只给摘要、时长和台词，并在提示词里写明「这是重写，要给出一版新的拍法」。复测后两段的拆分、景别、机位、动作都换了，台词仍然逐字保留。

**真模型的已知不足**（记入 TODO，不拦这次修复）：
- 重写后偶尔出现 5–6 秒的长镜头。
- 有一镜 4 秒放了 21 字台词，超过每秒 4 字。
- 出现「压抑感」这类抽象词。
- `shotWarnings` 会在卡片上提示这些问题，但不拦截出图。写分镜脚本本身（`plan`）也有同样的现象。
