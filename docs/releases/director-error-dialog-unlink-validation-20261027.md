# AI 导演台：操作失败改用错误弹窗；资产解除关联闭环（2026-10-27 本地验收）

分支 `fix/director-storyboard-prompts`，基于 main `c3978d92`。**本地验收通过**；第二轮（Studio 其他页面统一、慢供应商验收、main 上两条红测试）见文末「第二轮」，发布记录另见 `director-error-dialog-unlink-production-release-20261027.md`。截图在同名目录，`before-` 开头的是修复前。所有验收都用本地可丢弃的测试作品（测试模式，固定样例，不调模型、不扣积分），没有改动任何线上作品。

## 用户反馈

1. 「该资产仍被片段使用，请先取消关联」只是页面上有个横幅，应该是错误弹窗；其他同类错误也查一遍。
2. 系统上好像也没有可以删掉关联的地方（这里指解除资产和片段的引用，不是删除片段）。

## 修复前（本地复现）

- **报错位置**：在资产详情里删除被引用的「林夏」，服务端拒绝后，只在页面顶部出现一行横幅「该资产仍被片段使用，请先取消关联」。
  - 桌面上，横幅被资产详情抽屉的遮罩挡住（`err-before-delete-desktop`）。
  - 手机上，资产详情是全屏抽屉，横幅被整个挡住，点了删除什么都看不到（`err-before-delete-mobile`）。
  - 报错里也没说是哪些片段在用。
- **不只是删除**：资产详情抽屉、片段「关联资产」「视频」抽屉里的所有操作（生成、上传、采用、确认、保存……），失败时都落到这同一条被挡住的横幅上。
- **解除关联的入口**：片段卡上「关联资产」打开的抽屉只能看，没有解除按钮（`err-before-clip-assets-drawer`）。唯一能去掉关联的地方，是「编辑镜头」里一排勾选框：取消勾选再保存。资产页和报错都没有指向这里。
- **还有一处没算进去**：资产如果是某句台词的说话人，旧的删除检查不把它算作引用。删掉后这些台词就没有了说话人，片段会被标成「需修改」。

## 修复

### 1. 统一的错误弹窗

位置在 `src/ip/studio-errors.tsx`，接口是 `openStudioFailure` / `useStudioFailure`，基于 antd 的确认框样式：
- 标题写「X 没有完成」，X 是具体操作，比如「删除「林夏」」「保存「旧书店」的修改」「删除片段 1」。
- 正文分三块：
  - 原因：服务端的原话。网络中断时写成「网络连接中断，没收到服务器的回应」，不显示英文的 Failed to fetch。
  - 下一步：按错误码给一句默认说法，调用方可以写得更具体。
  - 可展开的「错误详情」：错误码、logId，可以复制。
- 可以关闭，长文本可以滚动、可以选中。
- 同一个操作的同一个错误还开着时，不再弹第二个。
- 冲突类错误（别处改过）：导演台会先把作品刷新到最新，弹窗的下一步第一句写「页面已经刷新到最新内容」；调用方写的下一步（比如「改动还在编辑框里」）跟在后面。

### 2. 导演台的接法

- 工作台的 `setError` 改为打开这个弹窗，页面顶部那条操作错误横幅删掉了。
- 每个调用点都用 `failed(setError, "操作名")` 标明是哪个操作，共约 50 处，覆盖：
  - 剧本：生成、保存、拆分、作为一集、提取资产、设定资料。
  - 资产：生成参考图、批量生成参考图、上传、采用、确认、保存、恢复自动提示词、形象参考、删除。
  - 分镜：写分镜脚本、重写、批量生成、删除片段、保存提示词、采用和确认视频、声音参考、导出。
  - 一键制作：暂停、继续、确认、停止。
  - 其他：停止文字任务、改作品名、关闭提示。
- 批量操作里部分没提交成功时，弹窗列出哪几项、为什么，并说明其余的已经开始生成。

### 3. 保持原样的

- **已经打开的操作弹窗里的失败，仍在那个弹窗里就地显示**，不另弹一个。涉及：
  - 一键制作、重写分镜脚本、重新生成剧本、撤销拆分、分镜图、确认资产清单、角色音色、新建作品、导入剧本这几个弹窗。
  - 作品设置弹层：原来报错会落到页面上，现在改为在弹层里显示「设置没有保存：…改动还在」。
- **后台任务失败、持续状态照旧**：
  - 任务失败按原样就地显示，包括写分镜脚本失败、出图失败、`work.notice` 的结果提示。
  - 后台轮询不调用 `setError`，所以同一个错误不会反复弹出。

### 4. 资产引用和解除关联（服务端）

- **删除时的引用检查**：`asset.delete` 有引用时返回 409 `DIRECTOR_ASSET_IN_USE`。`details.clips` 逐个列出用到它的片段：集号、片段序号、标题、是否在关联资产里、有几句台词。台词说话人也算引用。资产不删，也不自动解除任何引用。
- **新增 `clip.unlinkAsset`**，只把这一项从这一个片段的关联资产里去掉：
  - 其余资产的顺序不变，参考图「图N」的编号跟着顺序走。
  - 不删片段、不删资产，不动别的片段。
  - 已有的分镜图和视频不删，按指纹标成「需更新」。
  - 台词说话人不改。
  - 不在关联里时返回 409 `DIRECTOR_EDIT_CONFLICT`；片段正在出分镜图或视频时返回 409 `DIRECTOR_TASK_RUNNING`。

### 5. 资产引用和解除关联（页面）

- **资产详情**：新增「用在哪些片段」，每个片段一行，写明是关联资产还是 N 句台词，带「前往」按钮。
- **删除被挡时**：如果本地数据已经能看出有引用，直接弹错误弹窗，列出同样的片段和「前往」，不发删除请求。如果本地数据过时、没看出引用，就照常确认后请求服务端，服务端拒绝时用它返回的片段列表弹同一个弹窗。
- **「前往」之后**：
  - 跳到那个片段所在的集，并滚动到片段。
  - 关联资产的引用：打开「关联资产」抽屉，要处理的那一项描边高亮。
  - 只在台词里出现的引用：直接打开「编辑镜头」，在里面换说话人。
- **「关联资产」抽屉**：每项资产都有「解除关联」按钮。确认框会说明影响：
  - 只去掉这一项。
  - 已有分镜图或视频不删除，会标成「需更新」。
  - 这一段里还有他的几句台词，台词不变。
  - 手改过的提示词不会自动更新。
- **解除之后**：抽屉里提示「已不在这个片段的关联资产里」，并说明其他片段是否还在用，附「回到资产页」按钮。

### 6. Studio 其他页面

- 第一轮只改了首页（桌面 IpHome、手机 StudioHome）的新建画布失败：原来只在页面中部挂一行字，现在改为错误弹窗，输入的那句话保留，可以直接重试。
- 其余页面原本走右上角「操作未完成」提示框，第二轮统一成错误弹窗，见文末「第二轮」。

## 第二轮（2026-10-27）：Studio 其他页面统一成错误弹窗，补验收，修 main 上两条红测试

### 统一的错误出口

全站约 300 处报错都经 `reportStudioError`（直接调用、`useStudioErrorState`、`StudioErrorNotice`、`useStudioApp().message.error`）。这一轮不逐处改，而是改这个出口本身（`src/ip/studio-errors.tsx`）：

- **用户刚点了按钮 / 菜单项 / 提交，之后报上来的第一个错误**，按「那个操作没做成」弹错误弹窗。标题用控件上的字（「「新建画布」没有完成」）；确认框里的「确定」「确认删除」这类按钮换成弹窗标题（「删除画布没有完成」）。知道更准操作名的地方直接传 `action`。
- **没有这样的操作**（页面加载、轮询、媒体加载、自动保存、换了页面、这次点击已经算过一个错误）照旧右上角提示。自动保存失败、旧任务恢复失败显式标 `background`；任务轮询、媒体加载原本就是 `once`，按后台处理。所以后台状态不会因为轮询反复弹窗。
- 下拉选项、开关、勾选框是选择不是操作；带 `aria-expanded` / `aria-haspopup` 的按钮只是打开菜单，都不算。拖进 / 粘贴文件（不在输入框里）算一次上传操作。
- **打开着的弹窗或浮层已经把这条错误写出来了**（在弹窗里点的操作，或点了打开弹窗后弹窗里读取失败），不再叠一个弹窗，也不再挂右上角提示。关着但还留在页面里的弹窗不算。
- 同一个错误开着时不弹第二个，不论从哪条路报上来。「查看错误详情」打开详情弹窗（原因、下一步、错误码、logId，可复制），不再算一次失败。
- 弹窗层级 1400，高于画布浮层、抽屉和下拉（最高 1300）。可关闭的弹窗标题给右上角关闭按钮让出位置，窄屏长标题不再压在 × 下面。
- 下一步按错误码给：冲突类只有导演台（会先刷新作品）说「页面已经刷新到最新内容」，别的页面请用户刷新；`*_NOT_FOUND` 说「这项内容已经不在了…刷新页面看一下」，不再叫人重试；`*_RUNNING` 说等进行中的那一项完成。

绕开这个出口的几处一并接上：

- 搬来的画布（`canvas/` 下三个文件）原来用 antd 顶部 message 报错，改用 `useStudioApp()`（文件头留了改动注释）。
- 手机账号页（`proto`）的底部黑条 `toast(…, {tone:'err'})` 统一交给出口，提示类（warn / ok）不变。
- 官方示例管理（`/projects/demos`）三个操作的失败、企业页的操作失败、资产详情「建卡」、卡片人设对话都交给出口；企业页弹窗里的错误仍在弹窗里就地显示。

### main 上两条红测试的根因

`personal-asset-library.test.tsx` 与 `studio-template-source.test.tsx` 把 `@ai-star-eco/api-client` 包根整个 mock 掉，而 `studio-errors.tsx` 从包根引入 `publicModelErrorMessage`。测试里一报错，整理错误这一步就抛「mock 上没有这个导出」，错误永远显示不出来，断言找不到提示，还多出两个未处理错误。改为从子路径 `@ai-star-eco/api-client/public-model-error` 引入（`package.json` 加了这个导出，导演台与对话里同样的引用一起改）；测试没动、没跳过，两条现在通过。
