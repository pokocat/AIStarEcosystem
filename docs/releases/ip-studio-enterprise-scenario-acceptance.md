# 企业积分管理：产品场景验收

> 本地确定性供应商、隔离数据库；不调用付费生成，不向真实企业充值。下表记录操作、预期和已执行证据；浏览器未覆盖的分支明确由服务端测试验证。生产验收独立记录。

| 场景 | 用户操作 | 必须看到的结果 | 证据 |
|---|---|---|---|
| S01 建企业、邀请成员 | 已开通主账号建企业，复制邀请；另一已开通用户接受 | 独立登录、一个当前企业、零初始企业余额；个人余额和开通不变 | Foundation 集成测试；实页完成创建、邀请、接受和撤销 |
| S02 邀请冲突与开通 | 未开通者接受；两家企业同时邀请同一人 | 不通过邀请开通产品；最多一个当前关系，拒绝越权 | Foundation H2/MySQL |
| S03 管理员权限 | owner 授予管理员能力；管理员尝试提权或操作 owner/同级 | 可管理普通成员，不能管理自己或更高权限，不能进入平台财务 | Foundation/Points/Lifecycle 集成测试；实页授权管理员、本人/主账号不可选 |
| S04 收款与分配 | 财务登记人民币、积分、凭据并核准；owner 批量分配 | 只入企业主钱包；分配等额出入，不记第二次充值；刷新可核对 | Recharge/Points 测试；实页模拟100元/1000积分、批量两人各200 |
| S05 显式付款 | 同一成员用个人、企业分别生成 | 确认框显示本次付款、余额、预计费；仅所选账户变化；不足不混扣 | 实际HTTP生成测试；实页企业扣8/个人不变、停用后个人生成通过 |
| S06 全入口与实际计价 | 图片、文本、配音、口型、视频、素材库和模板入口 | 每个收费引用有一个付款授权；视频包装不二次冻结；仍检查私有资源归属 | 入口映射；专项集成与 worker 测试 |
| S07 模型与容量 | 选未允许模型、并发发任务、零积分任务占满上限 | 冻结前拒绝未授权模型；排队/受理未知/零费任务均占位，不超限 | Studio/Video/Lifecycle 集成测试，含并发和零价任务 |
| S08 失败与部分成功 | 两张图仅第一张成功；文本实耗低于预估；视频失败 | 仅成功或实际用量扣费，未用额按原桶释放；重复终态无重复账 | 本地 HTTP 供应商 + 真实账本测试 |
| S09 停用排队成员 | 有可用额与未派发任务时停用 | 先禁新任务，取消未派发任务，回收全部可用额；个人自费仍可用 | Lifecycle 集成测试；实页停用回收192、个人自费生成通过 |
| S10 停用后恢复 | 已受理任务未完时停用，再恢复并另发积分 | 老任务仍按原授权结算；老退款归企业，新分配留成员 | Lifecycle 集成测试；实页恢复后不自动分配 |
| S11 退出后重入/换企业 | 已受理任务冻结时退出，重入原企业或加入新企业 | 旧冻结不搬家；旧退款按原来源/桶回原企业，不能取走新关系资金 | Lifecycle H2/MySQL |
| S12 供应商中断与重启 | 已有供应商 ID 后轮询失败或 worker 重启 | 继续查询原任务，保留冻结/容量；不重提；已受理结果恢复后只结一次 | 图片/视频恢复专项测试 |
| S13 无 ID 的受理未知 | 超时后无供应商任务号；运营核对原凭据再补原 ID | 保留冻结；补原ID后只查原任务。若供应商明确证明未受理，须显式确认并保存依据后仅退原剩余冻结；不退已成功部分，不重生成 | 管理端专项及财务角色403；实页两张图片/一条视频核对，46冻结释放、未重提 |
| S14 主账号移交与退出 | 发起移交、接收者确认、原 owner 退出 | 唯一 owner；原充值目标仍为企业，不能随原 owner 变个人资产 | Foundation/Recharge/Lifecycle 测试；实页双向移交完成，钱包主体不变 |
| S15 关闭企业 | 有在途、余额或待核准申请时关闭，再处理为空 | 有阻断原因；清空后才能关闭，释放当前归属，历史账可查 | Lifecycle 集成测试；实页992可用余额阻止关闭，未强行清账 |
