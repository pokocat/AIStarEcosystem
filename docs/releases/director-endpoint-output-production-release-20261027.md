新规则由 `StudioWorkflowService.endpointChatRate` 共用：

1. 有端点 `defaultMaxTokens` 时使用该默认值，并受端点 `chatMaxOutputTokens` 上限约束。
2. 默认值未配置时读取端点能力上限；端点两项均未配置，才回落后台 Token 售价的 maxOutputTokens。
3. Token 单价和输入预算仍按后台售价配置；输出预算按端点形成受理时的费率快照，即使旧售价配置的输出预算较低，也不会悄悄压低已明确配置的端点预算。
4. 模型列表里的费率、导演台估价、最大冻结、实际请求、实际用量结算使用同一有效输出预算。调用方 maxCost 仍校验，预算不够明确拒绝，不自动增加获批费用。
5. 画布、助手、导演台的视频提示词优化继续读取独立用途绑定；普通文字任务仍使用作品文字模型。旧任务保存的端点、预算不改，不自动重试。
