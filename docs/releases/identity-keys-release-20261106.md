## 为什么发

上午账号中心因欠费断开，10:52 的重启让已登录用户全部卡住，见 [灵感库发布记录](inspiration-library-release-20261106.md)。原因：校验登录用的公钥第一次用到时才取，持锁、没有超时，只存在内存里。排查时还发现，依赖库自带的公钥缓存 15 分钟过期，断开时间一长，不重启也可能校验失败。

## 上线内容

- 公钥存进平台配置 `identity.jwks-cache`，启动时先读，账号中心断开也能重启。只有公钥，后台不能改也不能删。库里的 issuer 与当前不同就不用。
- 校验令牌不再连账号中心。后台每 5 分钟取一次，取到才替换；取不到、回错误、回空集合都继续用旧的。
- 令牌的 kid 不认识时才去取，最多每 10 秒一次，请求最多等 3 秒，不持锁。取到了还不认识就是无效令牌（401）；取不到回 503 `IDENTITY_UNAVAILABLE`，前端保留登录状态并显示重试。
- 同步手机号和昵称连不上账号中心时，每 30 秒只放一个请求去试，其余直接通过，超时也管到正文。

没有迁移，DTO 和 openapi 没有变化。线上到 main 的服务端差异只有这次修复。

## 窗口

- 发布前：账号中心 200；有一个文字任务和一个视频任务在跑，等到 13:42 全部结束才重启。
- 重启期间 API 共 16 个 502：部署探测 6 个，用户请求 10 个（读对话 6、钱包 3、企业 1）。verify 全绿，启动后 0 条 ERROR。

## 线上验收（13:43–13:46）

- 启动时日志写「库里还没有验签公钥」，约 6 秒后写「验签公钥已更新 kids=[id-2026-09]」。库里那行 issuer 是 `https://id.aibuzz.cn`，不含私钥字段。
- 伪造令牌都回 401，耗时约 0.05 秒：同 kid 但别的钥匙签的、没发布过的 kid。不带令牌也是 401。
- 真实令牌：超管账号打开 `/projects`。页面里那份令牌已过期，先收到 401，自动换了新令牌（RS256，kid `id-2026-09`，有效期 60 分钟），之后 `/api/me` 和画布列表都是 200。
- 启动后到 13:45 共 91 个 200、8 个 401：3 个是上面的探测，5 个是超管页面令牌过期时的第一批请求。没有其他用户被拒，也没有 503。

## 运行到当晚 22:31

没有重启，`app.jar` 校验和不变。API 没有 500、502、503、504，最近 30 分钟 2028 个 200；另有 22 个 499（用户断开，13 个是对话事件流）。取公钥失败 0 次，库里的公钥行还是第 1 版。

## 本地验证

用真实服务端配一个模拟账号中心。`dev` 下无效令牌会被自动登录成种子账号，所以核对的是 `/api/me` 返回的账号，不只看状态码。

| 情况 | 结果 | 最慢耗时 |
|---|---|---|
| 账号中心不回话，服务端重启，40 并发 | 全部是令牌里的账号 | 0.14 秒 |
| 账号中心完全断开，服务端重启，40 并发 | 全部是令牌里的账号 | 0.13 秒 |
| 库里没有公钥，账号中心也断开，16 并发 | 全部 503 `IDENTITY_UNAVAILABLE` | 0.12 秒 |
| 刚断开时的第一批请求（要同步资料），40 并发 | 全部通过，多等约 3 秒 | 3.06 秒 |
| 紧接着的一批 | 全部通过 | 0.06 秒 |
| 过 30 秒后的一批 | 全部通过，最慢的多等约 3 秒 | 3.09 秒 |

## 没有验证的

- **没有在线上真的断开账号中心重启**。下一次重启的日志应该写「已载入库里的验签公钥」，这时才算线上走通了从库读取。
- 账号中心换钥、恢复后不重启就能用：只有单元测试（真实网络请求和真实校验）。本地实测那轮没核对账号，重跑时另一个聊天占了服务名额。
- 503 时的前端重试页没在浏览器里点过，只有单元测试确认不会判成未登录。
