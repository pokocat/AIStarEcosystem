## 上线内容

- **一个素材位可以放多张**，张数和用途配在场景目录里，运营后台能改。11 个场景照茂隆的技能配置，比如服装上身分模特、上身/全身装和下装；茂隆没有的场景按用途推断。取代当天下午发布的 `sameAs`。
