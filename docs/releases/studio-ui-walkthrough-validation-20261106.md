## 走查中修复的问题

- 手机页面水合失败：`useIdentity` 首帧用了 `/api/me` 缓存，和服务端不一致，整棵树被重建。首帧改为和服务端一样。
- 导演台工作台的「回到旧版」压住「创作助手」，工作台不再显示这个悬浮开关。
- 助手建议写死了别的作品的角色名「陈德茂」，改为当前作品的角色。
- 视频任务把整理方案和检查结果写进画布，项目封面会露出 JSON。这两类结果不再写入画布。
- 手机画布设备提示还是旧 H5 的青色按钮，改为深墨主按钮，返回文字改为「返回项目」。
- 手机导演台列表的操作按钮竖排挤在右侧，改到标题下方。
- 手机画布任务返回条压住工具和缩放条，改为靠右。
- 画布冲突弹窗用了 antd 已废弃的 `maskClosable`，开发环境会报 1 条错误，已改为 `mask.closable`。
- 费用确认弹窗显示「−0 积分」和没有折扣时的「折后费用」，这两行只在有值时显示。
- 文案：「回到 AI 视频继续」改为「在 AI 视频中打开」，「不用这个结果」改为「放弃拆分」，「提交重新生成」改为「重新生成」，「去创作」改为「开始创作」。

## 复验

修复后在新标签页干净复测：手机 `/assets`、`/projects` 没有水合错误；导演台工作台不再显示悬浮开关，助手建议用当前作品的角色名；手机任务返回条在 x 52–363，不压左栏工具和缩放条。全部测试（1772 条）和类型检查通过。没有再完整重走一遍所有页面。
