# AI 艺人孵化演示同步第二版发布（2026-11-07）

## 发布了什么

- **地址**：https://incubator.aibuzz.cn
- **服务**：只发 `web-incubator`，09:04 CST 重启。其他服务没有重启。
- **制品**：`20261107-incubator-v2`，从 main `1fcca9363` 在仓外干净工作区 `../AIStarEcosystem-release-incubator` 构建。
- **内容**：设计方 11-05 的第二版压缩包。工作台导航重排为七组加页签，新增总览、AI 图片、AI 视频，导演台支持多项目和画布 / 流程两种浏览，真人切片、AI 数字人、混剪批量重做，全系统默认暗色、可切亮色。

## 怎么合并的

以第一版压缩包为基准，「我们搬入时的代码」和「第二版」做三方合并：118 个文件自动合并，10 个有冲突的手工解决，新增 27 个，删除 8 个不再用到的。

保留的修改：语言固定中文、去掉原生弹窗、手机宽度适配、地址栏同步、运营后台入口、演示数据角标。

## 相对设计包额外改的

- **真实艺人**：设计包已换掉大部分，但明星签约和账单页还有三位，换成虚拟：贾乃亮→周景行、郝邵文→许知遥、李立群→程远山。上线后的页面代码里已搜不到这些名字，也没有 SK-II、Jo Malone、三只松鼠。
- **图片**：设计包仍用 Unsplash，共 161 张，有 36 张是新的。全部换成自托管生成图，共 177 张（`public/images/`，8.2MB）：新生成 41 张（AI 视频 21 张、AI 图片 17 张、数字人背景 3 张）。明星图文件名跟着新名字改了。
- **暗色下的弹窗**：设计包把 `bg-gray-900/800` 一律反转成浅色，本意是深色按钮，结果 ⌘K 面板和所有旧弹窗、面板、进度条底都成了浅底白字。反转已限定到按钮和链接。
- **暗色下的琥珀按钮**：`text-black` 被改成浅色，小程序的「制作」、账单的「立即充值」成了白字配琥珀底。现在只有白底才跟着变。
- **其他对比度**：批量工具和 AI 创作不可点的生成按钮（白字配淡紫）、亮色下落地页目标卡片、孵化向导的步骤标签、几处过淡的提示字。

## 线上验收

用无头 Chrome 按真实域名访问：

- 暗色和亮色各走一遍：12 个入口（桌面和手机 375）、工作台 14 个菜单和全部页签（桌面），共 150 个页面。没有裂图、页面报错、控制台错误、外部图片请求，也没有横向滚动。
- 真实点击走通：AI 视频选场景、生成、发到导演台；AI 图片生成；导演台切流程、新建项目；三个批量工具打开；底色切换并在刷新后保持；⌘K 搜索跳到内容日历；孵化向导打开；手机宽度打开制作工坊。
- 暗色下打开了旧弹窗（⌘K、艺人详情、后台审核）看过，已是深色底。这一轮是在本地发布包上看的，线上走查只跑了 ⌘K。
- 177 张图请求都返回 200。浏览器实际加载到 129 张，其余在没展开的场景分组、形象锻造模板、小程序深层页面里。
