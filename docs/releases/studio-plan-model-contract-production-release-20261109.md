# 制作计划模型选择与清晰度合同修复 · 2026-11-09

## 故障与修复

北京时间 16:15（IPR-44389154cf174b9886cc）及 17:07（IPR-f3668b3ba3ff40c78984），制作计划报价报 `VIDEO_STUDIO_SPEC_INVALID`「清晰度只能选 768p 或 544p」。原始模型回复实际选择 Seedance 与 720p，但把端点放在 `settings.video.model`；计划清洗同时也没有保留标准位置 `settings.model`，报价因此使用默认 H3。这是平台解析问题，未提交到视频供应商，不是供应商新增限制。

图片、视频制作步骤统一保留 `settings.model`；视频兼容读取嵌套的旧写法，归一后只保存标准字段。两处不同、类型错误或空白的明确选择直接拒绝，不静默换用默认模型。报价与执行继续共用 `StudioPlanSteps`、场景策略及端点合同，未指定模型的旧计划沿用平台默认模型。计划提示明确模型字段位置，并要求模式、清晰度、画幅及时间来自所选模型同一份合同。接口与模板类型移除 H3 专属清晰度枚举，声明为所选端点的合同标识；没有新增全局清晰度配置或修改模型售价。
