## 1. 小云雀实际长什么样（走查记录）

### 1.1 整体骨架
- 进到一部剧之后，最左边是一条 56px 的**图标竖条**：剧本（书）、资产库（文件夹）、分集视频（播放键）三格，当前那格深底高亮；
  底部是帮助、通知、头像。原来的全站侧栏不出现。
- 顶栏：左边剧名；右边是**全剧风格**（如「90 年代写实电影风格」）、**画幅**（16:9 ▾）、积分余额和会员档。
- 每一步做完，屏幕下方中间浮着一条深色提示条：「角色和场景设定会应用到整部剧集中，建议调整完毕后再继续哦　←　下一步 →」。
  在画布上则是右下角一个按钮：「确认角色和场景后，进入分镜脚本生成 →」。

### 1.2 入口（新建）
- 大标题「短剧 Agent 2.0」+ 一张大卡片，卡片上方四个页签：**上传剧本 / 剧本创作（限免 1 次）/ 重制转绘 / 创建画布**。
- 上传剧本：拖放区「上传剧本｜粘贴文本」，下面「风格 ▾」「比例 ▾」，右下「开始创作」。
- 剧本创作：左边一个「上传剧本 / 图 / 视频」参考位，右边输入框「上传素材或描述故事想法，AI 帮你写人物、结构与情节」；
  工具条：`+`、`@`、技能 ▾、选题 ▾、风格 ▾、比例 ▾、剧本模型（「ScriptBird · 国内剧本 · 10 集」）、字数「1/300 字」、发送。
  下面一排选题快捷卡（剧本医生、小说拆解、玄幻仙侠、都市恋爱……）。
- 风格 ▾ 是一个大浮层：左边分类（全部 / 真人 / 2D / 3D），右边带缩略图的风格格子（无风格、自定义风格提示词、中式古装影棚……）。

### 1.3 剧本页
- 标题「共 3 集」，右上 `···`。一张白色大卡片里三节，都能折叠：**原始创意**（用户那句话）/ **剧本摘要** / **分集剧本**（「收起全部」）。
- 分集剧本按集展开，集名后面有一把锁。正文是标准剧本格式：
  ```
  ### 场1-1
  日 内 旧教室
  出场人物：林微
  【字幕：2024 年，南方县城老中学，即将拆除】
  △ 阳光透过布满灰尘的窗户……
  同事（vo）：微姐，那男的条件真不错……
  林微（语气温和却不容置疑）：我习惯一个人了……
  【闪回】
  ```
- AI 写剧本分三段：故事设定 → 分集大纲 → 剧本正文，每段都有「通过 / 拒绝」，可以手改，有带时间的修改记录（手册）。

### 1.4 资产库 · 列表
- 标题「资产库」，右上「已识别 8 个角色」。页签：**角色 8 / 场景 12 / 3D 导演台 / 文本 / 图片 / 视频 / 音频 / 多轨编辑器**，右边搜索、「全集 ▾」、筛选。
- 角色卡：竖版全身立绘、左上「主角」绿标、名字、「2 个形象」。场景卡：横版图、名字、「2 个场景图」。
- **点一张角色卡 → 跳回画布**，高亮这个角色的所有形象、视口移过去，并打开出图面板。列表就是画布的目录。

### 1.5 资产库 · 画布
- 一打开就摆好了：每个角色一个灰底分组（组名 = 角色名），组里是它的几个形象卡；场景成组排在右边。
- 形象卡：上面是图（没图时灰色占位 + 「待生成」），下面两个小方钮（**音色**、**加号**），再下面「陈屹 - 基础形象 - 基础形象」和
  「出现集数：第 1, 2, 3 集」，右边 `···`。
- 普通节点：图片、文本（也能连线当参考）。连线 = 引用，被选中节点的上游线变紫。
- **选中形象卡 → 屏幕下方停一块出图面板**（不是贴在卡片下面）：
  - 正文是结构化的外貌描述：基本信息 / 面部特征 / 服饰装备 / 配饰 / 姿态构图 / 光影渲染，右上可放大编辑。
  - 底部一排：`+` 上传参考素材、`@` 素材引用、风格 ▾、模型 ▾（每个带一句说明）、
    「9:16 · 3K ▾」（清晰度 3K/4K + 比例 16:9 / 21:9 / 9:16 / 4:3 / 3:4 / 1:1）、**角色设计**、预设提示词、润色、「✦ 1」预计积分、发送。
- **角色设计**弹窗：六个页签的标签选择器，点选就往描述里写。
  - 基础：性别表达（女性 / 男性 / 中性）、年龄（18–22 / 23–28 / 29–35 / 36–45 / 46–60 / 60+）、区域 / 文化背景（东亚 / 东南亚 / 南亚 / 西亚·北非 / 欧洲 / 撒哈拉以南非洲 / 拉丁美洲 / 北美·大洋洲）、肤色（色块 + 自定义）、皮肤质感（原生肌理 / 通透清润 / 微雀斑 / 健康光泽 / 成熟肌理 / 干净哑光）
  - 妆容与穿搭：妆容（伪素颜 / 清透水光 / 冷感哑光 / 明艳红唇 / 无妆原生 / 清透底妆 / 自然修容）、服装（白色基础上衣 / 黑色基础上衣 / 简约白衬衫 / 低饱和针织）、配饰（小银耳饰 / 无配饰 / 珍珠耳钉 / 金色耳圈 / 细框眼镜 / 简约腕表 / 小耳钉）
  - 五官：脸型（柔和鹅蛋脸 / 流畅瓜子脸 / 利落方脸 / 幼态圆脸 …）、面部风格（柔和自然 / 浓颜立体 / 清冷疏离 / 英气利落 …）、骨相（自然柔和 / 高颧骨留白 / 清晰下颌 …）、鼻型、唇形
  - 体型：高挑纤细 / 匀称健康 / 小骨架纤薄 / 修长有力 / 丰润柔和 / 肩背挺拔 / 纤细修长
  - 发型：发型（法式层次锁骨发 / 水波纹流苏波波 / 高颅顶半扎发 / 碎盖 / Clean Fit 短发 …）、发色（色块 + 自定义）
  - 风格：表情状态（轻微浅笑 / 恬静放空 / 平静正视 / 若有所思 / 自信微笑 / 沉静思考 / 自信克制）、摄影方案（白底定妆 / 浅灰影棚 / 米白柔光 / 正面半身 / 轻转十五度 / 证件式特写）
- **形象详情**（`···` 或音色钮）：左边这个形象的图（「主图」角标，下面「上传素材 / 拼图」）；右边
  角色名称（可挂到「已有角色」下）、形象名称、出现集数（多选）、形象音色（文本音色 / 音频音色：上传音频 / AI 生成 / 绑定已有音频）。
- 左下工具条：资产管理（抽屉：按分组列出全部资产，「共 24 项」）、重置视角、隐藏连线、只看角色和场景、小地图、触控板 / 鼠标模式、缩放。
- 底部中间：添加节点（角色 / 场景 / 3D 导演台 / 文本 / 图片 / 视频 / 音频 / 多轨编辑器）、**角色库**（全屏预设角色大库）、使用教程、快捷键、指针。

### 1.6 分集视频（逐集列表）
- 「分集视频」，下面「共 3 集｜分镜脚本生成 100 字符消耗 2 积分，以实际生成为准」，右上「+ 新增一集」「批量」。
- 每集一张横卡：封面 + 时长角标、状态（未生成 / 已完成…）、「第 1 集：旧教室重逢揭尘封往事」、「角色 4 · 场景 3 · 分镜视频 10/10」、
  三个钮：预览 / 编辑 / 下载。还没做的集是「编辑」+ `···`。

### 1.7 单集编辑器
- 顶栏：「分集视频 / 第 1 集 · 第一集」面包屑；视频模型 ▾、清晰度 ▾、风格库、画幅、技能设置、积分、**合成全集**（没做完时灰）。
- 左栏「资产库」（列表 / 宫格切换、搜索、「第 1 集 ▾」只看本集、分组）：本集用到的角色形象、场景、素材；底部「+ 新建」。
- 中间「片段 01」：左边一个小播放钮；标题后面一行小字「输入 @ 引用资产及工具｜每 1 秒消耗 6 积分」；
  大文本框「输入描述，@ 引用角色 / 道具 / 素材 / 场景…」，右下「引用 / 编辑 / 完成」。有内容时是分镜脚本：
  「（时长：4.0 秒）日，学院 - 训练场。远景，平视……」，角色和场景以**头像 + 名字**的小标签嵌在句子里。
- 右栏：「故事板助手」对话（我们第二期）。有视频时中间右侧是这个片段的预览播放器。
- 底部「片段轴」：「多选」「智能预演（会员）」；一排缩略图「片段 01 · 10s」，已生成的可重新生成 / 删除，片段之间 `+` 插入。

## 2. 用户路径

| 屏 | 路由 | 竖条图标 | 做完去哪 |
|---|---|---|---|
| 我的画布 | `/canvas` | —（全站侧栏「画布」） | 新建 / 打开一张 |
| 新建 | `/canvas/new` | — | 剧本 |
| 剧本 | `/canvas/<id>/script` | 书 | 角色和场景 |
| 角色和场景 | `/canvas/<id>/assets?view=board\|list&tab=characters\|scenes\|materials` | 文件夹 | 逐集制作 |
| 逐集制作 | `/canvas/<id>/episodes` | 播放键 | 单集编辑器 |
| 单集编辑器 | `/canvas/<id>/episodes/<no>` | （同上） | 合成成片 → 下载 |

- `/canvas/<id>` 直接跳到服务端算出的 `step`（没拆过角色场景 → 剧本；还没有任何片段 → 角色和场景；否则逐集制作）。
- 进到一张画布后隐藏全站侧栏，换成画布自己的竖条（和小云雀一样）；竖条顶部的 logo 点回 `/canvas`。
- 全站侧栏「创作」组加一项「画布」；首页（dashboard）加一张入口卡。

### 2.1 我的画布 `/canvas`
- 标题「我的画布」，第一格是「新建画布」卡，后面每张画布一张卡：封面、标题、「3 集 · 5 个角色 · 片段 12/30」、更新时间（`formatDateTime`）、`···`（重命名 / 删除，删除要确认）。
- 空态：一句话说清画布是干什么的 +「新建画布」。

### 2.2 新建 `/canvas/new`
```
┌──────────────────────────────── 新建画布 ─────────────────────────────────┐
│  [ 粘贴写好的剧本 ]  [ 让 AI 写剧本 ]                                       │
│ ┌──────────────────────────────────────────────────────────────────────┐ │
│ │ 粘贴：大文本框（最多 10 万字），或拖一个 .txt 进来                         │ │
│ │ AI 写：「说说你的故事想法」一句话（≤500 字）+ 集数 ▾ + 每集时长 ▾          │ │
│ └──────────────────────────────────────────────────────────────────────┘ │
│  风格 ▾（分类 + 格子的浮层）   画幅 ▾ 9:16 / 16:9                  [ 开始 ]  │
└──────────────────────────────────────────────────────────────────────────┘
```
- 「开始」不花钱：建画布（粘贴的剧本由服务端按集切开）、进剧本页。
- 风格是前端常量列表（`src/constants/canvas-styles.ts`）：无风格、自定义（自己写一句）、写实电影、90 年代怀旧、古装影棚、都市时尚、国风水墨、日系动画、3D 卡通 …；
  没有缩略图时用一块色带 + 名字，不去网上找图。
- .docx 第一期不收（说清「先把 Word 里的文字复制进来」）；只收 .txt。

### 2.3 剧本
```
[竖条] │ 共 N 集                                                    [···]
       │ ┌─────────────────────────────────────────────────────────────┐
       │ │ ▾ 原始想法      一句话                                         │
       │ │ ▾ 故事大纲      题材、主线、人物小传         [通过] [重写 ✦2 ▾]  │
       │ │ ▾ 分集剧情      第 1 集 标题 · 钩子 · 梗概 … [通过] [重写 ✦6 ▾]  │
       │ │ ▾ 分集剧本      [收起全部]                                     │
       │ │   ▸ 1. 旧教室重逢  🔒   正文（可直接改）        [重写这一集 ✦4]   │
       │ └─────────────────────────────────────────────────────────────┘
       │     ▂▂ 角色和场景会从剧本里拆出来，剧本改好再继续　[拆出角色和场景 ✦4 →] ▂▂
```
- **AI 写**（source=idea）：进页时故事大纲是空的，给一个大按钮「写故事大纲 ✦2」。每段出来后用户**通过**才解锁下一段：
  故事大纲通过 → 「写分集剧情 ✦6」；分集剧情通过 → 「写全部分集剧本（N 集 ✦4×N）」或逐集写。
  「重写」下拉里写一句要求。每段、每集都能直接手改。锁上的集不会被重写（按钮禁用并说原因）。
- **粘贴来的剧本**（source=paste）：没有故事大纲 / 分集剧情两节，直接是分集剧本；页首一行「按『第 X 集』切成了 N 集」，
  切错了可以手改（每集标题、正文都能改，能加一集 / 删一集）。
- 修改记录（`···` → 修改记录）：每次「通过」或 AI 重写前自动存一版，最多 10 版，列表显示时间和说明，可「恢复到这一版」（恢复前也先存一版）。
- 「拆出角色和场景」：已经拆过再拆先确认「新出现的角色和场景会加进去，已有的保留、只补出现集数」。拆完跳到角色和场景（画布）。

### 2.4 角色和场景
**列表**（手机上只有这个）
```
[竖条] │ 角色和场景                                   8 个角色 · 12 个场景
       │ [角色 8] [场景 12] [素材 4]        [搜索] [全部集 ▾] [多选]   [画布 | 列表]
       │ ┌主要角色┐ ┌───────┐ ┌──────┐
       │ │ 立绘    │ │ 待生成 │ │ …    │   多选后底部出现：[为选中的 12 个出图 ✦24]
       │ │ 林微    │ │ 陈屹   │
       │ │ 2 个造型│ │ 2 个造型│
       │      ▂▂ 角色和场景会用在所有集里，调整好再继续　[← 剧本]  [下一步：逐集制作 →] ▂▂
```
- 桌面上点角色卡 → 切到画布并定位到这个角色（高亮它的全部造型、打开第一个造型的出图面板），和小云雀一样。
- 手机上点卡片 → 打开造型详情抽屉（能改描述、挑图、出图）。
- 「全部集 ▾」：只看出现在某一集的角色 / 场景。

**画布**（桌面，`@xyflow/react`，`dynamic({ssr:false})` 只在打开画布时加载）
- 节点：**造型卡**、**场景卡**、**素材图**、**文字素材**、**分组**（每个角色一个 `group:char:<id>`、场景一个 `group:scenes`，自动建）。
- 造型卡：图（没图 = 占位 +「待生成」；在跑 = 进度；失败 = 原因）、`+`（给这个角色加一个造型）、「林微 · 学生时期」、
  「出现在第 1, 2 集」、`···`（造型详情）。有多张候选时右下角标张数，点开挑「用这张」。主要角色的分组标题带「主要角色」标。
- 连线：见 `CanvasBoard.edges` 注释的允许组合；被选中节点的上游线高亮成主色。
- 选中造型 / 场景 / 素材图 → 屏幕下方停出图面板：描述正文（可放大编辑）、`+` 上传参考（上传后自动建一张素材图并连过来）、
  出图模型 ▾、画幅 ▾、**角色设计**（只对造型）、出几张（1–4）、预计积分、生成。
- 造型详情弹窗：左边候选图（挑主图、上传一张），右边角色名（可改挂到别的角色）、造型名、出现集数（多选）、外貌描述。

## 3. 数据

### 3.1 表
```sql
drama_canvas      id, owner_user_id, title, ratio, doc_json LONGTEXT, doc_version, created_at, updated_at, deleted_at
drama_canvas_run  id, canvas_id, owner_user_id, kind, target, status, cost, client_request_id, job_id,
                  input_json, result_json, refs_json, error_code, error_message, created_at, finished_at
                  UNIQUE(owner_user_id, client_request_id)（实体 @Table 上也声明）
```
迁移编号：实现时看两处目录（`resources/db/migration/*.sql` + `src/main/java/db/migration/*.java`）取 max+1，**部署前核对线上 `flyway_schema_history`**。

### 3.2 文档
形状见 [`packages/types/src/drama-canvas.ts`](../packages/types/src/drama-canvas.ts) 的 `DramaCanvasDoc`（剧本 / 角色和造型 / 场景 / 素材 / 画布布局 / 逐集片段）。
文档上限 4MB（规范化后的 UTF-8 字节数），超了 413 `DRAMA_CANVAS_TOO_LARGE`。

### 3.3 红线（照 ipstudio 的事故换来的）
1. **只存 key**：保存前递归剥掉 `url` / `lastFrameUrl`；读出时只给**属于本人**的 key 派生签名地址（查 `storage_asset`：app=drama、userId、cdnKey 三者对上）。
   drama 生成的 key 里没有 uid，所以**画布的所有产物（出图、上传、视频镜像、末帧、成片）落库时都要写 `storage_asset`**。
2. **防覆盖**：`PUT` 必须带 `baseDocVersion`（规范化 JSON 的 sha256 前 16 位），对不上 409 `DRAMA_CANVAS_STALE`。前端 409 时停止自动保存，
   提示「这张画布在别的页面改过了」，给「载入最新」。
3. **服务端不改文档**：生成结果进 `drama_canvas_run.result_json`，前端合回文档再存。合并按 runId 幂等。
4. **生成只读已保存的文档**：提示词正文、参考图（连线 / @ 引用）、首帧、片段时长、合成顺序都从库里那份文档取；请求带 `docVersion`，
   对不上 409。读出来的每个 key 都过归属闸，不是本人的 → 400 `DRAMA_CANVAS_ASSET_NOT_OWNED`，不扣费（不是跳过）。

### 4.1 计费
- 文字类：提交时冻结，成功结算，失败 / 取消退回（照 `withCharge` 的冻结结算，但放到 worker 里）。
- 出图：preflight（引擎、提示词、归属）在冻结之前；整批一次冻结，单价快照进 `input_json`，每张成功才结算；失败的退回（照 `DramaReferenceAssetService`）。
  **不再「先出图后扣费」**（现有 `renderFrame` 的老问题）。
- 视频：提交时冻结（单价 × 秒数），worker 结算或退回（沿用 `MaterialVideoJobService`）。**首帧必须写进 `variant_config.first_frame_key`**（聚算 H3 只认这个）。
- 合成：免费。
- worker 派发一律挂 `afterCommit`（ipstudio 真联调踩过：事务里派发会让 worker 查不到行）。

## 5. 几个关键做法

### 5.1 报价
- 每个花钱的按钮上直接写本次价格（`✦2`、`✦42`）。价格来自 `/me/drama/config` 和 `/me/drama/render/models`。
- 逐集制作页顶部写清楚一集大概要花多少。
- 批量动作、以及 ≥ `confirmThreshold` 的单次动作先弹确认框报总价。服务端以自己的计算为准（`run.cost`）。

### 5.2 一致性
- 造型图就是资产本身：片段里 @ 的是造型 id，出首帧时服务端取这个造型**当时挑中的那张**。改了造型图，之后新生成的片段就用新图。
- 已经生成的片段不自动重跑（花钱）；片段格子上标「用到的造型换过图了」。

### 5.3 片段怎么出视频
我们的视频候选：聚算 H3 只接了首帧；seedance 有首帧 + 尾帧；generic 有首帧。所以片段 = **先出首帧（多参考出图，便宜）→ 再首帧生视频**。
这一步正好就是小云雀「智能预演」想解决的事：花小钱先看画面对不对。候选不支持图生视频时，「生成视频」旁边写「这个模型不看首帧，角色可能对不上」。
片段文本拼进视频提示词时，按行保留「（N 秒）」，让模型按时长切镜头；整段前面加全剧风格。

### 5.4 「用上一片段最后一帧」
上一片段挑中的视频有 `lastFrameKey`（seedance 回传并镜像）就直接把它设成本片段首帧（不花钱、不调模型）；没有就按钮置灰并说「上一片段没有末帧」。
第二期再用 ffmpeg 截帧补齐。
