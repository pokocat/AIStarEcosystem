# Studio 运镜标签（v0.211，本地未发布）

视频节点面板、展开编辑器与 Studio 视频创作抽屉使用同一个运镜输入组件。用户打开“运镜”，搜索或选择推进、拉远、横移、跟随、环绕、升降、固定或手持指令，在当前光标位置插入命名标签；选中文字时替换选区。标签可点名称展开成完整文字修改，也可点击移除，或在相邻光标处用 Backspace/Delete 整条删除。

标签只是完整自然语言指令的显示形态。客户端文档 `metadata.prompt`、生成正文 `request.prompt` 和剪贴板文本始终保留完整指令，不新建第二套运镜配置字段，也不向供应商伪造原生 camera 参数。刷新根据相同正文重新识别标签；自定义修改后的指令仍作为普通可编辑文字。引用图标签与运镜分别序列化，复制不混入删除按钮名，粘贴仅接受纯文本。

原生面板随画布自动保存；展开编辑器编辑同一份节点正文。创作抽屉沿用既有草稿语义：提交前保存节点及请求，取消未提交修改时丢弃抽屉草稿。所选模型、模式、数量与时长变化不清空正文。运镜使用文字提示，是否准确实现由模型能力决定，不宣称任何模型原生精确控制。

手机原生视频面板默认把参考素材收起为带数量的“参考内容”入口，展开后仍可查看、替换和断开原连接。为正文保留可见编辑空间；报价和提交保留在底部。编辑面板打开时收起手机节点工具条与继续创作条，关闭编辑面板即可恢复；桌面和展开编辑器保留原参考素材条。

活跃或受理结果未知任务仍走原任务恢复。后续修改草稿不得改变已持久化的 `studio.request`；未知确认复用原 `clientRequestId` 和正文，不能因为新增运镜而再建收费任务。

实现：`src/ip/studio-motion-prompt.tsx` 是目录与选择器真源；vendored `canvas-prompt-chip-input.tsx` 仅扩展通用指令标签及光标/剪贴板支持，保留 @ 引用逻辑。新增 CSS 使用 `.ip-surface` 作用域，手机形态读取 `html[data-layout="mobile"]`，沿用现有纸白、墨、群青与麦黄令牌。

LibTV 命名运镜标签依据先前已记录的实地观察。此次实时复核的两参考图视频节点中，工具随模型切换，未重新看到运镜菜单；确认特效入口为有广场/收藏/最近使用与作者搜索的独立库。当前运镜目录为本平台编写的可编辑提示，不宣称逐项复刻其目录。特效库、五分钟长视频及其他未对齐功能继续单列。

验证记录见 `ip-studio-unified-canvas-validation.md` §22；本增量不提交新的模型生成、不评价免费模型画质、不部署。
