# 成片：生产阶段做好基础，编辑室只做精修

> 现行设计真源（2026-11-07，本地实现，未发布）。选型决定：Twick 负责编辑和预览，服务端 FFmpeg 负责导出，不换编辑器。

## 1. 分工

用户的原则：**基础能力放在视频生产阶段默认做好；编辑室只给想精修的人用，不用来补基础操作。** 新增成片能力先判断属于哪边。

| 放在哪 | 内容 | 用户要做什么 |
|---|---|---|
| 生产阶段（导演台整集导出、一键成片） | 自动字幕、各段音量统一、片段接缝去爆音、背景音乐说话时压低、清晰度选择 | 不用操作，或选一下 |
| 编辑室（高级编辑，只有电脑版） | 变速、淡入淡出、画面颜色、小窗、图片、改个别字幕 | 需要时才打开 |

## 2. 自动字幕

合成时决定字幕从哪来（`StudioCaptionService`），手写的优先：

| 情况 | 字幕内容 | 字幕时间 | `output.captions.status` |
|---|---|---|---|
| 导演台，语音识别可用且对得上 | 台词原文 | 语音识别 | `recognized` |
| 导演台，语音识别没配置、失败或对不上 | 台词原文 | 按镜头时间和字数估算，并告诉用户 | `estimated` |
| 导演台，本集没有台词 | 无 | 无 | `no_lines` |
| 一键成片，语音识别可用 | 识别出来的字 | 语音识别 | `recognized` |
| 一键成片，没听到人声 | 无 | 无 | `no_speech` |
| 一键成片，语音识别不可用 | 无，**不编字幕**，成片照常合成 | 无 | `unavailable` |

- 已知台词和识别结果逐字对齐（`StudioCaptionAligner`，最长公共子序列）：识别错个别字不影响，字幕永远是台词原文。一个片段不到 35% 的字对得上，就不信这段的识别时间。
- 一屏最多 15 字（竖屏）、18 字（方形）、24 字（横屏）；按标点断句，句末逗号句号不显示，问号叹号保留。
- 所有字幕合成一路透明画面（`StudioPackagingService.captionTrack`，ffconcat 清单），不再一条字幕一路输入，上限从 24 条放到 200 条。
- 去掉 Whisper 在近静音处常见的幻听句（「请不吝点赞订阅」等），只在没有已知台词时用得上。

**语音识别的配置**：后台「AI 模型」给「Studio · 语音识别」（`DAP_TRANSCRIBE`，V76 扩枚举）绑定端点，接口要兼容 OpenAI 的 `POST {base}/audio/transcriptions`，返回带 `segments` 的 `verbose_json`。费用算在导出里，不向用户收积分。线上还没绑定。

## 3. 声音

`StudioPackagingService.finish` 是 Studio 成片的最后一道，一次编码：

1. `cleanClipAudio`：每段原声按片段长度对齐（声音比画面短的补静音，否则后面的会错位），接缝做 15 毫秒淡入淡出去掉爆音。
2. 响度统一到 -16 LUFS / -2.5 dBTP（与配音同一标准，v0.135）。
3. 背景音乐先压到 -27 LUFS，循环铺满，人声作为侧链压低音乐（`sidechaincompress`），结尾 1.5 秒淡出。

画面上没有要叠的东西时视频流直接复制，不重新编码。

## 4. 清晰度

`packaging.quality`：缺省跟随片段；`720p` / `1080p` 按画幅算尺寸（1080p 竖屏 1080×1920）。片段不是这个档就重新缩放，界面提示放大不会让画面更清楚。

## 5. 编辑室

- 速度（0.5–2 倍）：改速度时片段在时间线上的长度跟着变，同一轨后面的片段前后挪。Twick 播放的素材时间是 `(props.time + 已播放秒数) × 速度`，导出的素材起点按这个公式算。
- 淡入淡出：Twick 的 `fade` 动画（0.5 秒），导出用 `fade` 滤镜，都是从黑到画面。没有用 `xfade`：线上共享的 ffmpeg 是 2018 版，`xfade` 要 4.3 以上；这一版用到的滤镜 4.0 都有。
- 画面颜色：Twick 的 `mediaFilter`（鲜艳、明亮、暖色、冷色、黑白），导出按它的 CSS 滤镜数值换算成 `eq` / `hue` / `colorchannelmixer`（`StudioEditGraph.LOOKS`）。
- 小窗和图片：`metadata.pip` 的视频和所有图片叠在主轨上（`overlays`），位置用四个角，大小用滑块，也能在画面上拖。
- 字幕：合成过一次且片段没变时，打开编辑室字幕已经在时间线上（`seedCaptions`）；时间线上没有字幕时，导出时自动生成（`autoCaptions`）。

## 6. 界面

按不懂技术的用户设计：

- 导演台：点「导出整集」弹一个对话框，只问字幕、背景音乐、清晰度三件事，都有默认值，直接点「开始导出」就能得到带字幕的成片；重新导出时沿用上一次的设置。合成中说明要多久、可以离开页面；完成后主按钮是「下载成片」，旁边能先「观看成片」，并说明字幕是怎么来的。
- 一键成片：五步编号（选择片段、设置声音、添加字幕、添加文字、选择清晰度），除第一步都可以不动。字幕默认自动生成，手写收在「手动填写」里；语音识别不可用时不能选自动生成，默认不添加。背景音乐可以直接上传。
- 编辑室：右侧说明改成「如何精修」五步（后来收进折叠项，见第 6 节），属性不写术语（播放速度、开头淡入、画面颜色、显示位置），工具栏提示换成中文。
- 字幕烧进画面无法去除，两处都写明补救办法（改为不添加后重新导出，原片段不受影响）。

### 第二轮复评后的规则（2026-11-07）

- **叫法统一成「导出」**：导出成片、已导出的成片、导出中、导出失败、导出免费；页面叫「制作成片」。对话制作计划和 `/video` 进度里的「合成成片」是系统自动做的一步，这轮没改。
- **只打开编辑室看一眼不算改过**：撤销状态和字幕开关都没变时，返回不存档，一键成片的设置和「导出成片」按钮都还在。真改过才存，保存失败不关编辑室；没保存时刷新或关标签先问一声。
- **背景音乐在编辑室也算数**：音频面板能看到、能换、能移除，导出带 `edit.musicStorageKey`。
- **语音识别不可用时**：「自动生成」不能选、不写推荐，默认「不添加」。线上还没绑定语音识别，**发布前要绑定并实测**，否则一键成片默认没有字幕。
- **手动字幕一行一条**：开始、结束、文字分开填，时间按片段算好；底层还是 `开始-结束: 文字`。没写字的行不算字幕。
- **人物声音和背景音乐分开列**：上传的音乐标 `studio.audioRole=music`，不进人物声音；生成的配音不进背景音乐。选好后显示文件名、试听、移除；预览里按 25% 音量一起放。
- **下载有反馈**：按钮变「正在准备下载」且不能连点，开始后说明去浏览器下载列表看。文件还是先取回内存再保存（为了文件名），长片会等一会儿，改成直接给下载地址见 TODO。
- **待确认的视频不挡导出**：对话框写明「开始导出后将一并确认」（`options.confirmPending`）。工具栏有「去确认（N）」「去生成视频（N）」，跳过去后那一段高亮 2.4 秒。
- **编辑室再次打开**：Twick 的时间线存在全局表里，按 `contextId` 取；同一页再次打开要用新的 id，否则读到上次的时间线和已释放的素材地址，预览一直转圈。预览上的转圈也不显示（打开已保存的工程时它要等第一次播放才收起）。
- **旧版 ffmpeg**：`loudnorm` 之后必须再写一次 `aformat`（采样率 + 声道），3.4 不带声道布局，后面的滤镜会报错，8.x 看不出来。改滤镜后用旧版跑一遍真实渲染测试（Ubuntu 18.04 官方源的 ffmpeg，把 `ffmpeg`、`ffprobe` 换成 `docker exec` 的包装脚本放到 PATH 最前面）。
- **高级编辑状态**：片段区只读（改了也不生效的控件不留）；返回时改过才问「继续编辑 / 不保存 / 保存并返回」，比较的是导出清单（`toEditTimeline`），不是工程本身（点选片段时 Twick 会往工程里补位置信息）。
- **片段卡**：提示词默认收起；确认单独一行；已有视频时，所有会再生成一条的按钮（`paid`）都先说花多少，不留绕过确认的入口。
- **素材没加载齐**：编辑室的保存和导出变灰，给「重新加载」，返回不存档；缺段的工程不能写回存档。
- **存过高级编辑**：成片页直接「导出成片」，用存档算清单（`toEditTimeline` 是纯函数，不加载 Twick），手机上也能导出；继续修改才需要电脑。
- **编辑室加视频**：接到主轨片尾，不盖住已有片段；小窗才叠在竖线位置。
- **批量生成视频**：默认跳过已有视频的片段并列出来；要重新生成得再点一次「已有视频的片段也重新生成」，确认框写明再次扣费。
- **存过高级编辑的成片页**：写明将导出几段、多长、背景音乐和字幕；下面的列表标「原始片段」，因为导出的是存档。
- **编辑室和浏览器后退**：打开时压入一条历史记录（带上 Next 的内部状态，否则 Next 会整页刷新），改过就询问，没改直接退出。
- **下一步跟着人走**：分镜页片段多，导出按钮滑出视野（算上固定顶栏）后，右下角出现一条提示：导出中、已导出可下载、几段生成中、几段没有视频、可以导出。生成中的片段不算「缺视频」，也不给「去生成」。
- **高级编辑加载**：加载屏写已加载几个、有「返回」，加载失败给「重新加载」；浏览器后退在加载时也直接退出。
- **背景音乐**：编辑室音频面板能直接上传；存过高级编辑的成片页也能换，存档之外的音乐不写进存档，导出时以成片设置为准。
- **编辑室右侧**：没选中时不放说明文字，显示这条成片：几段、多长、片段列表（点一下选中并跳到那里）、其他内容、字幕开关、背景音乐（上传、更换、移除、试听）；操作说明收进折叠项。选中后才是这一段的属性，顶上「全部片段」返回。字幕开关和音乐与左侧面板共用同一个值。
- **重新生成**：分镜图有图后，主按钮是「确认使用」或「完成」，重新生成是次要按钮并先说费用。视频重新生成后不自动替换（服务端规则），卡片上说明新版本已生成，可换用或保留。点版本即采用（2026-10-30）不变，点之前写明「点击换用」。
- **存过高级编辑的成片页**：不显示原始片段的列表和预览，列出真正会导出的内容；有空白时写明。
- **空白**：拖短片段不会自动补位（自动补位会让撤销回到有空白的状态又被补上，撤销就废了），所以右侧提示并给「去掉空白」，导出前再问一次。判断只有 `studioEditGapSeconds` 一处。
- **播放**：Twick 播到片尾不会停，`StopAtEnd` 停在片尾。
- **工具条的删除隐藏**：Twick 自带的删除会留下空档、导出成黑屏，只留右侧会把后面片段往前补的那个。
- **导出完成**：「下载成片」排第一，「重新导出」排最后；顶部的一键制作结束语按当前状态说下一步，不再留着「请在分镜中确认」；另弹一条提示，在别的工作区也看得到。

## 7. 没做的

- 导演台成片不能直接进编辑室（编辑室在画布里）。
- 片段之间的叠化转场：要 `xfade` 或自己叠两路，预览也要另做，这一版只有淡入淡出。
- 语音识别结果没有缓存，重复导出会重新识别。
- 手机上不能打开编辑室（沿用原有判断）。
- 导演台确认卡上「确认使用」和付费的「重新生成视频」仍挨着，有了导出时一并确认后走到这里的人变少，这一版没动。
- 编辑室时间线条上不显示片段名（Twick 自带样式）。
