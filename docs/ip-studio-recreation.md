## 片段解析与拉片（2026-10-15本地实现）

2026-10-15重新核对用户提供的小云雀工程：示例说明明确从「素材拆解 → 拉片」进入，画布同时包含全片创作拆解、人物形象、风格参考、BGM原声和各片段。其片段1时间范围为0–3.8秒，内部镜头表又分0–1.8秒和1.8–3.8秒。因此「片段」是可包含多个镜头的叙事段落，不等于单个切镜，也不等于模型看图的分页。

本轮接通全片之后的片段解析，验收流程和真实产物，不以模型叙事是否符合恐龙范例作为通过条件。保留现有「解析」入口；「拉片」作为独立操作，复用已有全片解析上下文，已有正文保留用户编辑，不在打开文档时自动启动新任务。

- 画布组织：原片 → 全片拆解分组；原片 → 片段1、片段2……，每段一组「可播放片段视频＋镜头拆解Markdown文档」。
- 分段：基于画面变化候选及全片内容形成连续时间范围，镜头可组合成叙事片段；不固定按秒均切，不把每次闪电直接当成切镜。时间范围由真实视频时钟承载，手动调整分段留待后续。
- 每段文档：标题与原片时间范围、镜头构造表（时间/画面骨架/摄影机/调度构图焦点）、段落表达（叙事要素/视觉变化/剪辑节奏/声音）、视频生成Prompt。继续复用剧本Markdown编辑器。
- 素材：视频片段必须真实裁切可播放，保留原片key及起止时间；提取的参考图沿用本人存储与签名链路。声音未接入分析时明确未分析，BGM提取单独后续接入。
- 任务：确认后关闭小面板，进度留在画布；允许失败片段重试，不重跑已完成全片；刷新不重复建节点，编辑可保存导出。

本地实现沿用`operation=recreation`，以`mode=segments`区分拉片；不新增任务、计费或积分系统。`StudioFilmStudy`先让模型按原始画面提出片段结束点，工程只约束有限、连续、合法的原片时间范围（最多8段、覆盖片尾），不验收模型对情节或镜头的理解。模型未返回可用分段数据时，按非闪光的画面变化候选分段。逐段直接接收Markdown正文，不套全片报告的字段/证据校验。

每段真实转码裁切为最长边不超过1280的H.264/AAC MP4，保留存在的原音轨；ffprobe核验实际文件与目标时长。原片key与原片时间范围留在片段节点`studio.sourceRange`，视频是普通可复用节点。分析复用本段时间范围内的真实采样图，数量遵循候选`max_ref_images`（2026-10-16切换后当前为9张；旧候选未配置时回落6张），声音明确未分析；不是把全片文字直接切成几份。

服务端逐段持久化`output.filmStudy`进度，完成一段即有媒体key和正文；URL仅在出wire时签名。前端按稳定id增量生成片段组、视频、Markdown文档和原片→片段→文档连线。轮询与继续任务不会覆盖已经编辑的文档，已落地标记避免重复建组。失败后显式「继续拉片」会通过本人旧任务恢复，复用已完成段和已裁切媒体，只对未完成段调用模型；请求身份、冻结与实际Token结算沿用既有Studio链。

界面沿用420px小面板和共享Markdown编辑器，视频入口固定原片、确认后关闭。全片报告节点另有「继续拉片」，已有全片正文只读作背景，不重跑全片解析。未实现手动调整分段、BGM独立提取和角色自动提取，本轮先验收分段/裁切/逐段分析/画布落地。

## 输入与报告

第一版支持60秒、128MiB以内的视频。服务端先校验本人项目/视频key、实际时长/画面、视觉模型、提示词和按量售价，再经原Studio链受理。当前直接调用固定版本Hypit媒体模块，以低分辨率解码全部原始视频帧，保留原始PTS，优先保留明显视觉变化前/当时/后的画面，再补齐长时间空档，最终1至64张分析帧。每页最多8张较大画面分段读取，汇总时附上未拼格的真实尾帧独立复核结尾。亮度变化单独标记，不直接视作切镜；超过预算优先保留强变化，不能保证分析覆盖每一帧。时间为近似定位，不是切镜点；不读取音轨，也不提供逐镜拉片。

报告的固定组织来自用户给出的恐龙样例：

| 部分 | 内容 |
|---|---|
| 创意命题 | 可见事件及显式标注的主题解读 |
| 视觉基因 | 媒介与美术风格、色彩、光线、材质与后期、构图、摄影机六项 |
| 反复出现的画面元素 | 画面中反复出现的视觉母题 |
| 复刻时建议保留的要点 | 为保持相似创作效果而提出的建议 |
| 创作骨架 | 时空/镜头组织、影像与声音边界、叙事动作三项 |
| 核心创作手法 | 画面实例、作用解读、可迁移做法 |
| 分析边界与建议词 | 身份/连续动作/声音不确定性，以及反推的可编辑创作提示词 |

报告字段由 `packages/types/src/ip-studio-workflow.ts` 定义。画面事实 `observed`、复刻规律 `rule` 与手法作用 `effect` 分开。每项视觉基因、骨架与手法须引用本次真实帧编号；服务器附加真实来源与采样时间，拒绝模型编造来源；无效帧编号隐藏并注明定位不确定，不因单条引用失败丢弃整份分析。提示词在 `prompts/material/dap.ip_studio_recreation.md`，后台Prompt管理沿用默认资源与版本管理；不把验收范例或“幼崽/复活”结论注入实际模型请求。

## 任务与画布

复用 `/v1/ip-studio/projects/{id}/studio-runs`，operation `recreation`，无需新表/新路径。来源快照进入IpRun私有_exec，报告存output.recreation，正文Markdown存output.text供历史和资产库读取。模型支持看图是管理员明确声明，不按模型名猜测。

报告是独立文字业务节点，原视频保留，连线记录来源；受理前先保存。刷新匹配原任务，网络未知时保持原clientRequestId并提供确认原任务，不重新收费。失败可显式重试；保存失败不提交；输出截断/不完整失败并释放冻结；不可靠帧引用隐藏并提示。完成按实际Token结算，余量退回，沿用端点队列和afterCommit。

报告中的时间点播放受理时的原片key，原视频之后换版本也不会偷偷换成新片。生成完成的报告刷新可查看。基于报告创作是显式免费创建普通创作要求文字并打开助手，下一轮AI调用仍需用户发送；保存失败重试不重复建节点。

完整画布模板只保留普通报告正文，剥离作者的私有来源/任务绑定，防止其他用户查询作者任务。逐镜拉片、自动转写与声音理解留待后续。
