# 个人资产库与资产快速编辑方案

日期：2026-10-11。状态：按现有产品重新整理的规划草案，尚未实施，不代表线上能力。

用户最新要求：停止独立原型迭代，改为评审贴合实际产品的方案；剧本提取只能是剧本内的扩展功能，不进入一级菜单。先前原型只验证了部分交互，不作为正式产品的导航、页面布局或实现依据。

本方案以当前仓库代码为产品基础。竞品部分沿用此前只读实页记录，并重新核对小云雀公开手册；LibTV 本轮公开页面未能读取，不将其内部规则写成已验证事实。以下取舍为产品建议，尚未由用户全部定案。

## 方案要点

1. 升级现有 `/assets`：将“素材库”统一命名为“资产库”，不再新增平行入口。
2. 保留现有创作、画布、故事板和剧本编辑器。提取入口放在剧本编辑器的“素材”面板，快速完善是资产编辑任务，二者都不进一级导航。
3. 全部成功生成结果自动入库；有设定但没图的角色、场景保存为待完善对象。普通图片与可复用角色分开组织，使用同一份底层文件和来源记录。
4. 文件夹只负责人工整理。人物身份、来源剧本、使用画布分别记录，名字和文件夹都不是合并依据。
5. 新画布通过现有素材按钮或 `@` 选取个人资产；记录精确版本，主图变化不自动替换已制作画面。

## 1. 目标与范围

用户要求：凡是生成过的内容，都能在个人数字资产库找到；新画布能够通过 @ 直接引用；剧本提取的角色、场景等即使还没有图片，也应成为可编辑的资产，可批量生成或逐项上传、填写描述和提示词后生成。

本方案以 AiAvatar 内所有生成入口为目标范围，先完成画布和 Studio，再补齐本应用旧资产生成链。跨 music / drama / celebrity 的全生态回流是后续独立接入项，不把其他产品的所有历史产物宣称为本期已覆盖。

## 3. 入口与导航

### 沿用现有产品层级

桌面一级导航继续使用现有“首页 / 创作 / IP 管理 / 模板管理 / 素材库”，只建议将“素材库”改名为“资产库”。不新增“剧本提取”“快速编辑”或新的一级“剧本”栏目。画布及故事板继续作为创作中的工作方式，剧本文档继续从原剧本节点进入。

| 功能 | 放置位置 | 返回关系 |
| --- | --- | --- |
| 查看、整理所有个人资产 | 现有 `/assets` 升级 | 保留全局导航与现有页面框架 |
| 从剧本建立资产 | 剧本编辑器 → 素材 → 本剧资产 → 提取资产 | 仍在同一剧本文档任务内 |
| 快速完善一个或一批资产 | 本剧资产的“完善资产”；资产库卡片的“编辑”或选中后的“批量完善” | 返回原剧本/原资产列表，保留位置和筛选 |
| 引用个人资产 | 原画布素材入口、节点参考选择器、助手或生成输入框 `@` | 回填原节点或输入框，不跳转全局库 |

剧本节点的“更多”菜单可以提供“提取资产”快捷入口，但打开的是同一素材面板。全局资产库不放“提取剧本”的主按钮或引导横幅；待完善角色从状态筛选进入，来源剧本只用于回看依据。

### 当前没有独立的项目层

2026-10-11 用户澄清：产品当前没有组织多个剧本、画布的“项目”概念。代码里的 `IpProject` 是一张画布的持久化记录（一画布一行），不能当作上层业务项目。第一版不以新增项目管理为前置条件，用户界面统一写“来源画布”。

个人资产属于用户，具有独立身份；画布只记录创建来源与使用关系。同名不合并，同画布也可能有两位同名人物。区分卡片使用缩略图、来源画布和描述；库内直接创建的资产显示“资产库创建”，不要求绑定画布。

提取时以来源画布、剧本文档身份和已确认的提取对象关联识别已有草稿，不能仅凭姓名，也不能把每次提取运行当作全新身份。跨画布提取出同名人物时默认保留为独立待完善对象，可显式“使用已有角色”；重复提取沿用已确认关联，有歧义时提示用户选择，不自动合并或覆盖。

`@` 候选优先显示“当前画布已用”，其次用户选定的文件夹，最后“我的全部资产”；显示文件夹与来源画布辅助区分。跨画布复用通过选用同一资产完成，不需要先建立项目。

### 文件夹用于人工整理，暂不定义为项目

用户可以用文件夹组织一部剧的资料，但文件夹不承担剧本归属、角色合并、分集顺序、画布权限或默认角色身份等项目语义。现阶段自由画布与跨画布复用是主流程，强制项目会增加创作前准备，单纯人工整理又会让大量产物积压。建议采用“自动收集与记录来源 + 人工选择整理位置”，而不是全自动猜测或全人工收纳。

- “全部资产”是包含所有个人资产的聚合视图，“未分类”是尚未加入任何文件夹的筛选视图；二者不是额外复制的库。
- 第一版使用普通文件夹语义：一条资产一个整理位置，支持创建/改名、批量移动、移出文件夹和单层目录。此前“一资产多文件夹”更接近收藏集合，会增加移动/删除/修改的理解成本，本期不采用；跨画布引用不要求把资产复制到另一个文件夹。
- 文件夹表达整理关系，不改变归属、权限、人物身份和来源；同文件夹也允许同名角色，不按姓名或放置位置合并。
- 所有结果仍自动入个人库；未选择文件夹时进入未分类。用户在快速编辑或生成时明确指定保存文件夹后，该操作新产物可按其选择归入对应文件夹，系统不根据标题、姓名或提示词推测项目关系。
- 画布可选“新资产保存到：某文件夹”，从文件夹发起新画布时带入这一可见设置；用户明确选择后，新提取对象和自由生成产物自动进入该处，@ 也优先显示该处，不需要每次生成后再手动整理。不选择则未分类。设置变化只影响后续新资产，不追溯搬动旧资产。
- 已有角色的重新生成/增加造型仍挂到该角色，不能因为当前画布另选文件夹就移动原角色。素材保留真实来源画布；从任意文件夹引用角色都不改变整理位置。若要独立演变，显式“复制为新角色”。已有画布继续锁定所选版本。
- 删除文件夹前明确显示“保留内容并移至未分类”，不连带删除画布、人物或文件。画布级文件夹管理可后续复用组织机制，本期不额外建立完整项目管理模块。
- 资产选择器在结果中展示文件夹标签；没有文件夹时显示来源画布/资产库创建，并用缩略图和描述辅助区分。

文件夹如“废市”可以承载用户的一部作品的资产，但现有画布列表仍独立。新画布引用该文件夹的角色即可，不要求加入一个“项目”，也不要求为每张画布复制一套人物。

桌面：`首页 / 创作 / IP 管理 / 模板管理 / 资产库`，直接升级现有 `/assets`，不增加一个平行的库。

移动：保留现有底部“资产”，使用同一份数据；详情与快速编辑使用全屏页面。

画布：保留固定“资产库”按钮，打开侧栏；助手与图片/视频生成输入框的 @ 打开同源选择器。侧栏提供“当前画布 / 我的文件夹 / 全部个人资产”，未选文件夹的新画布默认全部个人资产。选择器搜索覆盖名称、描述、标签、文件夹与来源画布。

IP 管理继续负责人物长期设定、主形象、默认声音等；资产库负责全部创作内容的查找、整理、快速完善与引用。同一人物卡片指向同一档案，不再创建一份独立人物。

## 4. 资产库页面

侧栏负责范围（全部/未分类/自建文件夹），主区域采用两种内容视图。“待完善”改为角色视图中的状态筛选与数量提示，不再与内容类型并列为第三个主视图。

| 视图 | 内容与默认组织 | 核心操作 |
| --- | --- | --- |
| 全部素材（默认） | 按最近产出展示所有生成/上传的图片、视频、音频、文本；同一轮候选成组并可展开全部 | 预览、引用、编辑、收藏、整理 |
| 角色与场景 | 角色、场景、道具/产品按对象聚合；同一人物一张卡，包含各版本和相关素材 | 快速完善、生成、上传、选择默认版本 |

全部结果能找回和对象能持续复用是两项不同任务。普通图片不因生成成功就自动成为新人物；无图角色也不是坏掉的图片文件。生成记录和对象档案可展示同一文件的不同用途，但不能复制文件或丢掉来源。角色与场景中的每次生成全部进入素材视图；自由生成结果可显式“设为角色/加入已有角色”。未整理为角色的普通素材仍可直接 @。

筛选维度彼此独立：媒体类型（图片/视频/音频/文本）、来源（AI 生成/上传/提取）、来源画布/剧本、收藏、时间。人物/场景是对象类别，图片/视频是文件类型，不混为一排互斥选项。

“全部素材”中提供“AI 生成 / 我上传的”快捷筛选。卡片展示真实预览、名称、类型、来源和状态；视频提供真实封面，音频提供播放入口，文本显示正文摘要。没图的对象在角色与场景视图显示名称、描述和“待生成形象”，不伪装成媒体加载失败。文件夹为空时提供上传/新建角色入口，不用强制建项目的空态挡住创作。

## 5. 入库与归属规则

1. 生成成功且产物已保存到我方存储，即自动登记；不依赖前端轮询、打开页面或用户点击收藏。
2. 一次生成多份候选，全部入库；未被采用的结果同样可查可引用。局部成功时已成功项立即可用。
3. 上传成功的本人素材也统一登记；相同文件可关联多个资产，不复制文件。
4. 剧本提取产生“资产草稿”：已有名称、类别、来源和描述，没有图片也可保存；草稿状态与生成任务状态分开。
5. 同一剧本相同提取对象重放不重复创建；不同剧本的同名“张三”不自动合并。用户可显式关联已有角色或新建。
6. 纯自由生成图即使没有绑定人物，也进入全部资产，不强迫用户先建 IP。明确从张三资产发起的生成则直接挂回张三。
7. 自动入库免费，不再次调模型；用户发起生成前显示真实报价。
8. 用户主动删除/隐藏的记录保留标记，后台回补不能把它重新显示出来。

## 6. 资产快速编辑页

### 先在剧本内确认，再完善

“本剧资产”与“素材引用”要分清：前者是这个剧本已经确认使用的角色、场景和道具；后者是从个人库选择的参考素材。它们是剧本素材面板内部的内容范围，不另建全局资产库。

首次点击“提取资产”时，默认使用当前已保存并采纳的剧本版本；存在未保存编辑，先保存草稿及来源快照，保存失败不开始提取。尚未采纳的 AI 建议稿不自动当作来源。

- 正文中已有完整人物小传、场景、道具设定：直接整理为待确认清单，不为已有结构再次调用模型。
- 只有故事正文或用户主动选择“从正文补充提取”：再调用模型解析，事先展示范围及实际报价。全文/分集范围要显式选择；解析不改写原剧本文字。
- 清单展示名称、类别、原文描述、出处和可选整理文件夹；默认保留为本剧的新对象。用户可以取消误识别项，或明确选择已有资产来复用。
- 点击“保存资产”后，无图对象也持久入个人库；未确认的解析建议不混进正式列表。不自动生成图片、不自动铺满画布。
- 保存后原素材面板展示“本剧资产 · 待完善 N 项”，提供“完善资产”和“添加到画布”。已有对象持续从该处进入，不强迫用户每次重新提取。
- 剧本再次修改时提示“设定可能已变化”，只有用户选择更新才重新提取；显示新增项和变化项，保留人工描述、图片与原对象身份，剧本删掉的角色也不自动从个人库删除。

### 复用现有编辑任务，不新增一级页面

建议入口：保存提取对象后，可在原素材面板逐项完善，或点击“完善全部”打开集中编辑任务；全局库提供选中后的“批量完善”、单卡“编辑”。它们打开同一编辑能力，带入本剧/当前文件夹/选中资产的不同范围。深链接可用于恢复编辑，但不能把路由本身当一级产品模块；具体路径需避开既有 `/assets/[id]` 人物详情。

单项编辑沿用现有资产详情或人物详情的预览、描述、素材分区和生成操作。集中完善借用现有故事板详情的“左侧同类列表 + 右侧详情”组织，逐项切换而非连续打开多层弹窗；顶部显示处理范围、完成数量及批量按钮。保留当前产品字体、颜色和操作容器，不采用独立原型的顶栏及三栏布局作为标准。返回时恢复原节点、画布视口或剧本素材面板；手机复用单项全屏详情及固定底部操作栏。

单项流程：

1. 选择资产，改名称和类型，填写长期描述。
2. 上传素材，明确“设为主图”或“仅作参考”，也可从个人库选择参考。
3. 编辑本次生成提示词；长期人物描述与本次“换衣服/侧身”等指令分开保存。
4. 选择当前实际可用模型、比例、数量，查看报价后生成。
5. 结果自动保存为该资产的候选。没有主图时，首次单张成功结果成为初始主图；首次多候选则展示首张临时封面并提示选主图，引用时必须明确选一张。
6. 已有主图时，新结果不自动替换默认版本；用户显式“设为主图”。高级创作可以“在画布中继续编辑”。

批量流程：

- 顶部主按钮“一键生成缺图资产（N）”，另支持勾选后“生成所选”。
- 统一设置本批次风格、模型、比例，每项保留自己的描述和提示词覆盖项。
- 提交前校验每项描述与参考能力，列出可生成项、缺信息项、总数量和总报价；缺信息项定位到具体资产。
- 默认跳过已有主图及正在生成的资产；重新生成已有图是另一个明确动作。
- 按项显示排队、生成中、完成、失败；刷新可恢复，离开页面不影响任务。局部失败只重试失败项，网络结果不明确时查询原任务。
- 完成后主动作是“返回剧本”或“返回资产库”；“添加到当前画布”是明确的选用动作，“新建画布使用”是可选后续。不要把新开画布当作完善资产的必经步骤。

## 7. 跨画布 @ 与版本

用户在任意新画布输入 `@张三`，结果展示缩略图、资产名、文件夹、来源画布/剧本、身份描述与版本，避免同名误选。选择后变成可点击引用标签，展开可查看本次具体采用的图片和描述。

- 引用已有文件不重新生成、不扣生成积分，也不要求先手动复制到画布。
- “加入画布”创建引用节点；“用作参考”挂到当前输入，两个动作使用同一资产选择器。
- 对没有主图的草稿允许引用文字设定，并明确提示“尚无参考图”；要求图像参考的操作引导补图，不虚构图片。
- 保存精确资产与版本引用。新选择默认使用当前主图；旧画布和在途任务保持原版本，更新时提示“有新版本，可切换”。改名不丢引用。
- @ 只加载用户选中的内容，按当前模型的媒体能力和数量限制提示；不把整个人物所有历史版本都塞入生成请求。

## 8. 数据和服务实施建议

原则：统一入口与检索，但继续复用现有任务、文件、人物及账本真值。

- 建立可持久化的个人资产目录/索引，评估扩展 `ip_saved_asset` 与目录关联模型；不能直接将现有自由 JSON 保存接口当完整资产编辑接口。
- 目录关联现有 `DapAvatar / DapLook / Voice` 等业务对象；新提取的无图对象需要可独立持久化的草稿身份，图片生成后仍是同一个对象。具体复用哪个实体应在实施前核对状态与必填字段，不能仅为拿 ID 伪造已定稿人物。
- 资产对象与媒体结果一对多，允许同一文件被多个对象/画布引用。记录 owner、来源画布/剧本/节点/任务、输出序号、提示词快照、参考版本和 storageKey；签名 URL 不落库。
- 服务端任务完成时可靠登记或写入可恢复的入库事件；若异步索引失败，应自动补偿，可见性有明确时限，不能永久依赖浏览器。入库故障不得导致再次生成或改变已完成任务的结算。
- 以来源任务和输出序号幂等，文件按存储键去重；不以角色名称或签名 URL 去重。保留不同任务的来源记录。
- 复用现有生成、预检、报价、冻结/结算与 afterCommit 派发；批量只是编排和聚合状态，不另造生成引擎或任务成功真值。
- API 支持服务端分页、查询和筛选；列表某一个资源不可读时局部失败，不能整库空白。补齐真实缩略图与文本摘要。
- 审核和授权状态沿用原资产规则；进入个人库不扩张真人素材的使用权限。
- 删除画布节点不删个人资产。删除整个画布前检查其清理链，保护已入库或被其他画布引用的原件；资产删除采用回收站，仍被引用的文件不直接物理删除。
- 历史回补读取已有成功任务与候选文件，合并原手动收藏及人物造型；分批、可重入、不调用供应商，不把同一结果展示两次。原文件确已丢失则标明不可用，不补造。

## 9. 实施顺序与验收

### A. 自动归集 + 可查可引用

升级 `/assets` 和同源选择器，接通画布/Studio 图片、视频、配音、文本等成功结果，历史回补、分页搜索、@、精确版本与删除引用保护。首期包含单层自建文件夹、批量移动与画布显式选择新资产保存位置。为本应用其他生成链列覆盖清单，逐项接入，不用单一 worker 代替全覆盖。

### B. 剧本内提取草稿 + 快速完善

扩展现有剧本素材面板，将已确认提取对象可靠保存，接通单项上传/编辑/生成及批量生成缺图。A 与 B 一起构成本次用户需求的首个完整交付；A 单独完成只算阶段进展。实现按当前 `/assets`、画布选择器、剧本编辑器、人物详情分段验收，复用当前应用，不再制作另一套脱离产品的独立原型。

### C. 整理体验增强

增加批量标签、多级文件夹、关联/拆分、三视图/表情等高级资产完善与跨应用回流，避免第一版把高级管理全部塞到主页面。

验收必须覆盖：

1. 画布 A 生成两张图、一条视频及一份配音，关闭页面后任务仍入库；新画布 B 可查并引用全部产物，包括未采用候选。
2. 提取张三、李四与一个场景，无图草稿在资产库刷新后仍存在；重复提取不复制同一对象。
3. 给张三上传主图，再批量生成缺图，只处理李四和场景；生成前展示对应报价。
4. 批量局部失败、刷新恢复、网络重试不重复建单扣费；成功项保留，只重试失败项。
5. 张三重新生成后旧画布不变，用户可主动切换；同名不同角色可区分。
6. 删除原节点/原画布不破坏已入库且被新画布引用的内容；签名过期可刷新获取。
7. 历史回补不重复、不恢复用户已隐藏内容，不调供应商、不新增生成收费。
8. 两个文件夹各有一个独立张三，@ 显示文件夹及缩略图；跨画布引用不移动/复制角色，删除文件夹保留内容并移至未分类；明确设置保存位置后只对后续新资产生效，已有角色的新版本仍挂原角色。
9. 一级导航没有“提取”及“快速编辑”；在剧本素材面板完成保存、完善后回到同一剧本，再从同一画布继续创作，正文、节点及视口保留。
10. 已有结构化设定直接建草稿不重复调模型；从正文解析使用保存的来源快照，原文事实与创作建议分开。再次更新提示差异，不覆盖人工确认的形象与描述。

### 《废市》的实际产品动线

1. 在现有创作画布中打开《废市》的剧本节点，进入原剧本编辑器。
2. 打开“素材”面板，选择“本剧资产 → 提取资产”。已有设定直接整理；纯正文按选定范围分析。人数与场景数取决于实际结果，不沿用原型固定的 6 人/4 组。
3. 核对江口、安子等人物及长走廊等场景，保存到用户自建的“废市”文件夹。保留场次依据；原文未写的外貌标为待补充。
4. 点击“完善资产”，给江口上传主图，为其他缺图项补提示词后批量生成。每次成功结果和候选都进入个人库。
5. 返回原剧本或画布，选用需要的资产。以后从现有创作页开另一张画布，`@江口` 选择“废市”文件夹里的同一人物，不重新提取或复制。

产品判断：学习两家对创作记录与可复用对象的区分、小云雀的提取后完善流程和 LibTV 的文件夹整理入口；本产品统一入口，避免让用户先理解素材库/资产库命名区别。全量入库、普通文件夹单归属、画布保存位置和精确版本引用是本方案自己的设计建议，不冒充竞品已验证规则。是否增加正式项目，应由后续多集生产、统一风格、成员协作等实际需求决定。

特别取舍：小云雀手册描述了资产一处更新、全链路联动的行为；本产品建议保留已采用版本，新增生成时使用当前主图，已有制作主动更新。这样能避免角色换主图后，旧镜头、已确认画面和任务参考悄悄变化。此项是基于本产品连续制作需求的判断，不机械照搬竞品。
