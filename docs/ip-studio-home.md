# Studio 创作首页

2026-10-08 · v0.207 · 本地实现，未发布。

登录后的 `/dashboard` 与手机创作入口 `/create` 共用同一 Studio 创作区。沿用本产品的群青、麦黄、纸白，以及既有资产名称字体与桌面顶栏；不复制 LibTV 的商标、配色或营销内容。

## 首页与创作动线

首页先呈现创作起点，再呈现继续创作、模板与灵感、数字资产和原有资产工具。创作想法可以为空：空白提交打开对应面板，有内容时先免费创建画布并保存一个可见的“创作想法”文字节点，再带入面板。输入正文不写进 URL。首页不发送模型生成请求；模型、参考、规格及费用仍在 Studio 中显式确认。

| 入口 | 实际落点 |
|---|---|
| 全能创作 | Studio 创作助手，全能模式，带入已保存想法与文字节点引用 |
| 图片创作 | 图片面板，可继续添加参考和选择模型 |
| 视频创作 | 视频面板，独立文生视频或补选首帧 |
| 剧本创编 | 剧本面板，可编辑设定、原创或粘贴文本 |
| 导演执导 | 同一助手的导演模式，讨论节奏和镜头 |
| 成片编辑 | 同项目成片视图；缺少片段时可回画布上传或创作视频 |
| IP 商品视频 | 同项目人物、商品与卖点表单 |
| 人物配音 | 同项目声音与台词面板 |
| 数字人口型 | 同项目视频与音频驱动面板 |
| IP 人物库 | 与画布添加共用的人物/素材详情选择器 |
| 空白画布 | 新建空白项目，画布不自动打开生成面板 |

“继续创作”读取本人真实项目列表，最近四张画布直接恢复原项目。模板与灵感分为官方模板、我的模板与精选画布：版本模板使用既有输入/报价/免费实例化表单；旧模板及示例创建独立副本，不改原内容。没有目录内容时明确展示空态；读取失败可重载，不冒充空目录。

保存想法失败后保留输入与已创建项目，重试只重新读取并保存同一项目。若上一次保存实际已经成功，读取后直接恢复；不重复写入或创建新项目。已有画布的其它节点保留，用户已修改的同一想法不会被首页旧草稿覆盖。

原有真人复刻、资产合成、声音训练及素材管理继续位于次级“更多资产工具”区域。资产与授权信息仍来自原接口；待处理授权直接进入授权页。

## LibTV 对照依据

2026-10-08 在 Chrome 中只读复核了已有 `https://www.liblib.tv/` 首页：新建画布创作，模型/视频/图片/音频/剧本/智能剪辑入口，最近项目，以及原创改编、导演执导、角色造型室与 TV Show 分类。TV Show 可筛选精选画布，部分作品可查看创作过程。本次没有新建 LibTV 项目、发送生成或公开内容。

我们将已经接通的创作能力与近期项目前置，并沿用同一项目内的对应面板、人物选择器与模板套用流程。模型入口按后台实际候选显示在创作面板，不将未配置模型品牌放成可执行首页按钮。现有成片编辑不等于 LibTV 的自动智能剪辑，精选内容仍是平台官方示例，未实现社区投稿与公开链接复制。高级视频、Skills 与声音克隆差距继续见[对齐记录](ip-studio-libtv-alignment.md)；首页完成不能替代全量功能验收。

## 实现与证据

主要代码：`src/components/hub/studio-home.tsx`、`src/ip/studio-entry.ts`、`src/styles/studio-home.css`。元数据保存在已有客户端画布文档内，没有新增后台接口或迁移。设备形态继续以 `html[data-layout]` 为真值，显式电脑版/手机版选择有效。

Chrome 已逐一验收图片、视频、剧本、导演、成片、商品视频、配音、口型、人物库、空白画布和全能创作的实际落点。图片想法保存并刷新恢复，助手想法自动引用；最近项目打开原项目，不再创建一份。手机 `/create` 显示相同十个主要功能。没有提交模型生成。

模板人物选择首次发现套用表单遮挡人物库：全局 `.ip-surface` 查询误命中固定顶栏，手机该顶栏还会隐藏。已改为明确内容容器，画布继续使用既有 body scope；选择人物时暂时隐藏模板表单，输入状态保留，确认或取消回到同一表单和原选择按钮焦点。实际 dialog 由 title 建立“IP 人物库”可访问名称。桌面和375×812手机均能选择小紫的整张设定图、保留自定义名称并返回输入；手机免费制作计划返回1张/8积分，未实例化或生成。

前端完整回归35文件/253项通过。新增8项覆盖真实入口、正文保存、保存失败沿用同一项目、未知保存结果恢复、版本模板不提前实例化；最终弹窗修复后4文件/14项通过，最后生产构建通过。workspace类型与API契约通过。浏览器明细为 `.studio-e2e/home/browser-report.json`，界面证据及impeccable独立审查/文档记录在同目录。生产部署、OIDC/MySQL验收未做；完整状态见[验证记录](ip-studio-unified-canvas-validation.md) §18。
