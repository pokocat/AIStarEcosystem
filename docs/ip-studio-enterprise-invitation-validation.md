# 企业群发邀请：实现与验收

> 2026-10-17 · 本地实现，未生产发布。用户要求直接重写，不兼容旧单次邀请。

## 功能

- 企业管理员选择 90 天（默认）或一年，创建、复制分享链接；同一链接可供多人注册/登录后加入，可随时撤销。
- 品牌页 `/enterprise/invite#token=...` 展示真实企业身份、有效期、手机号/验证码表单；已有会话显式确认。桌面双栏，手机优先加入操作。
- 注册使用现有 ID SMS grant；企业邀请由本产品接受，不创建账号级推荐关系、不自动授予产品开通或积分。
- 其他企业成员、停用成员、无效/撤销/过期邀请、运营查看均不能借此绕过限制；网络失败可重试，保留原邀请与已完成的登录。
- token 不落本地存储、不进入 URL path/query；匿名 preview 通过 POST 正文，响应 no-store；页面 no-referrer/noindex。

## 数据变更

V59 清空 `aep_enterprise_invitations` 中旧邀请，删除 `accepted_by`。新的群发链接加入后仍有效，每个加入动作独立记录审计。清理不触碰企业成员、自然人账号、钱包、账本或作品；迁移只在检测到旧列时执行，重复运行不删除新链接。

## 发布边界

需要一起发布 server（V59）和 web-aiavatar；新页面与 preview 必须同版本可用。保留原企业功能开关和产品开通要求。上线会使旧邀请失效，管理员需创建新链接。生产数据清理和正式短信注册尚未执行，不以本地结果代替。
