# 资产库交互原型验收记录

日期：2026-10-11。范围：独立本地原型，不包含后端接入、真实模型生成、积分扣费或生产发布。

## 已验证的主流程

通过真实浏览器界面点击完成：

1. 从用户提供的《废市》剧本（92场）建立本轮6位主要人物和4组主要场景。
2. 快速编辑展示原文依据、场次入口、人物描述和可编辑的创作提示词。
3. 一键补图对9项有提示词的资产报价72演示积分，志乃因提示词空缺留待完善。
4. 开启“一项失败”演示：其余项继续生成入库；江口单独重试成功。
5. 新建“废市 · 长廊初遇”画布，在选择器中搜江口，同时出现本剧和其他创作的同名独立角色，显示文件夹、描述、来源及版本。
6. 引用本剧江口v1及贝原家长走廊v1，输入画面描述，演示生成结果自动进入全部素材。
7. 江口生成v2并设为主图，旧画布继续显示v1，出现可主动更新的提示。
8. 实际本地图片文件上传为v3主图，保留旧版本；旧画布仍为v1。
9. 刷新页面后资产、上传图片、描述编辑和画布引用保留。
10. 将待完善项显式复用到已有角色后，保留完整编辑列表、完成进度、批量操作和原剧本依据；引用已有资产ID，不复制新角色。
11. 手机端打开文件夹管理菜单，确认改名和删除入口可见。

以上测试均未发起模型请求。上传测试图片来自仓库已有演示资源，不是《废市》的正式形象设定。

这是基于真实剧本整理的固定提取结果，不是运行中的AI提取器。生成预览使用已有示意图片，不验证人物一致性、场景准确性或真实模型效果。
