# 资产库原型的页面约束

THESIS: 生成结果成为可找回的个人素材；角色与场景成为可持续完善、准确引用的对象。

OWN-WORLD: 沿用 web-aiavatar 的 DESIGN.md：暖灰背景、白纸表面、深墨按钮、中文宋体标题。原型独立，保留生产设计文件。

STORY: 《废市》92场剧本 → 本轮精选6角色4场景 → 源文事实和创作建议分开 → 上传或演示补图 → 显式确认主图 → 新画布引用具体版本。普通单层文件夹组织资产，不发明项目实体。同名人物用文件夹、来源和缩略图区分。

FIRST VIEWPORT: 原型采用60px深墨导航（区别于生产壳的导航形态，正式接入时复用生产壳）和个人资产库标题；左侧文件夹，中央素材卡片，剧本入口带真实92场与本轮范围。示意图片明确标注。无营销大图。桌面四列素材，手机两列。快速编辑左列表、中央主图与版本、右表单及出处。

FORM: code-led ordinary extension of incumbent world. 无新视觉世界、无需独立概念图。关键交互：提取后的同一对象在编辑、库、@选择器之间连续存在；画布节点锁定版本，主图改动只提示新版本可用。动画只用于加载、状态切换和生成进度；respect reduced motion。

FINISH: HTML/CSS/JS语法检查；浏览器真实点击完整动线；桌面与手机截图；独立finish reviewer；独立documenter核对既有设计，不覆盖DESIGN.md。
