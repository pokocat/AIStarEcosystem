## 继承与实际差异

| 方面 | 源码观察与结论 |
| --- | --- |
| 主色与工作面 | 暖灰背景 `#f0efec`、白纸面、深墨 `#192229`、次文字灰 `#65707e`、细边线 `#e8eaec` 与既有规范一致。主按钮 hover 使用既有 `#323e45`；常规面板以底色、边线和留白分层，无常驻强投影。 |
| 状态 | 绿、赭金、红及各自浅底沿用既有值，用于可引用、待完善 / 演示、失败等状态，并有文字说明；没有将待完善伪装为成功。 |
| 字体职责 | 标题、人物名使用中文衬线栈；正文、输入、筛选、按钮使用无衬线栈。原型未加载生产自托管字库，实际字体依赖本机回退；标题和卡片名采用 500 字重，并非既有规范的 700 字重。 |
| 形状与焦点 | 小圆角控件、较缓圆角白面、细边线保持既有材料语言。控件通常最小高度 44px，焦点为深墨 2px 外轮廓、外偏移 3px；控件具体尺寸属于原型实现，未登记为新系统令牌。 |
| 导航偏差 | 桌面原型采用 60px 深墨导航，既有主系统是浅色共享顶栏。这是明确的原型差异，仅用于本地流程演示，不构成生产设计系统变更。 |
| 布局 | 桌面资产库为文件夹列加四列素材，快速编辑为列表 / 主图版本 / 表单三列；详情图使用 contain，卡片缩略图使用 cover。页面没有营销大图，内容与操作为主。 |
| 设备 | CSS 读取 `html[data-layout]`，脚本以 960px 默认断点写入；窄屏素材两列、编辑区重排，画布保留可滚动工作区。原型没有生产应用的显式设备切换与偏好持久化。 |
| 动效 | 加载旋转、轻量 hover 和状态提示；保留减少动态偏好覆盖。进度条宽度动画已在验收修正中移除。 |

原型的 CSS 变量只存在于这一独立页面，未注入生产应用。剧本入口的淡绿提示面及本页布局尺寸是局部实现，不提升为全局令牌。未来接入应用时，仍需使用既有作用域和设备选择逻辑。

既有 sidecar 的标题仍写为「Design System: AI IP 画布」，与当前 DESIGN.md 的标题不同；本轮只记录这一已有命名差异，未借原型任务改写设计文件。

## 内容与交互语义

资产、编辑页和选择器使用同一对象身份；名字允许相同，以来源、文件夹与缩略图区分。引用保存具体版本及图像，主图变化只触发可主动更新的提示。新版本保留在「全部素材」，没有用主图覆盖历史候选。

《废市》JSON 有 92 场，编号从 1 到 92；原型固定精选 6 位人物和 4 组场景。原文依据与可编辑创作建议分开。初始示例、生成预览和素材来源均明确标注；单项失败保留成功项并提供重试，报价不进入真实积分账本。

## 验收结论的范围

既有验收记录已报告桌面 1440×1000 与手机 390×844 的资产库、编辑和画布截图检查，及提取、部分失败 / 重试、同名引用、结果入库、版本保留、真实本地图片读取与刷新恢复的浏览器点击流程。它没有验证真实 AI 提取、模型画质、完整全片资产覆盖或生产接入，也没有逐项验收全部辅助操作。

本轮文档核对支持「沿用既有暖灰 / 白纸 / 深墨材料与字体职责，并明确保留原型差异」；没有将原型的局部样式反向声明为既有应用的新规范。
