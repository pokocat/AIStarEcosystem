# Studio 邀请落地页设计

2026-10-17 · 独立交互设计稿，尚未接入或替换线上邀请链路。

来访者是收到朋友链接、还不了解 Studio 的创作者。首屏应回答：朋友邀请我用什么、能做出什么、接受后去哪里。沿用 Studio 已确认的首页品牌与摄影素材，在同一视觉语言内增加邀请信息和单一主动作，不重新设计品牌。

- 分享地址应在 Studio：`https://aistar.aibuzz.cn/invite/{code}`。首屏保留 IP Studio、声量引擎归属、品牌口号、朋友的邀请和创作示意。
- 产品证明来自人物、影像与故事的视觉示意和可切换展示，不增加用户数、收益、获赠积分、免费使用或效果保证。
- 主动作“接受邀请，开始创作”；认证交给 ID，完成后回 Studio。已有账号登录不新增邀请关系；注册不等于产品开通。
- 手机先看品牌、邀请人、主动作，再看内容；主动作在首屏内。桌面以双栏形成文字与作品的对话。
- 原型包含正常邀请、已有账号、邀请失效、读取失败四种状态；CTA 只展示接入说明，不发短信、不建账号、不调用生产 API。

## Direction contract

THESIS：在 Studio 既有公开首页上增加朋友邀请这一明确入口，以创作画面说明产品，以邀请人建立来访上下文。

OWN-WORLD：继承暖灰底、白纸面、深墨操作、中文衬线标题、蓝灰品牌图标与暖色摄影；不用另一套账号中心视觉替代产品。

STORY：识别 Studio → 看见人物、影像和故事 → 认出朋友的邀请 → 接受并完成账号验证 → 返回 Studio。

FIRST VIEWPORT：桌面左侧为两行品牌主标题、产品说明与邀请行动，右侧为大幅创作示意及三个可切换方向；手机将邀请与行动放在大图之前，避免接受入口掉出首屏。

FORM：既有 Studio 首页的局部扩展；继续原双栏图文结构，只替换创作入口为邀请上下文，因此不另起视觉世界或方向抽签。交互锚点是人物／影像／故事切换。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 业务与后续接入边界

ID 保存邀请码和邀请关系；Studio 只提供品牌入口和本人视图。后续用既有 OIDC/PKCE 携带邀请码并保留应用回跳；不可接受任意 return URL，不改产品开通和积分。

初版 ID/Studio 功能代码已经部署，但本次线上首注册闭环尚未验收。用户指出通用 ID 链接脱离 Studio 后，调整为先审阅本页设计，再继续应用入口与注册回跳修正。指定测试手机号已按用户要求释放，旧账号归档、撤销登录并发送注销事件；本设计稿不再操作该账号。

## 设计检查说明

已执行一次静态设计检查：功能小字已统一提升至至少 11px；图片裁切容器和 `details` 被误报为贴边，实际图片为有意满铺，说明内容由内部留白承载。标题 shorthand 被扫描器误读为正文大小，浏览器实际手机主标题 43px、桌面约 56px；以真实页面测量和截图为准。原始检测输出保留在预览截图目录，不通过扩大忽略规则来隐藏报告。

## 原型验证与独立复核

实际浏览器验证 1280×720 和 390×844，均无横向溢出；390px 主按钮底边约 434px，位于首屏。人物／影像／故事可切换，方向键可移动标签；CTA 弹出接入说明，关闭正常；邀请失效隐藏邀请人、读取失败可重试恢复正常。此处是原型交互验证，不是生产认证验证。

四张有效截图见 [预览目录](studio-invitation-preview/)；截图 URL 的 `capture` 参数仅隐藏原型工具条，避免固定工具条遮挡长图，不隐藏页面内容。原型默认保留状态切换工具条。

独立 finish reviewer 首轮确认品牌、产品表达、邀请与手机动线达到原型要求，只要求 FAQ 字符图标换为 SVG。已按同一笔画修正；单项复核为 **resolved，disposition: ship**，重拍四张截图有效，未发现本次修复引入的回归。该最终复核仅对唯一修复项作确认，非生产功能验收。
