# Studio 邀请落地页设计

2026-10-17 · v2 直接注册稿。独立交互原型，尚未接入生产短信、注册或替换线上邀请链接。

用户最新要求：打开邀请链接就能输入手机号注册，不再先点“接受邀请”。保留 Studio 品牌与产品展示，邀请区简化为一行邀请人、手机号、验证码、注册按钮。

- 主按钮：**注册并进入 Studio**。手机号验证、创建账号和邀请绑定由 ID 负责，成功后直接进入 Studio。
- 新账号注册、已有账号登录使用同一验证码表单，不需要额外选择登录方式。已有账号的原邀请关系不变。
- 删除“接受邀请”、说明弹窗、“注册或登录后回到 Studio”和重复登录入口；产品介绍缩为一句。
- 邀请失效时清楚说明可普通注册；读取失败时先重试，不悄悄丢失邀请码。
- 保留品牌口号、摄影示意和人物／影像／故事切换；不新增用户数、奖励、积分或免费使用承诺。

## Direction contract

THESIS：朋友的邀请与手机号注册放在同一个 Studio 页面，来访后直接填写，没有中间确认页或接受按钮。

OWN-WORLD：继承 Studio 暖灰、白面、深墨按钮、中文衬线、品牌图标与暖色摄影；表单复用相同材料语言。

STORY：打开朋友链接 → 输入手机号并获取验证码 → 注册或登录 → 进入 Studio。

FIRST VIEWPORT：桌面左侧品牌标题和邀请注册表单，右侧创作示意；手机先显示品牌和表单，主提交按钮在首屏内，产品画面排在其后。

FORM：既有 Studio 首页的局部扩展；保留双栏构图，以手机号表单替换邀请确认模块。不重设全局视觉系统。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 原型与接入边界

[打开方式及交互](../../prototypes/studio-invitation/README.md)。演示验证码固定为 `123456`；输入仅存在当前页面，不会发送短信、提交手机号、创建账号或写邀请关系。错误、重发倒计时和提交反馈是原型行为，不能作为真实注册验收。

正式接入时，Studio 保持该品牌表单，ID 继续提供短信验证、账号创建和邀请绑定；不再使用“先跳通用 ID 邀请页、再接受”的路径。保留邀请码与应用回跳约束，不将身份或邀请真值放入 Studio，也不因注册自动开通产品。

初版邀请后台与管理视图已部署；完整线上首注册闭环待新入口接入后验收，见[发布记录](../releases/unified-account-referral-production-release-20261017.md)。指定测试手机号已释放，本次仅修改设计稿，不再操作生产账号。
