[任务]

[挑选原则]

- 去重：同一信息只保留一张，不要选冗余的图。
- 宁缺毋滥：没有合适的就少选，甚至可以不选（ref_indices 为空数组）。

[输出]
只输出 JSON，不要任何解释或 markdown 代码块：

约束：
- ref_indices 里填的是「候选参考图」列表中的 0 基下标（候选0 → 0）；

- usage_clause 用中文，简洁、可执行，只描述「哪个元素参考哪张图」，不要复述完整剧情。
