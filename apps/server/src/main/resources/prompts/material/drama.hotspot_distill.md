实时热词（每行一条）：
{{topics}}

## 一、先丢掉这些热词

时政 / 硬新闻 / 灾害事故 / 事实性事件播报 / 讣告 / 体育赛果 / 明星八卦纯爆料 / 任何敏感或不宜娱乐化的话题。

这一条针对的是**那件事本身**不该被娱乐化，不是让你放弃整批热词。热搜里通常同时混着生活、情感、校园、职场、消费、穿搭、亲戚关系这类词——先把这些挑出来用。

## 二、每条钩子必须「同一个人、同一个世界」

热词只提供**情境**（谁、在哪、正在做什么）。钩子后半段的冲突或反转，必须是**这个情境里的这个人**真的会碰上的事。

动笔前先把这三格填满，填不满就丢掉这个热词，不要硬凑：

- **谁**：一个具体的人，身份和年龄段要跟热词情境对得上
- **情境**：直接来自热词
- **冲突**：这个人在这个情境里遇到的具体麻烦或反转

## 三、下面五种一律不要（出现即丢弃，不要修补）

1. **话题域 / 主体错配** —— 热词属于一个话题域，后半句属于另一个，被硬焊在一起。
   - ✗ `包书皮时意外发现，前任留下的惊天伏笔` —— 热词是「学生开学」话题，后半句是「成人恋爱史」话题，两个域焊在一块，课本里出现前任伏笔也纯属生造。
2. **世界错配** —— 前后半句不在同一个时代或设定里。
   - ✗ `军训偶遇武状元，从此被全校高攀不起` —— 军训是现代校园，武状元是古代科举。
3. **因果不成立** —— 热词里的动作推不出后半句的结果。
   - ✗ `贴秋膘吃出百万身家，打脸势利眼亲戚` —— 多吃两口和挣到百万之间没有任何路径。
   - ✗ `开学第一课观后感，竟预言了全校大反转` —— 写观后感不可能预言别人的事。
4. **纯口号** —— 没有人、没有情境，只有励志话。
   - ✗ `想一万次不如做一次，逆袭从此刻开始`
5. **空心套模板** —— 全靠「竟 / 惊天 / 从此 / 顶流 / 伏笔」这类词撑戏，把这些词删掉就什么都不剩。
   - ✗ `难吃的一顿饭，竟揭开豪门惊天秘密` —— 哪顿饭、谁家豪门、什么秘密，一个都没交代。

自查方式：把「竟、惊天、从此、震惊全网」这类词全部删掉后再读一遍，如果剩下的话立不住，这条就不合格。

## 四、成立的样子

- ✓ `全班都穿同款校服，只有她的是定制的` —— 学生、校园、一个具体差异，三格都在同一个世界里。
- ✓ `开学第一天，新来的班主任是我妈的相亲对象` —— 学生视角 + 开学情境 + 这个学生真会遇到的尴尬。

## 五、其他

- 一个热词最多产出 1 条，不要为了用完热词而硬凑。
- 12–24 字。不要副标题，不要书名号。
- 去重，近似选题合并成一条。
- **逐条判断，不要整批放弃**：拿三格标准一条一条过，过关的就留下。不要因为「整批不够惊艳」而什么都不给。通常能出 **4–8 条**。
- 只有当这批热词**确实全部**落在第一条的丢弃类别里时，才返回空数组。
