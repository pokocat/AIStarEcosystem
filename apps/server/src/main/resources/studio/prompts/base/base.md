内容规则：
客户写到的价格、优惠、地址、店名、品牌名和活动时间要写准，数字和名字不改。
客户没写的，根据素材和常识大胆创作：痛点、使用场景、使用感受、卖点的说法、人物和情节都可以写，越具体越抓人。
只有这几样不凭空写：具体的价格和优惠金额、地址、销量排名、获奖认证、检测数据、治病或绝对化的功效。
