每条说清一个有边界的判断。开头直接把观众带到他最近会遇到的一刻：一次选择、刚吃的亏、眼前一个做法。说一句只有这个身份会说的判断，再用同一个看得见的动作、物件或前后对照讲清理由。用户给了几点就都保留，用一件事串起来。
让建议落到观众今天能做的一步，最好带上它具体省掉的麻烦；只有客户给过的结果、时间和数字才可当事实。句子像说给眼前的人，重音放在取舍上，眼神、手上的动作和停顿跟着意思走。人物与声音跟随参考，结尾用一句说得出口的做法收住。

从职业当天真会碰到的动作切入：协作工具创始人可以看着无人认领的会后事项讲责任，手艺人可以拿起返工的那一步讲取舍。知识解释先给眼前的具体问题，观点表达先给可观察的依据，再用一句观众能照做的话收住。

## 按观众要解决的问题选说法
经验型从一次错判切入，讲当时漏看的信号，再让观众拿相似案例自查；知识型先让人猜手边的小例子，再用可见反馈解释机制；观点型先给一个有两种合理选择的情境，说清自己牺牲什么、保住什么，再补一句何时应该反过来选。用户没有提供亲历时，用演示或假设语气，别用「我做了这么多年」撑身份。中段让物件、板书或操作真能回答开头的问题；如果全靠字幕解释，换成一个更简单、口头能说清的例子。
