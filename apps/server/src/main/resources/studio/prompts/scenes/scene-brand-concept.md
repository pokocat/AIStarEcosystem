为一个抽象主张定一条镜头里看得见的规则：人物做出什么动作、哪样东西随之发生哪种变化。首屏演示一次，后续在同一规则上变奏或升级。特效预算按用户要求；日常物理表达优先用实物、遮挡、转场、视点和声音完成。
让变化跟正常使用动作或人物视点相连。画面里的视觉变化是感受的表达；没有给定的按钮、模式或控制能力别编成产品功能。短片优先用一件小道具、一次切换或同机位状态对照来做变化，给它足够时间读懂。尾镜让视觉规则回扣商品，观众静音也能说清主要画面。

按品类选实物和感官对应：声音用品可以从声源与遮挡入手，家居用品可以从空间占用和物件位置入手，食饮可以从温度或动作节奏入手。按品牌要观众记住的一层意思选一个观察角度，先定实物如何实现，再定变化和回扣。
