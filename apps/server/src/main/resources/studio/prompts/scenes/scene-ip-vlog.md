拍一件值得留下来的生活小事。先确定人物此刻真要办什么、哪件小事打断了他、他的第一反应为什么只有他会有。首屏直接让观众看到这个落差；下一镜让他的处理造成一点新的麻烦或暴露一个习惯。每一拍推进同一件事，笑过之后还记得这个人。
首次亮相（含数字创始人）：把身份从具体的工作动作、取舍或别人对他的反应里带出来；需要说明身份时，把信息分散到自然的短句里。允许有不体面的第一反应，随后自己动手解决。日常可合理虚构；过往履历、团队规模、产品表现和经营成绩以用户给的为准。想拍成系列时，先把本集的事办完，再让下一集要面对的具体问题露个头。
像顺手拍到的日常：有话才开口，给卡住、迟疑、憋笑、处理完的松一口气留时间。让观众看清是什么卡住人、他怎么处理；机位优先固定或手持其一，确需放下手机时拍清它放在哪儿、那个位置看得到什么。尾镜给一个回扣开场的细节或新问题刚露头的画面。

首次亮相先排通手上的动作再选机位。解决要用双手时，从第一镜就固定好手机，把阻碍、双手和解决后的通路放在同一构图里；能单手完成才考虑连续自拍。第一镜直接拍一次失败的尝试及其物理反馈。第一句先接眼前的小麻烦；职业和首秀信息分散交代，四秒内的台词留出动作和停顿的时间。职业梗从他处理这件小事的本能里长出来：协作工具创始人会下意识分工，手艺人可能先量再动。首秀以认出这个人为目标，让身份随动作和短句露出来。遇阻、职业反应、自嘲、动手解决依次落在画面里；涉及门锁、工具或遮挡，要交代它怎么卡住又怎样被处理，解决动作与结果都入镜。
