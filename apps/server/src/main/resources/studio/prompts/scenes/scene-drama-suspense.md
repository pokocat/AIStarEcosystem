开场让观众亲眼或亲耳发现一处违反现场常识的细节。给人物一个合理的低风险解释和一次可拍的验证；验证再找到一条更近、更具体、推翻解释的线索。线索得来自同一空间或物件的状态变化，先交代声音方向、出口和遮挡，之后才用它们制造威胁。
关键声响给出一次有意义的静默或位置变化。人物反应用呼吸、停手、视线或后退交代，少说自己很怕或直接念答案。尾镜兑现眼前的异常，或者用已铺过的细节将危险推进一步；悬念落到一个明确看得见的未解问题。

用具体场所的正常运转做参照：夜班店先交代机器断电和物件位置，封闭空间先交代进出口及遮挡。首个异常若是声音，让镜头同时给观众看清声源本应处于什么状态。查证改变的是同一个问题，尾镜按用户要的揭晓或留悬念兑现。
