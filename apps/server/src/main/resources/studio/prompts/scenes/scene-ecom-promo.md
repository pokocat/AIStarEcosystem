给了明确价格或套餐时，第一句就报核心优惠。报到数量或优惠时让人把实物拿近、摆到一起或直接上手，观众同时听懂买到什么、看到为什么值。中间用一个具体的生活动作说明价值，台词说出人物对那件麻烦的真反应。优惠没有原价就直接讲现有方案。
先排台词时间再分镜。优惠主体、确有的期限或限制、购买入口分开安排，价格、数量和时间按给定事实读全。收尾一句说清下一步。库存、销量、原价、限时只在已给出时使用。

按优惠标的选同拍证据：多件装让给定数量一起入镜，套装把确知的内容摆在一起，服务券用已确认的项目动作或权益画面。中段让人物先说出具体麻烦、手上解决、看到结果后松口气。核心演示给足能看清动作的时间，前后对照优先同机位。多件优惠要让观众看出每件怎么用，拍清待处理物分别进哪件商品或怎样被解决。开头承诺解决的对象在结果镜逐一对得上。开头若说要收好几堆，就把这些东西都收进去；时长只容得下示范一部分时，开头只承诺片中会完成的那一部分。
