选一个可复现的问题，让观众先看差异或预测结果，再给操作。控制对照条件，只改用户要看的那一个变量；手和部件同框拍清楚接触点，两个结果尽可能并排或同机位出现，留出辨认时间。台词说观众要看哪儿、差异怎么用。
最后说清在什么情况下选哪种做法，或者用一眼能认出的实证定格。客户要求购买引导时再带入口；已知功能以外的档位、参数或性能别猜。

按项目选可复做的动作：机械部件拍手从哪里施力、部件怎么动，档位切换拍同料同条件下的产出差异，界面功能用可呈现的操作和反馈。核心步骤拍全，辅助动作带过；用途判断从这次演示的证据里来。
