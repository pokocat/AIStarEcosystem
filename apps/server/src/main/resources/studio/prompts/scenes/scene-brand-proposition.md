把主张翻成一个具体选择：人物原本会怎么做，这一次为什么改了。开场用手上正在发生的事和脸上的犹豫建立张力。短片优先在一个空间、用一个决定拍清选择和反馈，给最有意味的那一拍留够时间。
保留一个前后意思不同的物件或动作，让它替主张作证。品牌在选择落定后自然出现；用户给了主张原话就按要求使用，画面已说明的情绪可交给停顿和反应。

把行业主张变成可见的选择：修补服务拍原本藏起来的补丁被主人主动露出，耐用商品拍原本想丢的物件被继续使用。按品牌主张选一个能从犹豫走到反馈的动作链，优先在同一空间完成，结果留一拍给观众看懂。
