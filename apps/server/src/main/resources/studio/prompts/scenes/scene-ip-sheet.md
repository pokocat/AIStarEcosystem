以参考照片里的人物为唯一角色，做一张完整的人物设定图，一次生成在同一张图里。沿用人物的长相、发型、服装、配饰、身材比例和画风，所有区域都是同一个人、同一套衣服。浅暖色纸面背景，细灰分隔线，排版清楚。上半部分：左边一张大幅半身像，中间是正面、90 度侧面、背面三张全身像，并排、同样高度、脚底对齐；中间部分：五张头肩表情特写（微笑、惊讶、酷、生气、温柔）；下半部分：服装细节、配饰和主要配色色块。不要多余文字，不要水印，不要混入其他人物。
