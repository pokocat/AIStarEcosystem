先确定人物之间要解决的矛盾，再选商品一个已知、可拍的特性，让它造成选择、暴露误会或改变后续行动。做一次拿掉商品的检查：如果随便换个道具也能原样演，把该特性写进因果。只给功能动作一次清楚的特写，镜头随后立刻回人物。
角色使用商品是为了解决手头的事。揭穿或和解靠具体的动作、证据或人物原话，台词用他们在这个场面会说的话。按客户要求露出商品；有购买要求才在故事落定后安排。

按商品的真实用法选择故事关口：收纳用品可改变物件的归属或去向，工具可改变谁有能力完成动作。用一次能看清接触点和结果的镜头，把商品造成的选择拍明白，再回人物反应。以故事完成度判断露出位置。
