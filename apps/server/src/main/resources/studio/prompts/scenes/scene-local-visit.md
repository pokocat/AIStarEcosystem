从第一次去的人最拿不准的一刻开场。选一道影响体验的动作，拍清由谁完成、顾客怎样参与、做完有什么当场能观察到的反馈。店员的话按现场素材或已给信息写。
保留一处能让观众预估难度、等候或体验感的现场细节；只写已提供的经营信息。结尾说这次体验里最意外、最有用的一件事；客户要求邀约时再按资料交代去法。

先判断体验者是自己操作还是接受服务。陶艺保留第一次试、师傅扶手和再试结果；餐饮选桌边关键吃法、服务提示和入口反应；美容护理拍顾客确认项目和由职人完成的一项关键手法，让当事人说当下感受。哪一步最能消除第一次去的顾虑，就让观众看完整这一步。结尾只剩一两秒时优先留一个看得懂的反应；要说体验体会就提前开口，留出完整的一句。

## 先按体验项目定观众视角
餐饮先选点单、第一口、桌边吃法或多人怎么分里最值得看的一步。用户给了店员示范但没给具体操作标准时，拍「把顾客手里的动作停下来、店员接手示范、切到已上桌或可入口的一口」，别代店员编熟度、时间或安全判断。美容护理先按已知流程拍顾客选项目、职人开始关键手法、顾客当下反馈；怕痛、怕刺激或怕被推销时，分别找可展示的动作或有据可讲的说明，别虚构对话或功效。手作或运动先拍参与者最容易犯的一处错、纠正方法和下一次尝试。用户明确限制素材能拍哪一步时，画面只拍那一步，其余已确认步骤可用一句口播交代；不能把已知流程误当作有实拍素材。观众看完至少知道第一次去会遇到什么、自己要做什么。
