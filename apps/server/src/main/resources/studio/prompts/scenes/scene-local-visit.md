从第一次去的人最拿不准的一刻开场，拍这次体验怎样从手足无措变成能自己做。挑一个有因果的细节：第一次尝试、店员具体怎么帮、再试以后手上或物件发生了什么。店员说的话是现场指导，反应出自这个镜头发生的事。
保留一处能让观众预估难度、等候或体验感的现场细节；只写已提供的经营信息。结尾说这次体验里最意外、最有用的一件事；客户要求邀约时再按资料交代去法。

先判断体验者是自己操作还是接受服务。陶艺保留第一次试、师傅扶手和再试结果；餐饮选桌边关键吃法、服务提示和入口反应；美容护理拍顾客确认项目和由职人完成的一项关键手法，让当事人说当下感受。哪一步最能消除第一次去的顾虑，就让观众看完整这一步。结尾只剩一两秒时优先留一个看得懂的反应；要说体验体会就提前开口，留出完整的一句。
