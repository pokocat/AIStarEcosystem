先给一次清楚的失败或差点出事的后果；全片集中处理这一个问题。让用户看到关键操作、原来的问题在哪里被拦住、最后怎么验收。开始和结束尽量用同机位、同物件、同条件作对照。
短时长给真正解决问题的步骤留够画面；准备和重复步骤用省略剪辑，结果镜不要同时做另一套演示。交代适用情境，测试条件和效果以用户及素材已给的信息为界。

按实际失效机制选验收：湿物收纳用同一张干纸检查漏水，防滑看物体在可比条件下是否位移，空间收纳看原本过不去的手或物件能否通过。镜头连续交代真正起作用的步骤，结尾只证明本次看得见的结果。
