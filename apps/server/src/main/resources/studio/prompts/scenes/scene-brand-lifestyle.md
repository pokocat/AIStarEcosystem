拍一个普通人原本可能放弃、最后仍做成的生活片刻。先亮出空间、时间或关系上的真实限制；产品用一项具体动作腾出机会。镜头跟着人怎么决定和怎么用，生活声和边角的小麻烦比完美摆拍更重要。
末镜用收拾、归位、余温或自然反应说明这件事是日常能发生的。让一句顺手说出的生活话或动作收住；产品露出保持清楚，避免用旁白替代人物体验。

把限制放进具体时刻：小户型折桌先拍脚被自行车挡住，通勤物件先拍正要出门时双手腾不出来。围绕产品要为日常腾出的机会，把使用、体验和收尾归位拍成同一个人的动作链，结尾保留一句顺嘴的生活话。
