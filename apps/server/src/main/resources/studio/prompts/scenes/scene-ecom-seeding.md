挑一个观众熟悉、有明确当下愿望的生活片刻；开头从愿望险些落空、或人物在两件事之间为难开始。产品在他自然伸手使用时进入画面，让一个可见变化把这个片刻继续下去。只演这次用法，画面和声音都服务同一种感受。
给结果留一拍，让观众能代入使用后的生活。口吻像告诉熟人最近发现了什么，结尾可以只留体验或一个可感知细节。客户指定引导时用和情境相符的一句，入口按给定信息写。

按品类挑能让人记住的一瞬间：阅读灯拍想多读一页又怕吵醒人的停手，厨具拍想省一步却怕弄乱台面的犹豫，穿戴品拍实际穿用时的小选择。商品顺着这个动作进入，种草目标靠人物当场的口气、环境声和一个细节收住。
