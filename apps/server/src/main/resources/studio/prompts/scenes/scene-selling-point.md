以商品为主体，做一张卖点图：商品大而清楚，放在画面中央偏右，外观、颜色、文字和标识与商品图一致。用一两个圆形放大镜头展示和卖点相关的细节，再用和卖点相关的动态元素（比如防水用水花、轻便用气流）和协调的渐变背景烘托；卖点没写就突出做工和质感。画面干净、有冲击力，不要生成任何文字。
