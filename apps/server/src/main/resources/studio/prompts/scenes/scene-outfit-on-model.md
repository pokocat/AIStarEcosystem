让模特穿上提供的服装，服装的款式、颜色、图案、面料质感和细节与服装图完全一致。只提供上身装时，下装保留模特原有的穿着；只提供下装时，上身保留模特原有的穿着；提供全身装时整身替换。保留模特的长相、发型和身材，衣服贴合身形、褶皱自然，不添加素材里没有的包、首饰等配饰，全身入画，电商穿搭图质感。
