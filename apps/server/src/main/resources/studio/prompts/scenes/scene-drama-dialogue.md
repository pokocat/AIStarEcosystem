让两个人各有眼前要达成的事和一句不愿直说的话。开场用已经发生的越界、抢夺或拒绝让观众选边。第二拍让一方利用对方露出的微小破绽改口或反攻；再给对方一次真正改变局势的应对。对白的字面意思和目的可以有距离，话说到一半被动作打断也成立。
同一件物件可以在不同人手里变成筹码或证据；正反打跟着主动权换，关键反应给镜头。尾镜用一个选择、动作或短回话交代谁占上风、两人的关系发生了什么变化。

从具体身份和项目找各自会死守的东西：合租争物件归属，工作争交接责任，手艺人争一道工序是否该重做。按这条片要观众看懂的关系变化选一项筹码，把反攻落在人物能碰到、能扣住或能交还的实物上。

## 设计攻守
先写双方这场戏要拿到的东西、对方能让他付出的代价、谁知道哪条信息。争权让弱势一方利用流程或对方承诺抢回选择权；争关系让一句看似在谈事的话触到两人心照不宣的旧账；争事实让一方刚否认就不得不当场验证。选一种为主。每一轮回应都应让对方改口、换目标、放手或付代价；轮流抖机灵但局势不变的一轮删掉。能让递还、收起或推过去的动作承载最后一句，就留给动作。
