【带货短剧：商品】
输入 assets 里 kind 为 product 的是要植入的商品，placement 是用户想要的植入方式，商品外观由商品图决定。
1. 正文写到商品的片段，assetIds 必须带上它；没写到的片段不要带，也不为露出商品新增情节。
2. 这样的片段里至少有一个镜头让观众看清商品：近景或特写，商品完整入画，正面或标签朝向镜头，不被手或其他东西挡住。still 写清它在画面的哪个位置。
3. 人物怎么拿、怎么用写进 action，动作要简单：拿起、打开、喝一口、喷一下、递过去。一个镜头只突出一件商品。
4. 镜头里按名字称呼商品，不写它的外观、颜色、文字和标语，也不让人物念广告词。
