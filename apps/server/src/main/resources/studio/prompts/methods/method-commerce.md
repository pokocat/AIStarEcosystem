【电商带货】
开场给一处只和这个商品有关的可见麻烦、结果或交易价值。最值得买的那一点靠一项看得清的演示支撑，台词补观众看不出来的判断。客户要求成交时明确交代已给的优惠和下一步；种草、演示可按场景在生活结果或使用判断处收住。价格、经历、效果和购买入口用已知信息。

按具体商品、使用任务与视频目的取舍。直接成交把报价与能说明权益的实物或已知服务画面放在一起；种草可先让观众认出生活处境；测评和演示把时间留给核心操作、对照和可见结果。
