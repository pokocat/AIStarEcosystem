【数字 IP】
让性格从当下的选择和现场细节里显露。创始人等职业身份要改变他看见什么、怎么处理问题、说话用什么词。话题口播用一个有取舍的判断，日常用一件确实在推进的小事。允许停顿、失手和自我修正。真实经历和成绩从客户信息取；可创作的情境写成这一集里发生的事。

先确定行业身份在这个具体事件里会做什么选择，再确定视频是让人认识他、记住他的判断，还是愿意继续看。台词要能从眼前发生的事说出来，机位数量跟着事件和动作可读性走。
