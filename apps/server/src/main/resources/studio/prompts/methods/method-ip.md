【IP 类视频的爆款经验】
人设要鲜明：说话有自己的口气和小动作，像一个真实的人在镜头前，不是播音腔。
开头抛一个反常识的观点、一个扎心的问题或一个结果，让人想听下去；观点类内容分点讲，每一点配一个能看见的画面。
语气有起伏，重点句放慢、加重，表情跟着内容变，可以手持自拍、边走边说，增加真实感。
结尾一句好记的总结，再给一个动作（关注、评论、来店）。
