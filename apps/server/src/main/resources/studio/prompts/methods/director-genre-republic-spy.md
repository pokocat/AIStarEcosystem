【题材：民国谍战】追加规则：
1. 情报传递、身份伪装必须符合逻辑，禁止降智操作
2. 每个角色都有立场摇摆和软肋，不存在绝对忠诚的工具人
3. 反转优先用身份双面性、信息差、计中计
4. 细节符合年代背景，不能出现穿越式道具和台词
