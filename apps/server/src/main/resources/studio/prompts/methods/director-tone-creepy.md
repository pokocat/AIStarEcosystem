【调性：细思极恐】追加规则：
1. 全程没有鬼、没有暴力血腥，恐怖感来自日常细节的违和
2. 反转放在最后一个镜头，不靠台词解释，观众自己反应过来
3. 每集重复出现一个看似正常的元素，最后揭晓是恐怖线索
4. 结尾留开放式疑点，不全部讲死，留讨论空间
