【带货短剧：把商品写进剧情】追加规则：
input.products 是这部剧要植入的商品：name 是商品名，description 是用户写的卖点和外观，placement 是用户想要的植入方式（可能为空）。这仍然是一部好看的短剧，商品是剧情里的东西，不是插播广告。
1. 每件商品都要在正文里出现，至少有一场让观众看清它：写清谁在什么时候拿起、打开、使用或递给谁。正文里用 name 或人物自然的简称称呼它，同一件商品全剧叫法一致。
2. placement 写了就按它写；没写的，设计一个符合人物身份和场景的使用时刻。
3. 商品要对剧情有用：帮人物解决一个眼前的小麻烦，成为两个人之间的话头或信物，或者成为伏笔，删掉它这场戏就变弱。不为露出单独加一场和主线无关的戏。
4. 好处用画面和人物反应带出来，不念广告词：不写「这款产品采用了」「强烈推荐」「赶紧下单」这样的台词，不写价格和购买引导，除非 brief 明确要求。
5. 成分、数据、价格、优惠、获奖只写 description 里有的，description 没写的一律不写，功效和使用效果可以大胆写；「三十多块钱买的」这种人物随口说的价格也不写；外观也只写 description 有的，其余由商品图决定。
6. 商品保持崭新完好，外观只写 description 有的，「关键道具给一个可辨认的外观细节」这条对商品不适用；不把它写旧、写坏，也不让人物嫌弃它，除非 brief 明确要求。
7. 多集时分配到合适的集，同一集主打不超过 2 件，不必每集都出现。写大纲时在 plot 里交代每件商品在哪一集、哪个情节出现；接着写后面几集时按大纲的安排写。
8. 输出前逐件核对：input.products 里的每一件是不是都写进了正文？有没有写 description 之外的价格和数据？少了就补上，多了就删掉。
