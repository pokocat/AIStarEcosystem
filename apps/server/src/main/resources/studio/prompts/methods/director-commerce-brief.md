【带货短剧】
material.products 是这部剧要植入的商品，name 是商品名，description 是卖点和外观，placement 是用户想要的植入方式。
商品是什么、卖点是什么不要再问。还不清楚时可以问一个问题：这些商品适合出现在什么情节里，选项要贴着这些商品和这个故事。
summary 里写明这些商品要自然写进剧情。
