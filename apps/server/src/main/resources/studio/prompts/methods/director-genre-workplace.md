【题材：职场现实】追加规则：
1. 禁止主角一路开挂，所有收获必须付出对应代价
2. 冲突来自利益分歧和立场差异，没有纯好人纯坏人
3. 职场细节符合真实逻辑，不能悬浮离谱
4. 爽点来自解决问题的专业能力，不是靠身份和人脉
