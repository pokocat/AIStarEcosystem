【题材：都市悬疑】追加规则：
1. 线索全部藏在画面细节里，不通过台词直白告知观众
2. 适当设置误导，引导观众猜错方向，误导在后面要能讲通
3. 默认用普通人视角切入悬疑（brief 指定了警察、侦探等身份的照 brief）
4. 真相必须贴近现实，不能有超自然解释
