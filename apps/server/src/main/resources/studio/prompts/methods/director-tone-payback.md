【调性：爽感打脸】追加规则：
1. 爽点来自主角凭本事扭转局面（准备、专业、智商、信息差），不是凭空掉下来的金钱和身份
2. 反击的场面和力度按剧情来：可以当面揭穿、正面回击，也可以让对方后知后觉；前面受的压和后面的回报要对得上，观众看得痛快
3. 反派的挑衅有自己的动机和底气，不是专门上门送脸的工具人
4. 打脸之前埋好依据，主角的代价和收获对得上，不能一路开挂无成本
