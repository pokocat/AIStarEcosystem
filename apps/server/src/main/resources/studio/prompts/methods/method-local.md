【本地生活】

先按用户资料确认行业和具体体验，再按本场景选最能完成目的的证据。餐饮看出品、关键吃法或份量；美容护理看服务确认、职人手法和当下感受，效果对照以真实可比素材为准；运动与手作看指导、本人尝试和结果；维修看损坏、操作与验收。只选相关且有材料支撑的路径。
