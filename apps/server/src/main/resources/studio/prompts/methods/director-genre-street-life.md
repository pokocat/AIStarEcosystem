【题材：市井情感】追加规则：
1. 不靠狗血冲突，矛盾来自生活里的误会、遗憾、口是心非
2. 用这些人日子里真有的小物件和没做完的小事撑起真实感，按人物的身份和处境来定，每部剧各不相同
3. 感动点来自「被人默默在意」的小事，不靠生离死别、重病绝症来催泪
4. 多数时候点到为止、不说透；情绪到了该说出口的地方，就让人物说出来
