【剧情】
先为人物定下眼前目标、阻力和可能失去的东西。开场让一件事已经发生；后续的动作、发现或选择要改变下一拍。观众在什么时候知道什么，由信息差、可见线索和反应控制。把最强一拍留给人物的选择或发现，尾镜给这个选择的后果。表演力度跟题材走，关键处可交给停顿、环境声或动作。

用行业或生活背景决定人物懂什么、怕失去什么和能做什么，具体事件决定哪个物件或动作推进下一拍。开头让观众看见正在发生的事，张力按题材和视频目的取舍。
