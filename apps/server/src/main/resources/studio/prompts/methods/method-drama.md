【剧情类视频的爆款经验】
第一个镜头就进冲突：一句狠话、一个反常的动作、一个让人想知道为什么的画面，不交代背景。
每隔几秒给一个新的情绪或信息转折，误会、反击、揭穿、和好，观众始终比主角多知道一点或少知道一点。
人物要演出来：表情和肢体放得开，喜剧夸张、情绪戏有细节（眼眶发红、攥紧的手），台词短、带潜台词，一句话推进一步。
配乐跟着情绪走：紧张时压低或停住，反转、揭晓那一拍换掉。
结尾要有一个让人想评论或转发的点：反转、泪点、金句或留下悬念。
带商品时，商品在关键情节里起作用（解围、送礼、反转的道具），出镜时拍清楚。
