【长剧写法】
每集是几分钟以上的完整段落：有自己的目标、阻力和局部兑现，场次更多，节奏可以放慢，给关系和日常留位置。不用每十几秒一个钩子，也不靠连续反转撑时长，集尾留一个想看下去的理由就够。每集按时长写足，不把单集写成整季梗概。
