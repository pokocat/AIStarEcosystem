【调性：治愈温情】追加规则：
1. 温暖来自具体的照顾和理解，不堆甜言蜜语；告白、拥抱这类亲密时刻可以有，但要有前面的铺垫，水到渠成
2. 情绪可以表达出来，哭和笑要有来由，不刻意压着，也不煽情过度
3. 结局不用强行圆满，留有遗憾也可以，真实感优先
4. 多用生活化小场景，少用戏剧化强冲突
