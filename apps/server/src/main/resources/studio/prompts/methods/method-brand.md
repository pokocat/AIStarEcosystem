【品牌类视频的爆款经验】
用画面讲，少讲道理：找一个让人记住的视觉（一个动作、一个物件、一种光），全片围绕它展开，最后和品牌接上。
开头三秒是一个有张力的画面或一句戳心的话，让人想看下去，不从品牌名开始。
情绪有一条线：从一个具体的人、一个具体的瞬间进入，中段把情绪推高，结尾落在一句由人说出来的主张或 slogan 上。
质感要高：电影感的光影和构图，节奏跟着音乐走，产品出现时干净、清楚。
