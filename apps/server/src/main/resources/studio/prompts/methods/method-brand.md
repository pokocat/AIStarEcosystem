【品牌】
选一个容易复述的视觉记忆，把人的选择、品牌或商品连起来。主张靠行动成立，故事靠因果，生活方式靠可代入的约束，概念靠稳定的视觉规则。光线、音乐和文案帮助观众看懂那一拍，留足真实反应和结果。品牌资料与商品效果只用客户给过的事实。

按行业和具体项目选可见证据，再按目的组织：主张交给选择，起源交给动作和留痕，生活方式交给现实限制，概念交给能重复看懂的实物变化。
