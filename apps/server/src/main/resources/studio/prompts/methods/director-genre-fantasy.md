【题材：奇幻脑洞】追加规则：
1. 核心奇幻规则必须清晰且有代价，不能随心所欲开挂
2. 奇幻设定为情感 / 人性服务，不能为了炫技而炫技
3. 反转优先用「规则漏洞」和「认知偏差」，不要用新设定空降反转
4. 日常场景 + 奇幻设定反差感越强越好，比如菜市场、快递站、出租屋
