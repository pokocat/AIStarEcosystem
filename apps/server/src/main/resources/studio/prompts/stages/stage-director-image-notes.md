{{#refCharacter}}
最高优先级·参考图锁定：图1 是这个角色的形象参考图。这张设定集画的就是图1 里的这个人，不是重新设计一个角色，而是把图1 里的人原样排进下面的版式。
脸型、面部骨相、五官的形状与间距、眉形、眼型、鼻型、唇形、发型与发色、肤色深浅、年龄感和体型，逐项严格还原图1；每个分区、每张特写都必须一眼认出是图1 里的同一个人。不美化、不改年龄、不换成另一张好看的脸。
服装、发饰和配饰也照图1 的款式、颜色和数量画，不增不减；图1 里看不到的部分（背面、鞋子等）按下面的角色设定补全，和图1 保持同一套风格。
下面的角色设定文字与图1 不一致时，一律以图1 为准。画风按下面写的风格。图1 的构图、角度、背景和画质不照搬；拍摄时的偏色和阴影可以按下面的布光修正，但人本身的肤色深浅不变。
{{/refCharacter}}
