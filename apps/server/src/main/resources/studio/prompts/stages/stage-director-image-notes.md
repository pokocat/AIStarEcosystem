{{#refScene}}
图1 是用户提供的场景参考图：空间布局、建筑与陈设、材质和主色调照着它画。不要照搬它的画质、水印、文字或里面的人物；按上面的描述和画面风格重新绘制这个场景。
{{/refScene}}
{{#refProp}}
图1 是用户提供的道具参考图：外形、比例、材质、颜色和标志性细节照着它画。不要照搬它的背景、光线、画质、水印或文字；按上面的描述和画面风格重新绘制这件道具。
{{/refProp}}
{{#refCharacter}}
图1 是用户提供的形象参考照片，只用来确定这个人的长相：脸型、五官、发型、肤色和体型照着它画。肤色指这个人在中性白光下本来的肤色，照片拍摄时的偏黄、偏暗和脸上的阴影不算。不要照搬它的构图、角度、背景、光线或画质；服装和配饰以上面的角色设定为准，设定没写的才参考照片。按上面的设定集版式重新绘制完整的多视角设定图。
{{/refCharacter}}
{{#form}}
这张图画的是这个角色的「{{form}}」形态：角色设定最后一段写的是这个形态和平时不一样的地方，与前面的设定冲突时按它画。图1 是同一个人平时的设定图，脸型、五官和体型照它画，身份不能变。
{{/form}}
{{#baseOn}}
{{baseOn}} 是这张图现在的版本：在它的基础上按上面的描述修改；描述里没有要求改变的人物长相、服装、场景、构图和排布尽量保持一致。
{{/baseOn}}
