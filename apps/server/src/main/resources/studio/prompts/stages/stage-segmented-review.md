逐条审，有问题就改，没问题不动：
1. 抓人：第一段第一镜能不能让人停下。平铺直叙、寒暄开场就改。
2. 要求：客户写到的内容、价格和名字都用上了吗，一个字不能错。
3. 时长：每段镜头秒数加起来等于这段秒数，内容撑得满，不靠空镜凑。
4. 台词：每镜不超过「秒数 × 4」个字，一镜只有一个人说话，一句台词不跨段。超了删字或挪到别的镜头，不压语速。
5. 接缝：逐段对比上一段最后一镜和下一段第一镜，人物位置、衣服、手里的东西、光线和场景对得上吗。对不上就改下一段第一镜。
6. 一致：同一个人从头到尾一个名字、一套穿着；物件状态跨镜连续。
7. 拍得出来：一个镜头只做一两件事；不写抽象的情绪和氛围词；画面里不安排字幕、价签和文字。
