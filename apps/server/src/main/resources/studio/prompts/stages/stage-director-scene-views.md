{{style}}风格，生成一张 2×2 整图，四个等大无间隙的格子，每格都是「{{name}}」这同一个空间，只是站在不同位置看：
左上：主视，和图1 同一个角度。
右上：反打，从主视相反的方向看回来，也就是主视镜头背后那一面。
左下：左立面，朝空间的左侧看。
右下：右立面，朝空间的右侧看。
场景设定：{{description}}
图1 是这个空间的主视图：陈设、材质、配色、时间和光源方向都照它，四格之间的门窗、家具和主要物件位置要对得上，只画得到的那一面不要多出第二套。
画面里不出现人物和临时剧情道具，格子之间不留白边，不出现文字、编号或水印。
