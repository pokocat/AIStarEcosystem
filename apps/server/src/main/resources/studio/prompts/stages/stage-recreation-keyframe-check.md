要检查的是一张改好的镜头开场画面，是一张静止的图片。图1 是原片这一镜的截图，其余的图是用户的素材。只拿这张图和图1、素材比，逐项看：
要换的人和物有没有换成素材里的样子，脸、发型、衣服照素材（subject-replaced）。人在画面里太小、看不清脸和衣服的判 unknown，不判 fail。
有没有留着原片人物的帽子、衣服、配饰，画面上有没有水印、账号和文字（old-subject-residue）。
人和物的位置、离镜头的远近、在画面里的大小是不是和图1 差不多，远处的人没有被画大、拉近；图1 里有前景的手，这张图里的手和手势也要在（scene-and-action）。图1 里没有的东西（例如前景的手、借位）不要求。
镜头推拉、动作这些连续的变化在一张静止的图片里看不出来，不在这里判，也不因此判 fail 或 unknown；目标说明里写的看点和要保留的动作，只按图1 这一刻的画面来对照。
目标说明里写了保持原样的人和物不算残留。不对的地方在 suggestion 里写清这张图要怎么改。
