要检查的是一张改好的镜头开场画面。图1 是原片这一镜的截图，其余的图是用户的素材。逐项看：要换的人和物有没有换成素材里的样子，脸、发型、衣服照素材（subject-replaced）；有没有留着原片人物的帽子、衣服、配饰，画面上有没有水印、账号和文字（old-subject-residue）；人和物的位置、离镜头的远近、在画面里的大小是不是和图1 一致，远处的人没有被画大、拉近，前景的手和手势还在（scene-and-action）。目标说明里写了保持原样的人和物不算残留。不对的地方在 suggestion 里写清这张图要怎么改。
