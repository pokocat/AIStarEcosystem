## 4.1 账号管理中心（AccountManagementCenter）

### 4.1.1 页面目标

为 MCN 掌门人提供多平台短视频/直播账号的统一管理：
1. 绑定新账号并关联到某位 AI 艺人；
2. 跟踪每个账号针对每位明星的"报白"（明星IP授权白名单）申请状态；
3. 对冷启动期账号提供合规增长建议（官方渠道、平台工具、专属顾问私域）。

### 4.1.2 入口与跳转

| 入口 | 行为 |
|---|---|
| 侧边栏"账号与发布 → 账号矩阵" | `setActivePage('account_mgmt')` |
| 总览页待办"2个报白账号待提交材料补充" | 跳转本页（默认落在"账号列表"Tab，而非"报白状态"Tab） |
| 总览页快捷导航"账号管理 · 5绑定" | 跳转本页 |
| 本页出站跳转 | 无。"了解详情""加急（¥299）""扫码绑定"等按钮均无跳转 |

#### 状态流转（期望规则，依据状态枚举推导）

```
unsubmitted ──提交申请(扣⬡200)──▶ pending ──平台/明星方审核──┬─▶ approved
                                     ▲                        ├─▶ rejected ──修改后重新提交──▶ pending
                                     │                        └─▶ supplementing
                                     └──────补充材料后提交────────────┘
pending ──支付¥299加急──▶ pending(加急)
```

#### 业务规则

### 4.7.10 业务规则

1. 平台费固定 10%，MCN + 艺人 = 90%。
2. 默认方案（isDefault）不可删除；每位艺人应至少有 1 个生效方案（建议）。
3. 带 minMonthlyGmv 的方案仅在当月 GMV 达标时生效，否则回落默认方案（期望规则，原型未体现）。
4. 明星联动方案优先级 > 平台方案 > 全平台默认方案（建议）。
5. 结算金额 = round(totalGmv × pct)。
