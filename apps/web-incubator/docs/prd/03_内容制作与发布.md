# 第3章 内容制作、发布与宣发

> 本章覆盖“素材 → 文案 → 制作（切片 / AI数字人 / 混剪批量）→ 发布池 → 内容日历 / 规划 → 全网分发 → 矩阵宣发 / 直播控制”的完整内容生产链路，以及 AI 艺人编辑器内的音乐、影视、公告业务模块与两个独立弹窗（AI音乐生成、NFT铸造）。
>
> **事实来源**：`/workspaces/default/code/src/app/components/` 下的 React 原型源码。原型中所有数据均为前端 Mock 常量（如 `MOCK_ASSETS`、`MOCK_COPIES`、`MOCK_TASKS`），无后端接口；文中“现状差距”一节逐条标注原型与可上线产品之间的差距。
>
> **通用约定**
> - 语言：所有页面通过 `lang: Lang`（`'zh' | 'en'`）切换中英文，`zh = lang === 'zh'`。下文仅列中文文案，英文文案见源码。
> - 平台代码：`DY`=抖音、`KS`=快手、`XHS`=小红书、`VCH`=视频号、`BL`=B站（源码中直接使用缩写展示）。
> - Mock 人物：真人合作方“张艺星”“林音宝”，品牌方“极速数码品牌”“清洁卫士品牌方”。
> - 动效：列表/卡片统一使用 `motion` 渐入（`delay: i * 0.04~0.06`），展开区使用 `AnimatePresence` 高度动画。
> - “统计卡数值”若源码为硬编码常量，在字段表中标注“硬编码”。

### 3.2.8 状态与流转
- 资产状态：`reviewing`（入库待审）→ `available`（审核通过）；`available` →（授权过期/侵权）→ `frozen`；`available` →（权属争议）→ `disputed`；`frozen`/`disputed` →（续签/处理完毕）→ `available`。（原型仅静态展示，无流转动作。）
- 授权状态：`authorized` →（距到期临近）→ `expiring` →（过期）→ `expired`；示例 a6 为 `frozen + expired`，体现“授权过期 ⇒ 资产冻结”的联动。

### 3.2.9 业务规则
1. 冻结资产不可下载（隐藏下载按钮）且展示冻结警示。
2. 只能下载最新版本（第一行）。
3. 版本命名序列固定：原始版 → 剪辑版 → 字幕版 → 加水印版（越新越靠上）。
4. 统计卡基于全量 Mock，不随筛选变化。
5. 授权状态与资产状态独立展示，二者均需满足（available + authorized/expiring）才视为可用于制作（建议规则，原型未校验）。

### 3.2.10 空态/加载/异常
- 筛选无结果：网格为空，**无空态提示**（差距）。
- 无加载态、无错误态。

### 3.2.11 验收标准
1. 默认展示 8 张资产卡，统计卡显示 8 / 6 / 1 / 1。
2. 搜索“林音宝”返回 a2、a4、a7 共 3 张卡。

7. 再次点击已展开卡片可收起；点击另一卡片时前一卡收起。
8. 每卡标签不超过 3 个。

- 批量入库、新增素材、预览、下载均无功能；无上传流程、无文件格式/大小校验。

## 3.3 文案库（CopyVault）

### 3.3.8 状态与流转
```
draft ──提交──▶ ops_review ──通过──▶ partner_review ──通过──▶ legal_review ──通过──▶ approved(锁定)
                    │驳回                │驳回                     │驳回
                    └────────────────────┴─────────────────────────┴──▶ rejected ──修改(版本+1)──▶ draft
```
步骤状态判定 `getStepStatus(copy, stepKey)`（按顺序）：
1. stage=rejected 且该步意见存在且 passed=false → `rejected`（红，XCircle）；
2. 该步意见 passed=true → `passed`（绿，CheckCircle2）；
3. stage 等于该步 key → `current`（琥珀，Clock，附“审核中”标签）；
4. 当前阶段 step > 该步序号+1 → `passed`；
5. 否则 `pending`（灰，40% 透明）。

### 3.3.9 业务规则
1. 审批顺序固定三阶段，不可跳级。
2. 任一阶段驳回即整体 `rejected`。
3. `approved` 文案版本锁定，不可再编辑（不显示操作按钮）。
4. 极限词/风险词（示例：“全球首发”“史上最低价”）命中时在列表与详情双处提示，并应阻止进入下一阶段。
5. 文案有适用范围：合作方 × 平台 × 商品 × 有效期；超范围或过期不可被引用（建议，原型未校验）。
6. 只有 approved 文案能被 DigitalPersonHub 使用（数字人任务 g3 因引用 cp4 被阻断“文案含风险词，生成已阻断”“文案未通过法务终审”）。

### 3.6.8 状态与流转
- 模型：`training` → `review` → `active`；授权到期 → `frozen`（续签后恢复）。
- 生成任务：`generating` → `review`（质量审核，含质量分与问题项）→ `approved` → `in_pool`；任一前置校验失败或质量不达标 → `failed`。

### 3.6.9 业务规则
1. 只有 `active` 模型可用于生成（弹窗过滤与按钮显隐双重体现）。
2. 冻结模型（授权过期/待续签）禁止生成。
3. 文案必须为 CopyVault `approved`；含风险词或未过法务终审的文案将阻断生成（g3）。
4. 生成结果需质量审核，问题项（如“口型同步度偏低”）须处理后方可通过。
5. 每个模型必须绑定授权合同。

### 3.6.10 空态/加载/异常
无空态；`generating` 任务以旋转 RefreshCw 图标代表进行中；失败以问题标签展示原因。

### 3.6.11 验收标准
1. 统计显示 3 / 2 / 4 / 1。
2. 模型库筛选“声音模型”仅显示 m2、m5。
3. m5 显示“已冻结”与冻结提示，不显示“用此模型生成”；m3（review）也不显示。
4. 弹窗形象模型列表仅 m1、m4，声音模型仅 m2。
5. 点击遮罩或取消关闭弹窗。
6. 生成任务 Tab：g1 显示“入发布池”；g4 不显示预览按钮；g3 显示两个红色问题标签。

### 3.6.12 现状差距
- 弹窗不能真正选择模型/文案，“开始生成”不创建任务；无文案选择器、无平台/时长参数、无费用说明。
- 入发布池、预览无逻辑；模型训练/上传入口缺失；`training` 无 Mock。
- 质量分阈值未明确定义；`selectedModel` 选中无详情面板。
