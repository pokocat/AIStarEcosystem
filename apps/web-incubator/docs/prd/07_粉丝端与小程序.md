### 7.0.2 通用约定

| 约定项 | 说明 |
|---|---|
| 语言 | 所有模块接收 `lang: 'zh' \| 'en'`；粉丝端与 Coach 后台额外接收 `setLang`，可就地切换；两个小程序只读 `lang`，内部无切换入口 |
| 返回 | 粉丝端 `onBack`、小程序 `onBack` 均回到 `portal`；Coach 后台 `onLogout`；孵化器 `onBack` |
| 数据 | 全部 Mock 常量 + 组件内 `useState`，刷新页面或切换 Tab 卸载组件后状态丢失 |
| 动效 | 统一使用 `motion/react`：Tab 切换淡入位移（0.15–0.25s），列表项按索引递增 delay（0.04–0.06s） |
| 图标文字 | 原型使用 3 字母占位符代替 emoji（如 `MUS`、`HOT`、`GEM`、`HRT`），正式版需替换为图片/图标资源 |
| 金额 | 字符串直出（如 `¥1,240`、`0.05 ETH`），无数值计算、无币种换算 |

### 7.0.4 全局业务规则摘要

1. **平台佣金加成**（两个小程序共用）：抖音 +3%、小红书 +5%、视频号 +2%、B站 +4%、快手 +3%、全部 +0%。展示佣金 = 商品基础佣金 + 当前筛选平台加成；在「全部」下不叠加。
2. **名额（Quota）**：`占用率 = round(takenQuota / quota × 100)`；创业者端 ≥100% 红色、≥70% 琥珀；切片端 ≥80% 红色。
3. **任务五步流**：0 领取 → 1 已领取 → 2 AI 生成中（定时器 1.6s/2.0s）→ 3 素材预览 → 4 选平台（≥1 个）→ 5 发布成功。
4. **NFT 稀有度**：common / rare / epic / legendary 四档，分别对应灰 / 蓝 / 紫 / 金配色。
5. **礼物价格（虚拟币）**：小心心 1、星星 5、火箭 50、皇冠 100、钻石 500。
6. **签到**：创业者端连续 5 天、今日签到 +50 积分；切片端连续 3 天 +30 积分。
7. **授权合规**：切片端品牌任务若关联明星授权未通过（`status: locked`），任务不可领取。
