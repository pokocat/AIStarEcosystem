# AI 艺人孵化平台全端演示 · 产品说明

> 需求详情看原型自带的文档：[全平台 PRD](docs/产品需求文档_PRD.md)、[分章 PRD](docs/prd/)、[明星端产品文档](docs/产品文档.md)。
> 本应用是**演示**，不是正式产品的真值；正式产品规格仍以各子应用的 PRODUCT.md 为准。

## 定位

给业务方和内部看完整产品设想：平台如何把明星 IP 授权给生态创业者，孵化 AI 艺人、做内容、运营账号矩阵、带货变现，再多方分账。

## 模块

| 端 | 主要内容 |
|---|---|
| 落地页 | IP 生态总览、十种 IP 类型的方案页、AI 艺人专题页 |
| 生态创业者工作台 | 工作台、IP 孵化中心（我的艺人 / 明星专区 / 艺人市场 + 7 步孵化向导 + 出道仪式）、培训认证、素材中心、制作工坊（含 AI 导演台）、账号矩阵、发布中心、投流管理、数据看板、变现中心、收益管理、粉丝运营、授权与审核、设置 |
| 明星 IP 端 | 总览、IP 授权中心、报白账号、数字人授权、AI 形象授权、内容审核、商品入库、商品库、品牌授权、分成收益、授权规则、侵权巡查、合同中心 |
| 品牌端 | 数据总览、AI 艺人匹配、发现投流、议价 |
| 运营后台 | 运营总览、用户管理、内容审核、法务中心、平台分析、系统配置 |
| 粉丝端 | 发现、实时排行榜、NFT 市场、我的、音乐播放 |
| 小程序（两个） | 创业者：任务、佣金、报白、账号绑定；切片：切片素材、带货任务、收益 |

## 约束

- 全部示例数据，不调接口、不扣积分。
- 不替代任何已上线的子应用，也不从它们取数据。
- 人物和作品都是虚拟的，不写真实艺人（2026-11-06 起）。线上 `incubator.aibuzz.cn`，公开访问，不被搜索引擎收录。
