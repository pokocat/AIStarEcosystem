Studio 静态版（给设计用）

怎么打开
  Mac：双击「启动-Mac.command」。如果提示无法打开，到「系统设置 → 隐私与安全性」点「仍要打开」。
  也可以打开「终端」，输入 python3 和一个空格，把 serve.py 拖进窗口，按回车。
  Windows：双击「启动-Windows.bat」。
  浏览器会自动打开页面目录。用完关掉那个黑色窗口即可。
  需要电脑上有 Python 3。Mac 没装时，系统会提示安装开发者工具，或到 python.org 下载。
  解压后再打开，不要在压缩包里直接双击。

这是什么
  页面、样式和交互来自线上代码（{{COMMIT}}，{{DATE}}）。
  不连后端，不需要登录，所有数据都是示例数据，不会真的生成内容或扣积分。

可以操作的
  新建画布、拖动和编辑节点、创作助手对话（回复是写好的示例）、AI 图片和 AI 视频的生成流程。
  生成结果是占位图和一段示例视频。导演台可以看剧本、资产和分镜。
  画布的改动存在这个浏览器里，刷新后还在。对话记录刷新后会重置。

不能操作的
  导演台里的生成、编辑和一键制作，以及上传、发行、企业积分操作，会提示「静态演示版不能执行这项操作」。
  登录页没有内容，打开会直接进工作台。

字体
  英文和中文字体从 Google Fonts 加载，连不上时用系统字体，界面文字会略有差别。线上也是这样。
