# 首页 · 设计意图

范围：公开 `/` 与登录后桌面 `/dashboard`，实现 `src/components/landing/ip-home.tsx`。视觉系统见 `../DESIGN.md`。

首页让用户先看见角色和世界，再选择创作方向。英雄区左侧两行中文衬线标题与深墨主按钮，右侧暖色摄影风格人物，保留自然皮肤和发丝细节；随后是四张创作方向图卡与三张灵感示意卡。图片来自用户提供设计方向的 AI 创作示意，不能当作真实客户产物或营销数据。

「开始创作」、方向卡与故事卡先免费进入对应个人画布；匿名用户先登录。登录后「继续创作」只展示真实近期三张画布，读取与创建失败均有反馈，空态提供空白画布入口。付费生成在节点内确认，首页不替用户提交。

公共和登录后桌面首页共享组成；移动 `/dashboard` 仍为 HubHome。旧 root hash 与真人授权回调恢复保留。本轮桌面验证，不宣称手机或窄屏截图验收完成。
