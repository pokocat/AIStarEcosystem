# 首页 · 设计意图

范围：公开 `/` 与登录后桌面 `/dashboard`，实现 `src/components/landing/ip-home.tsx`。视觉系统见 `../DESIGN.md`。

首页让用户先看见角色和世界，再选择创作方向。英雄区左侧两行中文衬线标题与深墨主按钮，右侧暖色摄影风格人物，保留自然皮肤和发丝细节；随后是四张创作方向图卡与三张灵感示意卡。图片来自用户提供设计方向的 AI 创作示意，不能当作真实客户产物或营销数据。

「开始创作」、方向卡与故事卡先免费进入对应个人画布；匿名用户先登录。登录后「继续创作」只展示真实近期三张画布，读取与创建失败均有反馈，空态提供空白画布入口。付费生成在节点内确认，首页不替用户提交。

公共和登录后桌面首页共享组成；移动 `/dashboard` 仍为 HubHome。旧 root hash 与真人授权回调恢复保留。本轮桌面验证，不宣称手机或窄屏截图验收完成。

## 2026-11-13 主视觉改版（本地，未发布）

用户要求：不用实际图片，用颜色和线条做出未来感；声波的线条穿过去时自然形成标题的字，字要有书法感，大胆但清爽，对话框不要厚重。最终用户给了一张定稿字图（2026-11-14）。

现在的样子：标题是用户给的字图 `public/studio/home-title.webp`（原图 2000×667，按内容裁掉上下空白成 2000×334）：彩色声波从左（青）穿到右（橙红），经过中间时写成手写体「衣冠百变　戏路万千」。图是近白底；样式里饱和度降到 65%、提亮 4%（用户觉得原图太艳），底色也就成了纯白；电脑上铺到页面两侧的留白里，手机上放大 1.2 倍、裁掉两头只有细线的部分。打开页面时一道软边从左往右把图扫出来，「减少动态效果」时不动。h1 里有隐藏文字给读屏和搜索，图片 alt 为空。下面是副标题、细边半透明胶囊对话框（右边黑色「开始对话」，手机上只留圆形箭头）和一行浅色常用开头。

实现 `src/components/landing/home-hero-title.tsx`、`StudioConversationStart` 的 `pill`，样式在 `src/styles/studio-home-scenes.css` 末尾。换标题图时直接替换那张 webp（保持宽高比或同步改组件里的 width / height）。
