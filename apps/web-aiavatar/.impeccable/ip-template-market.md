# 模板市场 · 设计意图

范围：`/templates`，实现 `src/ip/studio-template-market.tsx`，复用 `studio-gallery.tsx`、`src/styles/ip-create.css` 与现有模板预览。模式：Operate。方向依据为 [ip-create-direction.md](ip-create-direction.md)；视觉系统沿用 [DESIGN.md](../DESIGN.md)，与 [创作页](ip-create.md) 共用浅色顶栏、暖灰底、白色工作面和深墨操作。

用户在这里挑选可复用的画布流程。顶部保留返回创作入口，目录以官方模板、我的模板、用户发布模板三项切换，当前项明确标识；官方与个人模板可按名称和说明搜索。封面为真实节点与连线 minimap，附模板名称、说明、节点数和来源；禁用模板明确显示「已停用」。数量来自实际模板列表，加载和失败时使用未确定标记。

点击已启用模板打开现有只读画布，可以浏览、缩放和查看提示词；此时没有个人项目、同步或生成工作台。只有「存为个人副本」才免费创建普通可编辑画布，失败保留预览，保存中防重复提交。个人副本在节点内选择本人素材、编辑和确认生成费用，原模板及其他副本保持各自身份。

「我的模板」延续本人画布「发布为模板」的私有保存与复用路径，符合条件的本人版本模板可停用/重新启用；状态更新失败保留原状态并说明错误。官方目录另保留既有精选画布，按 ID 去重；运营角色仍可进入原 `/projects/demos` 官方内容管理，不新增管理后台。

「用户发布模板」明确标记「待建设」，说明未来可发现他人流程，并提供查看我的模板的入口。当前个人发布不能被描述成公开市场已上线；这里没有虚构作者、热度、购买或下载数据。模板目录与官方示例独立读取、失败与重试，空目录和搜索无结果有对应说明及返回创作入口。

本轮本地路由和真实目录读取通过，实际检查及测试范围见 [创作页](ip-create.md)。最终审查为 `recapture`：浏览器控制超时，尚无该页面在 1536/1280 的有效最终截图，不能宣称渲染视觉验收通过。现有设计系统文件与 sidecar 保留，手机专项设计未开展。
