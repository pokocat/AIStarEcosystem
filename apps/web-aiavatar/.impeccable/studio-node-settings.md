# Studio 节点参数交互

Mode: Operate。范围是现有画布内的创作节点配置，不更换网站或画布的视觉系统。

用户给定 LibTV 参考：底栏直接展示模型与当前参数摘要；点击摘要打开分组浮层；比例用矩形预览与数字表示；选项直接点选并保留明显的选中状态。

## Direction contract

- 第一屏：创作要求和参考素材在节点面板；模型、独立的视频模式、参数摘要、总费用和箭头提交在固定底栏。设置浮层不再撑长正文。
- 图片：清晰度为实际 size 的档位摘要，附精确宽高；比例图形化；数量来自模型的批量能力。改比例时保留已选清晰度档位，找不到匹配规格才用该比例首个合法尺寸。
- 视频：模式、清晰度、比例与数量直接点选；时长用常用值与合同范围内的整数秒输入；素材在正文单一的编号缩略图条；按新增/移除的素材自动匹配合同支持的模式，一张图片优先图生视频、两张图片优先首尾帧，混合素材选择参考模式；手动选定的兼容模式保留，禁止隐藏或丢弃素材；模式菜单禁用不兼容选项；随机种子移到默认折叠的高级设置，保留固定值并可恢复随机。
- 剧本/分镜、文本修改、配音、口型、视频解析沿用相同的模型入口和参数浮层。只有模型的节点不强加无用设置；素材选择继续使用搜索/多选控件。
- 保持现有 .ip-surface 令牌、浅色工作面、深墨文字、细描边和紧凑控件。浮层只使用现有投影层级；不改全局色板和字体。
- 参数浮层独立滚动，按可用视口空间限制高度，挂在当前触发器最近的 .ip-surface；手机按 html[data-layout] 适配，模型/模式与参数/费用提交有序分成两行。
- 方向键切换选项，选中项可聚焦；Esc 先收起当前设置并归还焦点；参数修改不提交任务。固定模型仍显示名称。
- 能力真值：服务器模型目录与合同。没有服务端支持的画质、透明背景等选项不展示。

## Verification boundary

共享控件与各节点回归验证提交快照、草稿恢复、模型切换、费用与未知任务确认。临时本地预览页只用于视觉验收，不进入发布制品；线上验收只改参数，不调用收费生成。
