# IP 管理 · 设计意图

范围：`/ips`，实现 `src/ip/ip-management.tsx` 与 `ip-management-data.ts`。视觉系统见 `../DESIGN.md`。

管理页让用户在同一工作面选择人物、查看具体版本并继续创作。导航统一使用共享顶栏，主列表铺满内容区，包含真实统计、搜索、筛选和卡片；选中后右侧相邻档案打开，列表仍在原位，正文与底部操作分开滚动。这个组合仅属于 IP 管理，不作为画布抽屉。

对象来自现有个人 Avatar、形象与声音接口，不新建业务 IP 容器。已定稿不表示已发布，未知统计不显示成零；未归档表情、设定图、作品或声音直接说明。筛选无结果、空库、加载、整体与局部失败分别有对应反馈。

四个详情 tab 延续同一人物实体；设定保存同步列表和详情，失败保留草稿。具体视图和历史版本可选，进入形象画布时传递精确 storageKey/avatarId/version/lookId；免费建画布、节点内确认收费。引用写入失败复用已创建的 pending project。设定可导出 Markdown，素材分类和声音试听均沿用现有接口。

最终有内容的桌面截图来自明确演示数据的隔离环境；不以它证明线上真实人物库存或新增作品能力。本轮未完成手机或 1280px 截图验收。
