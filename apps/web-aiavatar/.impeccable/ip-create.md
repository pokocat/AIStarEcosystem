# 创作 · 设计意图

范围：`/create`，实现 `src/ip/studio-create-home.tsx`、共享 `studio-gallery.tsx` 与 `src/styles/ip-create.css`。模式：Operate。方向依据为 [ip-create-direction.md](ip-create-direction.md) 与用户参考截图；视觉系统沿用 [DESIGN.md](../DESIGN.md)。

这是现有浅色工作面的扩展：共享顶栏、暖灰底、白色细边线面板、深墨操作与原有界面字体。页面无侧栏，阅读顺序是快捷创作、个人画布、推荐官方模板。宽桌面用横向画廊；可用内容宽度不足时调整列数，不另设设备形态真值。`html[data-layout]` 仍决定用户选择的形态，画布内部的群青/麦黄作用域保持独立。

上方四个模板入口为个人 IP 女生、个人 IP 男生、数字人视频、IP 商品视频，绑定实际可用模板；图片、视频、剧本及空白画布直接进入免费创建路径，导演、成片、配音、口型与人物库从「更多工具」可达。模板入口只打开原有只读预览；显式「存为个人副本」后才能编辑，进入页面和预览不会启动生成。

个人画布用真实状态、名称与更新时间组织。搜索、状态、排序、网格/列表和每页五张的分页作用于同一列表。封面保留节点/连线 minimap，不用人物图替代；只请求当前页文档，最多并发两份，按项目及更新时间缓存图形结构，不保留签名媒体地址。缺图与局部失败有可见状态和重试。创建锁定重复提交；删除经确认，失败保留原对象和错误。

`/create` 直接挂载统一画廊 `StudioCreateHome`，旧 `CreateCenter` 不再是该路由入口。`/projects` 重定向到 `/create`，个人画布详情继续使用 `/projects/{id}`。推荐官方模板的「查看更多模板」转到 `/templates`。

模板只读预览与个人画布统一占满浏览器内容区：前四个模板快捷入口沿用现有全视口预览弹窗；图片、视频、剧本与空白画布进入的 `/projects/{id}` 不再叠加网站导航或扣除顶栏高度。个人画布保留原生名称和操作栏，返回回到 `/create`，桌面积分复用真实钱包组件及失败重试。`/projects/demos` 仍使用网站导航。此次修正延续既有画布样式和模板使用语义。

本轮本地检查：路由响应 200；真实接口快照为 58 张个人画布、9 份模板和 1 份官方示例，四个快捷模板 ID 均可用。20 项定向测试、应用 typecheck 与 API 契约检查通过，契约仍有原有 handler 警告；广泛测试另有与本次无关的剧本编辑器 `accepted.model` 失败，不能记为全套测试通过。未提交收费生成。

2026-10-10 全屏一致性修正的验证：`app-chrome.test.tsx`、`layout-mode.test.ts`、`wallet-balance.test.tsx` 与 `canvas-gate-auth.test.tsx` 共 34 项定向用例及应用 typecheck 通过；本地 3016 的已有画布路由只读请求响应 200。独立源码审查未发现具体的实质性缺陷；这些证据覆盖外壳路由、形态、钱包与登录闸，不替代页面渲染验收。
