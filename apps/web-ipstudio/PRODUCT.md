# AI IP 工作台 · 产品说明（web-ipstudio）

> 设计真源 [`docs/ip-studio-plan.md`](../../docs/ip-studio-plan.md)；**视觉系统真源
> [`design.md`](design.md)**（配色 token / 语义映射 / landing 与画布边界 / 素材规则）；
> 本文件只讲「这个子应用有哪些模块、界面上守哪些约束」。技术 onboarding 见 [`README.md`](README.md)。

## 1. 它解决什么

个人 / 品牌想要一套能拿去做 IP 的形象，难点从来不是「生成一张好图」，而是**十张图里的人得是同一个人**。
本工作台把这件事拆成一张画布上的几个节点，并把「稳定」做成流程强制：
一张照片 → 抽一次人物特征卡（之后全程复用）→ 挑一套内置风格（文案逐字进提示词）→
出主形象并定稿一张（成为下游每张图的身份锚）→ 批量出造型 → 发布成数字资产。

## 2. 模块清单

| 模块 | 路由 | 说明 |
|---|---|---|
| 公开 landing | `/` | 群青英雄区（三行麦黄大标题 +「创作我的 IP」+ 一张大竖主卡与两张小竖侧卡的重叠拼贴）→ 灵感画廊（四表情，锚 `#gallery`）→ 未来应用方向（四场景 2×2，锚 `#scenes`）→ 商业化展望麦黄横幅（顶栏「关于 IP Studio」锚 `#about` 落这里）→ 收尾 CTA。**landing 上不放产品工作流说明段**（见 §4.12）。CTA 与顶栏「进入工作台」按登录态进 `/projects` 或 `/login`，见 §5 |
| 登录 | `/login` | 账号中心接管时收敛为一个跳转按钮；legacy / mock 模式保留验证码 + 密码表单与 dev 种子账号 |
| 账号中心回调 | `/auth/callback` | 薄壳，复用 `@ai-star-eco/landing` 的 `AuthCallbackScreen` |
| 项目列表 | `/projects` | 我的 IP 项目卡（封面 = 主形象定稿图、草稿 / 已发布徽标、更新时间、删除）+「从模板新建」+「空白画布」 |
| 画布 | `/projects/{id}` | **搬来的开源无限画布**（`basketikun/infinite-canvas`，MIT，v0.157）。节点是通用类型（图 / 文字 / 视频…），要画什么写在节点自己的提示词框里，参考图就是连进来的上游图 —— 一张图一个节点，不再是四个 |
| 数字资产 | `/assets` | **只读**。六类资产概览 + 我的形象列表 + 选中形象详情（名片 / 造型 / 短动作与衍生）。画布发布出来的形象都登记在这儿；改形象回项目，出短动作或改设定去数字资产平台 |
| 名片 | `/cards` | **只读**。我的名片：状态、公开链接、用的哪个形象。草稿不给「打开 / 复制链接」—— 未发布的名片谁都打不开，包括本人。建卡与编辑在数字资产平台上 |
| 开通门 | 同上（拦截态） | 已登录但未开通「数字资产平台」时整页渲染 `EnrollmentGate`（本工作台与数字资产平台共用开通） |

顶栏导航「**项目 · 资产 · 名片**」的顺序就是这条链：造形象 → 登记资产 → 对外发布。

## 3. 画布

画布本体是**搬来的**（`basketikun/infinite-canvas`，MIT，整体 vendor 进
`apps/web-ipstudio/src/canvas`；为什么搬、剥了什么、改动纪律见那儿的 README）。

节点是通用类型：**图 / 文字 / 视频 / 音频 / 配置 / 分组**，不再有「照片 / 特征卡 / 风格 /
形象卡 / 出图」那套定型节点。

- **要画什么写在节点自己的提示词框里**，不是由几张上游卡拼出来
- **参考图就是连进来的上游图**，顺序由用户连线决定，最多 4 张（`aep.ipstudio.max-ref-images`）
- 一致性不靠节点类型强制，靠把上游图当参考喂下去 + 服务端模板里的一致性从句

**模型选择器在画布上**，候选来自后台配好的端点（`AiAppBinding` +
`ai_app_endpoint_candidate`），用户能选模型但不能填 Key。


## 4. 设计约束

1. **配色真源是 [`design.md`](design.md)**（2026-09-06 起）：低饱和**群青** `#495B91`
   （深至 `#344B70`）/ **麦黄** `#E7D58D` / **纸白** `#F5F4EF` / **墨** `#202C42`。
   分工固定 —— 群青给品牌顶栏、选中态与「进行中」；**麦黄只给主动作**（进入工作台 / 运行 /
   发布 / 提交）；工作台保持**浅色工作面**。
   > v0.151 首版的「单一青色 `#12B3DE`」（沿用 AiAvatar Atelier Ledger）已整体退役，
   > 本子应用不再有该色值。档案卡的排版骨架（白卡细边、等宽编号、衬线资产名）保留。
2. **字体分工**：Manrope（界面 + landing 中文大标题走 sans 800）/ Newsreader 衬线
   （**只给**项目名与资产名、节点标题）/ JetBrains Mono（**只给**编号、字段小标签、
   英文提示词、`IP STUDIO` 标识）。中文走系统字体回退链。
3. **文案红线**（AGENTS.md §8）：全中文；不把 `runId` / `stage` / 错误码原文当主可视文案 ——
   阶段翻成「正在画第 2 张」，错误码翻成「形象生成引擎还没在后台配好，请联系运营开通后再试」，
   原始码只进 `title` 悬浮。参考图未生效给中文原因。
4. **不溢出**：所有可变长文字（项目名、节点备注名、造型字段、风格描述、文件名）一律
   `min-w-0` + `truncate` / `line-clamp`，完整内容进 `title`。
5. **禁止原生 `confirm/alert/prompt`**：删除项目用 `@ai-star-eco/ui` 的 `AlertDialog`，
   发布用 `Dialog`，轻提示用自带的 toast 条。
6. **示例产物必须打标**：mock 模式的占位图与样例数据一律带「示例 / MOCK」角标，
   不与真产物混淆（AGENTS.md §8.0）。
7. **前端不碰模型、不碰积分**：生成永远是 `POST .../run` + 轮询 `GET /runs/{id}`；
   花费、参考图取舍、提示词拼装都由服务端决定，前端只如实展示服务端回报的结果。
8. **画布可达性**：撤销重做有键盘快捷键且在输入框内不拦截；节点面板既能拖也能点；
   连线不合法时给中文提示而不是静默失败。
9. **可访问性下限**（landing 与工作台同守，实测值见 [`design.md`](design.md) §2）：
   正文对比度 ≥ 4.5:1、`:focus-visible` 可见（深群青区换麦黄焦点环）、尊重
   `prefers-reduced-motion`；landing 的图集裁切用 `div + background`，每格必须自带
   `role="img"` + `aria-label`。
10. **landing 的手法不进工作台**：纸标签、错落旋转纸卡只在 landing；工作台是重交互面，
    一律规则栅格、无旋转（`design.md` §6 有 reject 清单）。
11. **landing 素材是真实作品图**：全部取自同一张 4×3 等格图集，生产真源在 OSS
    （`.../media/ipstudio/landing/character-atlas-v1.png`，由 `ATLAS_SRC` 直接引用；
    `public/landing/` 只是可选本地副本，不入 git、不自动启用）。
    禁止 SVG / 色块冒充作品，也禁止整页截图当网页；每张图必须是**完整的一格**（竖幅卡用
    `AtlasPortrait` 裁左右空白，不跨格、不拉伸）；场景区必须显式标注「以下为场景示意，
    相关能力将分阶段推出」，不得写成已支持的能力（`design.md` §8）。
12. **landing 不讲工作流**：landing 上不出现「上传照片 → 抽特征卡 → 挑风格 → 出形象组」这类
    流程说明，也不出现模型 / 提示词等技术表述。产品怎么用讲在本文件 §2–§3 与工作台内的
    提示里。已删过一版这样的段落，不要再加回来（`design.md` §10）。
13. **属性面板字号下限**：可编辑输入 / 主按钮 / 属性说明 ≥ 14px，辅助字段标签 12px；
    面板宽度不变，长文靠换行解决，不靠缩小字号或 `line-clamp` 截断（`design.md` §4）。

## 5. 登录与入口

landing 顶栏「进入工作台」与两处「创作我的 IP」共用同一段判断（`useAuth()` 的 `user`）：
已登录 → `/projects`；未登录 → `/login`。`/login` 在账号中心模式（`NEXT_PUBLIC_AUTH_MODE=id`）
下收敛为一个跳转按钮，legacy / mock 模式保留验证码 + 密码表单。本次视觉重构**没有改动**
这段跳转逻辑。

## 6. 不在 P1 的范围

独立产品码与独立开通、一致性打分与自动重跑、增量发布（已发布项目追加造型）、
多人协作、视频节点。见 `docs/ip-studio-plan.md` §8。
